- **Outcome:** `loop: A cancelled handler is released for good, even mid-delivery`
- **Decisions:** named, in Scrutinise, the compaction-and-insertion interaction `deliver()` now

```text
## Summary

Fixes `EventQueue.cancel()` so cancelling a subscription truly stops its handler, as the
`EventSubscription` contract promises: a cancelled handler gets nothing more, including events
already waiting in the same delivery, a second cancel changes nothing, and a cancel mid-delivery
skips no other handler. It touches only cancellation inside `EventQueue` — publish order and
delivery timing are unchanged.
```

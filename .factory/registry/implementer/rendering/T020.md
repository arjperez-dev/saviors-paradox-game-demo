  values I may not drop. `Vec2` is already used the same way throughout other per-frame application
  code (e.g. `lib/features/akeris/application/step_akeris.dart`,
  `lib/features/dungeon/application/step_zone.dart`), so this is a pre-existing, codebase-wide
  characteristic of the `Vec2` contract, not something this task introduced or could fix within its
  file gradient. Recorded here for the architect, not blocked on.

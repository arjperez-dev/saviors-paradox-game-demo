# T011 — Gather one part of the game's texts by key

- **Date:** 2026-10-14
- **Outcome:** Added `TextKey`, a zero-cost key type, and `TextCatalog`, an immutable
  key-to-`LocalizedText` map one part of the game owns, with `entries`, `[]` and a defensive copy
  of the map it is built from.
- **Decisions:** None — the task's `Implementation` compiled and passed as written against the
  tree as it stood.
- **Deviations:** None in `Implementation`. In the test bodies (which the task leaves to the
  implementer, stating only the `Assertion`): the two criteria that compare the catalog's `entries`
  could not assert equality against a `List`/`Iterable` of `MapEntry` directly, because Dart's
  `MapEntry` has no value `==` (it compares by identity), so two otherwise-equal entries never
  matched. Asserted by converting `entries` to a `Map` with `Map.fromEntries` and comparing that to
  the expected `Map` literal instead, which checks the same keys and texts without depending on
  `MapEntry` identity.
- **Evidence:** `lib/core/localization/domain/text_key.dart` and
  `lib/core/localization/domain/text_catalog.dart`, exactly as the task's `Implementation`
  specifies, plus `test/core/localization/domain/text_catalog_test.dart` against the task's
  `Acceptance criteria`. No file outside the task's `files` list was touched.

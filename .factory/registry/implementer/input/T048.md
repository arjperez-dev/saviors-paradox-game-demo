# T048 — Drain the frame's raw input into commands

- **Date:** 2026-10-15
- **Outcome:** Added `TranslateInput`, replacing the architect's stub: it
  keeps the raw inputs received each frame, subscribes through `EventSource`
  to `RunStarted`, `RunEnded`, `QuitToTitleRequested`, `WorldHalted` and
  `WorldResumed` to move `InputContexts`' stack, and on `drainInto` switches
  to the active context (releasing every held key and button through the
  outgoing context first), then translates the frame's inputs in order,
  once each, growing the pointer's stillness by `dt` and resetting it on a
  move.
- **Decisions:** none — the task file left no room; `Implementation` and the
  shared-file block were taken as given.

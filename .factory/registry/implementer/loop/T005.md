# T005 — Deliver published events in the order they were raised

- **Date:** 2026-10-14
- **Outcome:** Replaced the architect's `EventQueue` stub with the Observer implementation:
  `publish` queues, `deliver()` swaps the pending and delivering lists and offers each event in
  publish order to every subscriber whose handler type matches, in subscription order, via
  indexed loops with no allocation; an event published during `deliver()` lands in the swapped-in
  `_pending` list and waits for the next call.

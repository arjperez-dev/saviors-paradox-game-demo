# T064 — Ask a question with the focus on its safe answer

- **Date:** 2026-10-16
- **Outcome:** Added `ConfirmAnswer`, `ConfirmTexts` and `ConfirmQuestion` under
  `lib/core/ui/presentation/`, with their tests, exactly as the task's `Implementation` gave them;
  all ten acceptance criteria pass, `flutter test` and `flutter analyze --fatal-infos` are clean.
- **Decisions:** none — the task file left no room the `Implementation` and the cited references
  did not already fill.
- **Deviations:** `lib/core/ui/presentation/ink_frame.dart` and
  `test/core/ui/presentation/ink_frame_test.dart`, both unlisted but inside my module's root
  (`lib/core/ui/`), touched per the file gradient. Writing "clicking an answer gives it" exposed a
  latent bug in `InkFrame`: its flash `CustomPainter` never overrode `CustomPainter.hitTest`, so
  `RenderCustomPaint.hitTestSelf` defaulted to `true` whenever a painter is set
  (`flutter/packages/flutter/lib/src/rendering/custom_paint.dart`), and because the flash layer is
  the topmost child of `InkFrame`'s own `Stack`, it always claimed the tap first and stopped the
  hit test before it reached any widget placed in `InkFrame.child` — exactly `ConfirmQuestion`'s
  shape, since its two `MenuButton` answers sit inside the confirm box's own `InkFrame.child`. Every
  earlier use of `InkFrame` (`MenuButton`, `KeyCap`) wraps it in its own outer `GestureDetector`, so
  the bug never surfaced before. Fixed by overriding `hitTest` on `_InkFrameFlashPainter` to return
  `false`; added a regression test to `ink_frame_test.dart` for a clickable child receiving its tap
  through an unflashed frame. All of `ink_frame_test.dart`, `menu_button_test.dart` and
  `key_cap_test.dart` still pass unchanged.
- **Evidence:** No adaptation of the task's `Implementation` for the three listed production files
  or the two listed test files — each was written as given, against `08-engineering/testing.md` §3
  and the sandbox's `ttConfirm` for the test bodies. Files touched: `lib/core/ui/presentation/
  confirm_answer.dart`, `confirm_texts.dart`, `confirm_question.dart` (new, listed);
  `test/core/ui/presentation/confirm_texts_test.dart`, `confirm_question_test.dart` (new, listed);

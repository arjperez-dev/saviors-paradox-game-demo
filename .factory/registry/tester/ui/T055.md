# T055 — Generate a sheet's pencil border once from its seed

- **Date:** 2026-10-16
- **Outcome:** all 6 criteria have a matching, passing test; `flutter test` green (6/6).
- **Decisions:** none — no `Manual check` in the task file, so no manual test written.
- **Deviations:** none the tests reach; two checklist gaps found (below), both inherited from the
  same pattern already present in `PencilBox` (T053).
- **Evidence:** `flutter test test/core/ui/domain/sheet_outline_test.dart` → 6 passed, 0 failed,
  names verbatim to the acceptance table:
  - "the same seed gives the same sheet" — `border`/`inner` equal for two `Seed(30000)` builds at
    1680×960.
  - "different seeds give different sheets" — `border` differs for `Seed(1)` vs `Seed(2)`.
  - "the border is slightly out of square" — seeds 1–50, 4 points each, within 0.8 of
    (0,0),(1680,2),(1678,960),(2,959), named to `sheetAt` in a comment.
  - "the inner line sits 12 in" — seeds 1–50, within 1 of (12,12),(1668,13),(1667,948),(12,947),
    named to `sheetAt` and `pause-menu.md` §3 in a comment.
  - "the inner line comes from the next seed" — `inner` equals a direct
    `PolygonStroke.generate(…, Seed(30001), jitter: 1)`.
  - "the corners cannot be changed" — `add` on `border` and on `inner` throws `UnsupportedError`.

  Not reached by any test, and not required by an acceptance criterion or an Interfaces-table
  member: `SheetOutline` itself is not asserted for value equality (`operator ==`/`hashCode`) —
  criterion 1 is satisfied instead through its `border`/`inner` lists' own equality. Also not
  reached: sizes other than 1680×960, and seeds outside 1–50 or negative — none of which the
  acceptance criteria ask for.

  Checklist findings for the implementer:
  - **C11 / standards §4.6 (DRY)**: `SheetOutline.generate` (`lib/core/ui/domain/sheet_outline.dart`
    lines 15–35) repeats, structurally and in one line verbatim, the shape
    `PencilBox.generate` (`lib/core/ui/domain/pencil_box.dart` lines 15–35) already has: a
    `PolygonStroke.generate` from the seed for the outer shape, then a second
    `PolygonStroke.generate` from `Seed(seed.value + 1)` (same expression, `sheet_outline.dart:31`
    and `pencil_box.dart:31`) for an inset inner line, wrapped the same way in a private constructor
    with `List.unmodifiable`. The two differ only in the corner formula (square vs. slightly
    out-of-square), the inset, and the jitter constants — the exact case §4.6 names: "two blocks
    that differ only in their values are one function, one widget or one type with those values as
    parameters." No shared helper for "a seeded shape plus its next-seed inset inner line" exists in
    `core/ui/domain/` or `core/rendering/domain/`. This duplication was already present in T053's
    `PencilBox` and the task's own `Implementation` block specifies the same pattern for
    `SheetOutline`, so the gap is not new to this task's writing, but the code as written still fails
    C11 against `PencilBox`.
  - **architecture §4 (value object)**: the task's own Description calls `SheetOutline` "a value
    object (architecture §4)", whose rule is "equal by value", but the class
    (`lib/core/ui/domain/sheet_outline.dart`) overrides neither `operator ==` nor `hashCode` — the
    same gap already found for `PencilBox` in T053's tester report.

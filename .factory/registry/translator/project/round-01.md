# Round 01 — Initial idea: demo scope, story, stack, art, progression, permadeath

- **Date:** 2026-09-28
- **Outcome:** The idea became a Windows roguelike action-platformer demo of 5 of 20 zones, each
  closed by a boss, with the three-Akeris story, in-run progression and procedural zones.
- **Decisions:** Stack (Flutter desktop, OOP, DDD, Clean Code, patterns) recorded as client
  constraints only; the new-enemy design request held until proposals could be confirmed.
- **Deviations:** The operator's design document and animation were declared context only, not
  the idea; the demo framing and the story were new.
- **Evidence:** Set vision statement, genre, core loop, content scope (5/20 zones, 5 bosses),
  reference games (Hollow Knight, Dead Cells, Hades), session shape (autosave, permadeath),
  target platform, client constraints, success criteria, risks (art quality). Forced by the
  operator's 14-point brief.

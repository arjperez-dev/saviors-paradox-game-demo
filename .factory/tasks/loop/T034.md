# T034 — Keep the set of causes that halt the world

## Description

The bookkeeping of the world halts (architecture §2.3, architect `change-02`). Each screen that
stops the world names its `HaltCause`; `WorldHalts` holds the set of causes standing now. A halt
adds its cause and a resume removes only its own, so a repeated halt is ended by one resume and a
resume with no matching halt changes nothing. `StepClock` will only ask whether the world is halted
(T035); this class is the one place the set is kept (coding-standards §1, S).

## Constraints

- `domain/`: imports nothing of Flutter, Flame, `dart:async` or `dart:ui`.

## Implementation

```dart
// lib/core/loop/domain/world_halts.dart — new
import 'package:saviors_paradox/core/contracts/events/halt_cause.dart';

/// The causes that hold the world step, one per screen that stops it
/// (architecture.md §2.3). A repeated halt and a resume with no matching
/// halt change nothing.
final class WorldHalts {
  final Set<HaltCause> _causes = {};

  bool get isHalted => _causes.isNotEmpty;

  void halt(HaltCause cause) => _causes.add(cause);

  void resume(HaltCause cause) => _causes.remove(cause);
}
```

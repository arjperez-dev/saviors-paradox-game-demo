# T035 — Hold the world step while any halt cause stands

## Description

Under change-02 the world stops for five screens, not one: each raises an event extending
`WorldHalted` and ends it with one extending `WorldResumed`, both naming its `HaltCause`
(architecture §2.3). `GameLoop` stops hearing `PauseOpened`/`PauseClosed` and hears the two bases,
handing each cause to T034's `WorldHalts`; `StepClock` drops its own pause flag and only asks
`WorldHalts`. Its constructor only grows: given no halts, it keeps its own, so `lib/core/app/` and
T009's integration test compile unchanged. A hitstop still waits while the world is halted.

## Preconditions

- On `main`: T006's `StepClock` with `pause()`, `resume()`, `isHeld` and `advance`; T007's
  `GameLoop` subscribing `PauseOpened`, `PauseClosed` and `HitstopStarted`. T034's `WorldHalts` on
  `feat/loop`.
- `step_clock_test.dart` holds T006's eight tests; three of them call `pause()`/`resume()`.
- `game_loop_test.dart` holds T007's six tests.

## Constraints

- `StepClock()` and `StepClock(maxStep: …)` keep compiling: `lib/core/app/saviors_paradox_game.dart`
  calls `StepClock()` and is not this task's to change.
- The `GameLoop` constructor does not change in this task.

## Implementation

```dart
// lib/core/loop/domain/step_clock.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/loop/domain/world_halts.dart';

/// Turns the time a frame took into the step the systems receive.
final class StepClock {
  StepClock({this._maxStep = defaultMaxStep, WorldHalts? halts})
    : halts = halts ?? WorldHalts();

  /// The longest step a system ever receives, so that a stall never
  /// tunnels a body through a wall (architecture.md §5).
  static const Seconds defaultMaxStep = Seconds(1 / 30);

  final Seconds _maxStep;

  /// The causes holding the world step; the clock only asks them.
  final WorldHalts halts;

  Seconds _hitstopLeft = Seconds.zero;

  bool get isHeld => halts.isHalted || _hitstopLeft > Seconds.zero;

  /// Holds the step for [duration]; a shorter hitstop never shortens a
  /// longer one already running.
  void holdFor(Seconds duration) {
    if (duration > _hitstopLeft) {
      _hitstopLeft = duration;
    }
  }

  /// The world step for a frame of [frame] seconds: zero while the world
  /// is halted or while a hitstop lasts, what is left of the frame when the
  /// hitstop ends inside it, and never more than the maximum step.
  Seconds advance(Seconds frame) {
    if (halts.isHalted) {
      return Seconds.zero;
    }
    final clamped = frame.atMost(_maxStep);
    if (clamped <= _hitstopLeft) {
      _hitstopLeft = _hitstopLeft - clamped;
      return Seconds.zero;
    }
    final left = clamped - _hitstopLeft;
    _hitstopLeft = Seconds.zero;
    return left;
  }
}
```

# T008 — Drive the game loop from Flame's update

## Description

The one place that reads time (architecture §5): a Flame component whose `update(dt)` hands Flame's
`dt` to the `GameLoop` as `Seconds`. The integrator adds it to the game the composition root builds,
with an empty list of systems: each later feature that brings a system asks for its place in the
list through `shared_file_notes`.

## Preconditions

- T007's `GameLoop`, as its `Interfaces` declare.
- `lib/core/app/saviors_paradox_game.dart` on `main` is T003's: an empty
  `final class SaviorsParadoxGame extends FlameGame<World> {}`.

## Interfaces

| File | Symbol | Role | Signature |
|---|---|---|---|
| `lib/core/loop/presentation/loop_component.dart` | `LoopComponent` | exports | `final class LoopComponent extends Component` — `LoopComponent(GameLoop loop)` |
| `lib/core/loop/application/game_loop.dart` | `GameLoop` | uses | `GameLoop({required EventQueue queue, required StepClock clock, required List<SystemStep> systems})` |

## Implementation

```dart
// lib/core/loop/presentation/loop_component.dart — new
import 'package:flame/components.dart';
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/loop/application/game_loop.dart';

/// The one clock of the game: Flame's `dt`, handed to the loop as
/// [Seconds] (architecture.md §5).
final class LoopComponent extends Component {
  LoopComponent(this._loop);

  final GameLoop _loop;

  @override
  void update(double dt) => _loop.advance(Seconds(dt));
}
```

```dart
// lib/core/app/saviors_paradox_game.dart — shared, applied by the integrator
import 'dart:async';

import 'package:flame/components.dart';
import 'package:flame/game.dart';
import 'package:saviors_paradox/core/loop/application/event_queue.dart';
import 'package:saviors_paradox/core/loop/application/game_loop.dart';
import 'package:saviors_paradox/core/loop/domain/step_clock.dart';
import 'package:saviors_paradox/core/loop/presentation/loop_component.dart';

/// The game the composition root builds: the loop, and the systems later
/// waves add to it in their fixed order.
final class SaviorsParadoxGame extends FlameGame<World> {
  final EventQueue _events = EventQueue();

  @override
  FutureOr<void> onLoad() => add(
    LoopComponent(
      GameLoop(queue: _events, clock: StepClock(), systems: const []),
    ),
  );
}
```

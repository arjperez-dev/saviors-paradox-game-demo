# T107 — Split the zone builder into part files

## Description

T092's open finding C4: `zone_builder.dart` is 435 lines, over coding-standards §3's 300. The file
becomes a library of three files. `zone_builder.dart` keeps `ZoneBuilder`, `_Onward` and `_Attempt`;
the grid occupancy moves to the part `zone_builder_placement.dart`, the attaching of a room to the
part `zone_builder_attacher.dart`. Nothing changes but where the code sits: the same `Random` calls
in the same order, so every seed lays out exactly the zone it laid out before.

## Preconditions

- On `main`, `lib/features/dungeon/domain/zone_builder.dart` is 435 lines as T092 integrated it:
  `ZoneBuilder` (lines 15–28), `_Onward` (30–31), `_Draft`, `_Doorway`, `_Option`, `_Attached`,
  `_Placement` (33–148), `_Attacher` (150–265) and `_Attempt` (267–435).

## Constraints

- Every moved line is moved verbatim: no rename, no reordering, no change to an expression.
- The part files hold no imports (Dart's `part of` rule); every import stays in `zone_builder.dart`.
- Each file stays under 300 lines and each class under 200 (coding-standards §3).
- The private types stay private to the library; nothing becomes public.

## Interfaces

| File | Symbol | Role | Building block | Signature |
|---|---|---|---|---|
| `lib/features/dungeon/domain/zone_builder.dart` | `ZoneBuilder` | exports | factory | unchanged: `const ZoneBuilder()`, `static const int branchTries`, `static const int longestBranch`, `ZoneLayout? build(BiomeKit kit, Seed seed)` |

## Implementation

```dart
// lib/features/dungeon/domain/zone_builder.dart — the head of the file;
// the imports (lines 1–13) stay as they are, then:

part 'zone_builder_attacher.dart';
part 'zone_builder_placement.dart';

// Lines 15–31 as they stand (ZoneBuilder, _Onward), then lines 267–435 as
// they stand (_Attempt). Nothing else.
```

```dart
// lib/features/dungeon/domain/zone_builder_placement.dart — new
part of 'zone_builder.dart';

// Lines 33–148 of the old zone_builder.dart, verbatim: _Draft, _Doorway,
// _Option, _Attached and _Placement.
```

```dart
// lib/features/dungeon/domain/zone_builder_attacher.dart — new
part of 'zone_builder.dart';

// Lines 150–265 of the old zone_builder.dart, verbatim: _Attacher.
```

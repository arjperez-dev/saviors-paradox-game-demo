# T103 — Open the boss room's doors

## Description

`BossRoomDoors`, the use case behind the `BossRoomSeal` contract that `run` calls when the boss
dies. It replaces the stub. It loads the zone, asks the root to open the sealed doors, saves the
zone, and, when the root opened them, cues `sfx.bossDoor.open` at the boss room (`boss-room.md`
*Exit*; `sfx.md`). Doors that never sealed stay as they were. Sealing comes with the step driven
by Akeris's position (architect change-04).

## Preconditions

- On `main`, `lib/features/dungeon/application/boss_room_doors.dart` is a stub whose `unseal`
  does nothing.
- T098's `ZoneFactory` and T099's repository and mocks are on `feat/dungeon`.

## Constraints

- No rule and no state; one aggregate per call.

## Implementation

```dart
// lib/features/dungeon/application/boss_room_doors.dart — replaced whole
import 'package:saviors_paradox/core/contracts/events/sound_effect_cued.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_id.dart';
import 'package:saviors_paradox/core/contracts/ports/boss_room_seal.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/features/dungeon/application/ports/zone_repository.dart';

/// Opens the boss room's doors when the run says the boss is dead.
final class BossRoomDoors implements BossRoomSeal {
  BossRoomDoors(this._zones, this._events);

  /// 07-audio/sfx/sfx.md: the padlock breaks and the bars rise.
  static const SoundEffectId opened = SoundEffectId('sfx.bossDoor.open');

  final ZoneRepository _zones;
  final EventSink _events;

  @override
  void unseal() {
    final zone = _zones.load();
    if (zone == null) {
      return;
    }
    final unsealed = zone.unsealBossRoom();
    _zones.save(zone);
    if (unsealed != null) {
      _events.publish(SoundEffectCued(sound: opened, at: unsealed.at));
    }
  }
}
```

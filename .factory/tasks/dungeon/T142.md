# T142 — Tell stone from platforms, and carry what platforms hold

## Description

Architect change-05 (`ports-collision_world`). `hazards.md`: firm ground is stone, never a
platform, and a platform carries Akeris.

- **`isStaticSolidAt(point)`:** the zone's stone alone, never a platform.
- **`carry(box)`:** what the zone's last `advance` did to a box. The root keeps each platform's box
  from before the step in a new private part, `_PlatformMotion`, refilled in place.

**What `carry` returns:**
- the platform's displacement, for a box standing on a platform before the step (feet within 1 su
  of its top, overlapping it across);
- for a platform that moved into the box, the shift that puts the box out, along the platform's
  motion:
  - risen into it: on top, `Vec2(0, top − box.bottom)`;
  - come down into it: below, `Vec2(0, bottom − box.top)`;
  - moved sideways into it: beside it, on the side it moved toward;
- otherwise `Vec2.zero`.

Zone 1's kit moves platforms both up and down (`Vec2(0, 220)`, `Vec2(0, ±640)`) and sideways
(`Vec2(480, 0)`), so every case occurs.

`ZoneCollisionWorld` answers both, replacing change-05's stubs.

**Invariants added to the root:** what `carry` measures is always the zone's last step; stone and
platforms are told apart.

## Preconditions

- On `main`, `ZoneCollisionWorld.isStaticSolidAt` returns false and `carry` returns `Vec2.zero`,
  each marked not implemented (architect change-05).
- T109 is on `feat/dungeon` (it also edits `zone.dart`).

## Constraints

- `_PlatformMotion` is a `part of 'zone.dart'`, private (wave-04 `entities-behind-their-root`).
- `carry` allocates only the `Vec2` it returns (wave-04 `kernel-vec2-allocates`).

## Implementation

```dart
// lib/features/dungeon/domain/platform_motion.dart — new
part of 'zone.dart';

// Where each drifting platform stood before the zone's last step, and how
// that step carried a box with them (hazards.md: a platform carries
// Akeris; architect change-05).
final class _PlatformMotion {
  _PlatformMotion(List<WorldBox> boxes) : _before = List.of(boxes);

  // A box whose feet lie within 1 su of a platform's top stands on it.
  static const double _footing = 1;

  final List<WorldBox> _before;

  void remember(List<WorldBox> now) {
    for (var i = 0; i < now.length; i++) {
      _before[i] = now[i];
    }
  }

  Vec2 carry(WorldBox box, List<WorldBox> now) {
    for (var i = 0; i < now.length; i++) {
      if (_standsOn(box, _before[i])) {
        return now[i].centre - _before[i].centre;
      }
      if (now[i].overlaps(box)) {
        return _outOf(box, now[i], now[i].centre - _before[i].centre);
      }
    }
    return Vec2.zero;
  }

  static bool _standsOn(WorldBox box, WorldBox platform) =>
      (box.bottom - platform.top).abs() <= _footing &&
      box.left < platform.right &&
      platform.left < box.right;

  // Out along the platform's motion: on top, below, or beside it.
  static Vec2 _outOf(WorldBox box, WorldBox platform, Vec2 moved) {
    if (moved.y < 0) return Vec2(0, platform.top - box.bottom);
    if (moved.y > 0) return Vec2(0, platform.bottom - box.top);
    if (moved.x > 0) return Vec2(platform.right - box.left, 0);
    if (moved.x < 0) return Vec2(platform.left - box.right, 0);
    return Vec2.zero;
  }
}
```

```dart
// lib/features/dungeon/domain/zone.dart — the changes.
// 1. `part 'platform_motion.dart';` in the part list.
// 2. In Zone._'s initializer list:  _motion = _PlatformMotion(parts.platformBoxes),
// 3. The field:                     final _PlatformMotion _motion;
// 4. `advance` remembers the boxes before it moves them:
  void advance(Seconds dt) {
    _motion.remember(_platformBoxes);
    for (var i = 0; i < _platforms.length; i++) {
      _platforms[i]._advance(dt);
      _platformBoxes[i] = _platforms[i]._box;
    }
  }
// 5. After `isSolidAt`:
  /// Stone alone: never a drifting platform (hazards.md).
  bool isStaticSolidAt(Vec2 point) => _geometry.isSolidAt(point);

  /// What the last [advance] did to [box] (CollisionWorld.carry).
  Vec2 carry(WorldBox box) => _motion.carry(box, _platformBoxes);
```

`parts-tested-through-root`). It uses the first zone of seeds 1–10 with a platform, picking one
whose path is vertical or horizontal for each test, and advances it by `Seconds(1 / 60)`. "Its box
before" and "after" are `zone.platforms[i]` read before and after the advance.

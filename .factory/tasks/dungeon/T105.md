# T105 — Step the drifting platforms

## Description

`StepZone`, the system that advances the current zone each world step, moving its drifting
platforms (`hazards.md`). It replaces the stub. Its `state` is the zone's `ZoneState` snapshot.
It keeps the last snapshot as a memo of derived data, rebuilt only when the zone or its revision
changes, so the features that read `ZoneState` don't rebuild it every frame (operator,
2026-10-16). Before any zone exists, `state` is refused with a `StateError`. The room-entry,
boss-room and way-down events it will publish come with the step driven by Akeris's position.

## Preconditions

- On `main`, `lib/features/dungeon/application/step_zone.dart` is a stub with
  `ZoneState get state` and `void step(Seconds dt)`.
- T098's factory, T099's repository and mocks, and T100's `readZoneState` are on `feat/dungeon`.

## Constraints

- Its fields besides the repository are the memo (the zone shown, its revision, its snapshot):
  derived, never game state. `step` allocates nothing of its own.

## Implementation

```dart
// lib/features/dungeon/application/step_zone.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/state/zone_state.dart';
import 'package:saviors_paradox/features/dungeon/application/ports/zone_repository.dart';
import 'package:saviors_paradox/features/dungeon/application/zone_reading.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone.dart';

/// Advances the current zone by the world step, and shows its snapshot.
final class StepZone {
  StepZone(this._zones);

  final ZoneRepository _zones;

  // A memo of the last snapshot, rebuilt only when the zone or its
  // revision changes: derived, not game state (architecture.md §4, §6.5).
  Zone? _shown;
  int _shownRevision = -1;
  ZoneState? _state;

  ZoneState get state {
    final zone = _zones.load();
    if (zone == null) {
      throw StateError('no zone has been generated yet');
    }
    final shown = _state;
    if (shown != null &&
        identical(zone, _shown) &&
        zone.revision == _shownRevision) {
      return shown;
    }
    _shown = zone;
    _shownRevision = zone.revision;
    return _state = readZoneState(zone);
  }

  void step(Seconds dt) {
    final zone = _zones.load();
    if (zone == null) {
      return;
    }
    zone.advance(dt);
    _zones.save(zone);
  }
}
```

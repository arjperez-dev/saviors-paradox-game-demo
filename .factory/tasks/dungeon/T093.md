# T093 — Check a zone layout can be played

## Description

`ZoneValidator`, the specification a layout must satisfy before it becomes a zone
(design-patterns §10, §12; `layout.md` §B.2 step 4 and Acceptance 2–3):
- at least the fewest rooms;
- at least the fewest dead ends (the altars and the lore spirit's);
- every room reachable from the start;
- the boss room reachable from the start through main-path rooms alone.

## Preconditions

- T091's layout values are on `feat/dungeon`; tests build their rooms from T090's sanctuary
  templates.

## Constraints

- A specification: no state of its own, and no `if` chains in place of its named checks.

## Implementation

```dart
// lib/features/dungeon/domain/zone_validator.dart — new
import 'package:saviors_paradox/features/dungeon/domain/placed_room.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_kind.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone_layout.dart';

/// Whether a layout makes a playable zone (layout.md §B.2 step 4,
/// Acceptance 2–3).
final class ZoneValidator {
  const ZoneValidator({required this.fewestRooms, required this.fewestDeadEnds});

  final int fewestRooms;
  final int fewestDeadEnds;

  bool isSatisfiedBy(ZoneLayout layout) =>
      layout.rooms.length >= fewestRooms &&
      _deadEnds(layout) >= fewestDeadEnds &&
      _everyRoomReached(layout) &&
      _bossOnMainPath(layout);

  static int _deadEnds(ZoneLayout layout) =>
      layout.rooms.where((room) => room.kind == RoomKind.deadEnd).length;

  static bool _everyRoomReached(ZoneLayout layout) {
    final start = _indexOf(layout, RoomKind.start);
    return start >= 0 &&
        _reached(layout, start, (room) => true).length == layout.rooms.length;
  }

  static bool _bossOnMainPath(ZoneLayout layout) {
    final start = _indexOf(layout, RoomKind.start);
    final boss = _indexOf(layout, RoomKind.boss);
    return start >= 0 &&
        boss >= 0 &&
        _reached(layout, start, (room) => room.isOnMainPath).contains(boss);
  }

  static int _indexOf(ZoneLayout layout, RoomKind kind) =>
      layout.rooms.indexWhere((room) => room.kind == kind);

  static Set<int> _reached(
    ZoneLayout layout,
    int start,
    bool Function(PlacedRoom room) canEnter,
  ) {
    final reached = <int>{start};
    _visit(layout, start, reached, canEnter);
    return reached;
  }

  static void _visit(
    ZoneLayout layout,
    int room,
    Set<int> reached,
    bool Function(PlacedRoom room) canEnter,
  ) {
    for (final next in layout.neighboursOf(room)) {
      if (canEnter(layout.rooms[next]) && reached.add(next)) {
        _visit(layout, next, reached, canEnter);
      }
    }
  }
}
```

## Acceptance criteria

Each test builds a small `ZoneLayout` by hand from the sanctuary's templates, with
`ZoneValidator(fewestRooms: 4, fewestDeadEnds: 1)`. "The playable layout" is: start (0) →
antechamber (1) → boss (2) → way down (3), all on the main path, plus a dead end (4) linked to
the start.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/dungeon/domain/zone_validator_test.dart` | a playable layout passes | The playable layout satisfies the validator. |
| `test/features/dungeon/domain/zone_validator_test.dart` | a layout with fewer rooms than the fewest fails | With `fewestRooms: 6`, the playable layout fails (`04-zones/zone-1-suspended-sanctuary/layout.md` §B.2 step 4). |
| `test/features/dungeon/domain/zone_validator_test.dart` | a layout with too few dead ends fails | With `fewestDeadEnds: 2`, the playable layout fails (`layout.md` §B.2 step 4). |
| `test/features/dungeon/domain/zone_validator_test.dart` | a layout with a room no passage reaches fails | Removing the dead end's link leaves the layout failing (`layout.md` Acceptance 3). |
| `test/features/dungeon/domain/zone_validator_test.dart` | a layout whose boss is reached only through a branch fails | With the antechamber off the main path (`isOnMainPath: false`), the layout fails (`layout.md` Acceptance 3: the boss is reachable without any branch). |

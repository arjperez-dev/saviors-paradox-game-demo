# T109 — Follow Akeris through the rooms of a zone

## Description

The `Zone` root learns where Akeris is (architect change-04, `ports-zone_presence`). Three root
methods, each taking his feet and returning its domain event or null (wave-04
`roots-return-their-events`):

- `enterRoomAt` — the room he is in now, when it is another than the last one.
- `sealAround` — seals the boss room once he is 280 su inside it (`boss-room.md` Z12).
- `reachWayDownAt` — the foot of the way down, once its doors have opened (`layout.md` Z9).

What the root remembers of him lives in a private part, `_Presence`, as `_AltarBook` holds the
altars, so `Zone`'s own body stays under 200 lines.

**Invariants the root guards:**
- Akeris is in at most one room: the last room whose box held the point 60 su above his feet.
  Outside every room, the last room holds.
- A room is reported only when it changes.
- The doors seal once, only from open, only with his feet more than 280 su from both side walls
  inside the boss room's box.
- The way down is reached at most once, and only after the doors have opened.

**Domain events it records:** `AkerisEnteredRoom(room)`, `BossRoomSealed(room, boss)` (the existing
event, now also reached through `sealAround`), `AkerisReachedWayDown(zone)`.

Following him changes no snapshot, so `revision` rises only when the doors seal, as it does today.

## Preconditions

- On `main`, `zone.dart` declares `Zone` with `roomContaining`, `sealBossRoom`, `isWayDownOpen`,
  `wayDown`, `number`, the private `_bossRoomBounds`, and the parts `altar.dart`, `altar_book.dart`,
  `drifting_platform.dart`, `room.dart`, `zone_assembly.dart` (T097).
- On `main`, `zone_event.dart` declares the sealed `ZoneEvent` with `BossRoomSealed`,
  `BossRoomUnsealed`, `ItemTakenFromAltar`, `ItemReturnedToAltar`.

## Constraints

- `_Presence` is a `part of 'zone.dart'`, private, with no public member reachable from outside the
  library (checklist A7, A12).
- Each value taken from a reference names it in a comment, in the code and in the test
  (coding-standards §9, testing §3).
- The per-step path allocates only the probe point `feet - _probe` and an event when one happens
  (wave-04 `kernel-vec2-allocates`).

## Implementation

```dart
// lib/features/dungeon/domain/akeris_presence.dart — new
part of 'zone.dart';

// Where Akeris has been in the zone, as the root follows him (checklist
// C4: keeps Zone's own body under its line limit).
final class _Presence {
  // The zone 1 sandbox's `zAfterStep`: his room is the one holding the
  // point 60 su above his feet.
  static const Vec2 _probe = Vec2(0, 60);

  // boss-room.md Z12: the doors seal when he is 280 su inside, so they
  // never close on him in the doorway.
  static const double _sealDepth = 280;

  // The zone 1 sandbox's `zAfterStep`: the foot of the way down is
  // reached within 60 su across and 30 su up or down.
  static const double _wayDownAcross = 60;
  static const double _wayDownUpOrDown = 30;

  EntityId? _room;
  bool _hasReachedWayDown = false;

  static Vec2 probeOf(Vec2 feet) => feet - _probe;

  /// True when [room] is another than the one he was in, which it becomes.
  bool moveInto(EntityId room) {
    if (room == _room) {
      return false;
    }
    _room = room;
    return true;
  }

  static bool isDeepIn(WorldBox bossRoom, Vec2 feet) =>
      feet.x > bossRoom.left + _sealDepth &&
      feet.x < bossRoom.right - _sealDepth &&
      feet.y > bossRoom.top &&
      feet.y < bossRoom.bottom;

  /// True the first time [feet] stand at the foot of [wayDown].
  bool reaches(Vec2 wayDown, Vec2 feet) {
    if (_hasReachedWayDown) {
      return false;
    }
    final isAtFoot =
        (feet.x - wayDown.x).abs() < _wayDownAcross &&
        (feet.y - wayDown.y).abs() < _wayDownUpOrDown;
    _hasReachedWayDown = isAtFoot;
    return isAtFoot;
  }
}
```

```dart
// lib/features/dungeon/domain/zone.dart — the changes.
// 1. Add to the part list, in order:
part 'akeris_presence.dart';
// 2. Add the field, initialised where it is declared:
  final _Presence _presence = _Presence();
// 3. Add the three methods after `unsealBossRoom`:

  /// The room Akeris's [feet] stand in, when it is another than the last
  /// one he was in; null otherwise.
  AkerisEnteredRoom? enterRoomAt(Vec2 feet) {
    final room = roomContaining(_Presence.probeOf(feet));
    if (room == null || !_presence.moveInto(room)) {
      return null;
    }
    return AkerisEnteredRoom(room: room);
  }

  /// Seals the boss room once Akeris's [feet] are deep inside it; null
  /// otherwise, or once the doors are no longer open.
  BossRoomSealed? sealAround(Vec2 feet) =>
      _Presence.isDeepIn(_bossRoomBounds, feet) ? sealBossRoom() : null;

  /// Akeris at the foot of the way down after the doors opened: once.
  AkerisReachedWayDown? reachWayDownAt(Vec2 feet) =>
      isWayDownOpen && _presence.reaches(wayDown, feet)
      ? AkerisReachedWayDown(zone: number)
      : null;
```

final class AkerisEnteredRoom extends ZoneEvent {

  @override

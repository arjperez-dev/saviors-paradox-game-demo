# T108 — Pass the zone factory to the zone generator

## Description

T102's open finding (checklist T7, C2): `SeededZoneGenerator` builds `const ZoneFactory()` inline,
so no test reaches the branch where no attempt fits. The generator takes its factory through its
constructor, defaulting to the real one, and `ZoneFactory` becomes an `interface class` so a test
can stand a mock in for it. The default keeps every caller — `test/integration/dungeon_zone_test.dart`
among them — compiling unchanged.

## Preconditions

- On `main`, `ZoneFactory` is a `final class` with `const ZoneFactory()` and
  `Result<Zone, ZoneFailure> create(ZoneNumber number, BiomeKit kit, Seed seed)` (T098).
- On `main`, `SeededZoneGenerator({required List<BiomeKit> kits, required this._zones,
  required this._events})` calls `const ZoneFactory().create(...)` (T102).

## Constraints

- `ZoneFactory`'s behaviour, its `attempts` and its `const` constructor are unchanged.
- No other caller of either type changes.

// lib/features/dungeon/domain/zone_factory.dart — one line changes:
// `final class ZoneFactory {` becomes

```dart
// lib/features/dungeon/application/seeded_zone_generator.dart — the
// constructor and the build change; the rest stays as it is.
  SeededZoneGenerator({
    required List<BiomeKit> kits,
    required this._zones,
    required this._events,
    this._zoneFactory = const ZoneFactory(),
  }) : _kits = List.unmodifiable(kits);

  // One kit per zone number, from zone 1.
  final List<BiomeKit> _kits;
  final ZoneRepository _zones;
  final EventSink _events;
  final ZoneFactory _zoneFactory;

  @override
  ZoneState generate(ZoneNumber zone, Seed seed) {
    if (zone.value > _kits.length) {
      throw StateError('no biome kit for zone ${zone.value} yet');
    }
    final built = _zoneFactory.create(
      zone,
      _kits[zone.value - 1],
      seed.forZone(zone),
    );
    // … the switch, save and publish as they stand.
  }
```

```dart
// test/features/dungeon/mocks.dart — one class added, with its import
// of zone_factory.dart.
class MockZoneFactory extends Mock implements ZoneFactory {}
```

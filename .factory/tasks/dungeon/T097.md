# T097 — Guard a generated zone behind its root

## Description

`Zone`, the aggregate root of a generated zone (glossary §6). It is assembled from a layout
(`layout.md` §B.4: where things stand):
- its rooms, as `Room` entities;
- an `Altar` in every altar dead end, at its feature spot;
- a `DriftingPlatform` for every drift path, with the sandbox's phase
  `((room × 37 + platforms so far × 11) mod 100) / 100`;
- the lore spirit at the deepest dead end's feature spot, and the warning spirit at the
  antechamber's warning spot;
- the start at the start room's start spot, the way down at the exit's spot, and the boss room;
- its still world, a `ZoneGeometry`.

**Invariants it guards:**
- an altar holds at most one gift; taking empties it, and a gift returns only to an empty altar;
- the boss room's doors go open → sealed → opened, each step once: never opened before they
  sealed (`boss-room.md` Never);
- the way down opens only once the doors open (`boss-room.md` Never);
- a platform moves only by time, along its path (`hazards.md`);
- sweeps and casts meet the platforms where they stand now;
- every change raises the zone's revision.

**Domain events it records**, each returned by the call that caused it: `BossRoomSealed`,
`BossRoomUnsealed`, `ItemTakenFromAltar` and `ItemReturnedToAltar`.

**Queries the later position-driven step needs:**
- `roomContaining(point)`, as a room id;
- `altarWithinReach(point)`, the nearest altar within 80 su, as an altar id (`items.md` §2: the
  sandbox's 80 su; operator, 2026-10-16).

## Preconditions

- T089's values, T090's kit, T091's layout, T094's `Sweep`, T095's `ZoneGeometry` and T096's
  `AltarGift` are on `feat/dungeon`.
- The tests take their layout from T092's `ZoneBuilder` and T093's `ZoneValidator`.

## Constraints

- **The aggregate boundary.**
  - `Room`, `Altar` and `DriftingPlatform` are `part of 'zone.dart'`, with library-private
    constructors (`Room._`, `Altar._`, `DriftingPlatform._`) and mutators (`_gift`, `_advance`).
    So are `_Assembly` and `_Parts`, in `zone_assembly.dart`.
  - No method of `Zone` returns, takes or exposes an entity. It answers with an `EntityId`, a view
    value (`RoomView`, `AltarView`, `SpiritPlace`), a `WorldBox`, a `Contact`, a `HookSpot` or a
    domain event.
  - Every change goes through `takeFrom`, `returnTo`, `sealBossRoom`, `unsealBossRoom` or
    `advance`. Never `altar.take()` from outside.
  - `rooms`, `altars`, `spirits`, `platforms` and `ringsNear`'s answer are unmodifiable; `_rooms`,
    `_altars` and `_platforms` never leave the root.
- Entities are equal by their `EntityId` alone (checklist A12). Views and events follow T089's
  `Constraints`.
- No `late` (coding-standards §6.5): every field is set in the initializer list.
- `advance`, `sweep`, `cast`, `isSolidAt`, `isAbyssAt` and `ringsNear` use indexed loops and
  allocate nothing but the boxes and contacts they answer with.
- `room.dart`, `altar.dart`, `drifting_platform.dart`, `zone_assembly.dart` and `zone_event.dart`
  have no test file of their own; they are tested through `zone_test.dart`.

```dart
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';

/// What a zone shows of one of its rooms.
final class RoomView {
  RoomView({
    required this.room,
    required this.bounds,
    required List<EntityId> neighbours,
    required this.isOnMainPath,
    required this.isBossRoom,
  }) : neighbours = List.unmodifiable(neighbours);

  final EntityId room;
  final WorldBox bounds;
  final List<EntityId> neighbours;
  final bool isOnMainPath;
  final bool isBossRoom;

  @override
  bool operator ==(Object other) =>
      other is RoomView &&
      other.room == room &&
      other.bounds == bounds &&
      _sameIds(other.neighbours, neighbours) &&
      other.isOnMainPath == isOnMainPath &&
      other.isBossRoom == isBossRoom;

  @override
  int get hashCode => Object.hash(
    room,
    bounds,
    Object.hashAll(neighbours),
    isOnMainPath,
    isBossRoom,
  );
}

bool _sameIds(List<EntityId> a, List<EntityId> b) {
  if (a.length != b.length) {
    return false;
  }
  for (var i = 0; i < a.length; i++) {
    if (a[i] != b[i]) {
      return false;
    }
  }
  return true;
}
```

```dart
// lib/features/dungeon/domain/zone_assembly.dart — new
part of 'zone.dart';

// Builds a zone's parts from its layout (layout.md §B.4).
final class _Assembly {
  _Assembly(this.layout, this.ids, this.kit, this.seed);

  final ZoneLayout layout;
  final ZoneIds ids;
  final BiomeKit kit;
  final Seed seed;

  ZoneGrid get _grid => layout.grid;

  _Parts parts() => _Parts(_rooms(), _altars(), _platforms());

  PlacedRoom roomOf(RoomKind kind) => roomWhere((room) => room.kind == kind);

  PlacedRoom roomWhere(bool Function(PlacedRoom room) test) =>
      layout.rooms.firstWhere(
        test,
        orElse: () => throw StateError('the layout lacks a room a zone needs'),
      );

  Vec2 spotIn(PlacedRoom room, SpotKind kind) {
    final spot = room.template.spot(kind);
    if (spot == null) {
      throw StateError('room ${room.template.id} has no ${kind.name} spot');
    }
    return room.originOn(_grid) + spot;
  }

  List<SpiritPlace> spirits() {
    final lore = roomWhere((room) => room.role == DeadEndRole.lore);
    final warning = roomOf(RoomKind.antechamber);
    return [
      SpiritPlace(
        spirit: ids.spirit(0),
        role: SpiritRole.lore,
        room: ids.room(lore.index),
        position: spotIn(lore, SpotKind.feature),
      ),
      SpiritPlace(
        spirit: ids.spirit(1),
        role: SpiritRole.warning,
        room: ids.room(warning.index),
        position: spotIn(warning, SpotKind.warning),
      ),
    ];
  }

  List<Room> _rooms() => [
    for (final room in layout.rooms)
      Room._(
        id: ids.room(room.index),
        bounds: room.boundsOn(_grid),
        neighbours: [
          for (final next in layout.neighboursOf(room.index)) ids.room(next),
        ],
        isOnMainPath: room.isOnMainPath,
        isBossRoom: room.kind == RoomKind.boss,
      ),
  ];

  List<Altar> _altars() {
    final altars = <Altar>[];
    for (final room in layout.rooms) {
      if (room.role == DeadEndRole.altar) {
        altars.add(
          Altar._(
            id: ids.altar(altars.length),
            room: ids.room(room.index),
            position: spotIn(room, SpotKind.feature),
          ),
        );
      }
    }
    return altars;
  }

  List<DriftingPlatform> _platforms() {
    final platforms = <DriftingPlatform>[];
    for (final room in layout.rooms) {
      for (final path in room.template.drifts) {
        platforms.add(
          DriftingPlatform._(
            id: ids.platform(platforms.length),
            origin: room.originOn(_grid),
            path: path,
            // The sandbox's zoneBuild: ((room × 37 + platforms × 11) % 100) / 100.
            phase: ((room.index * 37 + platforms.length * 11) % 100) / 100,
          ),
        );
      }
    }
    return platforms;
  }
}

// The entities of one zone, made once, and the buffers the root reuses.
final class _Parts {
  _Parts(this.rooms, this.altars, this.platforms)
    : platformBoxes = [for (final platform in platforms) platform._box];

  final List<Room> rooms;
  final List<Altar> altars;
  final List<DriftingPlatform> platforms;
  final List<WorldBox> platformBoxes;
  final List<HookSpot> ringBuffer = [];
}
```

```dart
/// A generated zone (glossary §6): its rooms, altars, drifting platforms,
/// the boss room's doors and its solid world. Every change goes through
/// this root.
final class Zone {
  factory Zone.of({
    required ZoneNumber number,
    required BiomeKit kit,
    required Seed seed,
    required ZoneLayout layout,
  }) {
    final assembly = _Assembly(layout, ZoneIds(number), kit, seed);
    return Zone._(assembly, assembly.parts());
  }

  Zone._(_Assembly assembly, _Parts parts)
    : number = assembly.ids.zone,
      biome = assembly.kit.biome,
      boss = assembly.kit.boss,
      seed = assembly.seed,
      bounds = assembly.layout.grid.bounds,
      start = assembly.spotIn(
        assembly.roomOf(RoomKind.start),
        SpotKind.start,
      ),
      wayDown = assembly.spotIn(
        assembly.roomOf(RoomKind.wayDown),
        SpotKind.wayDown,
      ),
      bossRoom = assembly.ids.room(assembly.roomOf(RoomKind.boss).index),
      spirits = List.unmodifiable(assembly.spirits()),
      rooms = List.unmodifiable([for (final room in parts.rooms) room._view]),
      platforms = UnmodifiableListView(parts.platformBoxes),
      _bossRoomBounds = assembly
          .roomOf(RoomKind.boss)
          .boundsOn(assembly.layout.grid),
      _geometry = ZoneGeometry.of(assembly.layout, assembly.ids),
      _rooms = parts.rooms,
      _altars = parts.altars,
      _altarViews = List.unmodifiable([
        for (final altar in parts.altars) altar._view(),
      ]),
      _platforms = parts.platforms,
      _platformBoxes = parts.platformBoxes,
      _ringBuffer = parts.ringBuffer,
      _rings = UnmodifiableListView(parts.ringBuffer);

  /// items.md §2: within 80 su of its centre (the sandbox's stand-in;
  /// operator, 2026-10-16).
  static const double altarReach = 80;

  final ZoneNumber number;
  final Biome biome;
  final BossId boss;
  final Seed seed;
  final WorldBox bounds;
  final Vec2 start;
  final Vec2 wayDown;
  final EntityId bossRoom;
  final List<SpiritPlace> spirits;
  final List<RoomView> rooms;
  final List<WorldBox> platforms;
  final WorldBox _bossRoomBounds;
  final ZoneGeometry _geometry;
  final List<Room> _rooms;
  final List<Altar> _altars;
  List<AltarView> _altarViews;
  final List<DriftingPlatform> _platforms;
  final List<WorldBox> _platformBoxes;
  final List<HookSpot> _ringBuffer;
  final Iterable<HookSpot> _rings;
  _Doors _doors = _Doors.open;
  int _revision = 0;

  int get revision => _revision;

  List<AltarView> get altars => _altarViews;

  bool get isBossRoomSealed => _doors == _Doors.sealed;

  bool get isWayDownOpen => _doors == _Doors.opened;

  EntityId? roomContaining(Vec2 point) {
    final index = _geometry.roomIndexAt(point);
    return index < 0 ? null : _rooms[index]._id;
  }

  /// The nearest altar within [altarReach] of [point], or null.
  EntityId? altarWithinReach(Vec2 point) {
    Altar? nearest;
    var best = double.infinity;
    for (var i = 0; i < _altars.length; i++) {
      final distance = _altars[i]._position.distanceTo(point);
      if (distance <= altarReach && distance < best) {
        nearest = _altars[i];
        best = distance;
      }
    }
    return nearest?._id;
  }

  AltarGift? giftOn(EntityId altar) => _altar(altar)?._gift;

  /// Takes the gift on [altar]; null when the altar is empty or unknown.
  ItemTakenFromAltar? takeFrom(EntityId altar) {
    final found = _altar(altar);
    final gift = found?._gift;
    if (found == null || gift == null) {
      return null;
    }
    found._gift = null;
    _changed();
    return ItemTakenFromAltar(altar: altar, gift: gift, at: found._position);
  }

  /// Lays [gift] on [altar]; null when the altar holds a gift or is
  /// unknown.
  ItemReturnedToAltar? returnTo(EntityId altar, AltarGift gift) {
    final found = _altar(altar);
    if (found == null || found._gift != null) {
      return null;
    }
    found._gift = gift;
    _changed();
    return ItemReturnedToAltar(altar: altar, gift: gift);
  }

  /// Seals the boss room's doors; null unless they were open.
  BossRoomSealed? sealBossRoom() {
    if (_doors != _Doors.open) {
      return null;
    }
    _doors = _Doors.sealed;
    _changed();
    return BossRoomSealed(room: bossRoom, boss: boss);
  }

  /// Opens the sealed doors for good; null unless they were sealed.
  BossRoomUnsealed? unsealBossRoom() {
    if (_doors != _Doors.sealed) {
      return null;
    }
    _doors = _Doors.opened;
    _changed();
    return BossRoomUnsealed(room: bossRoom, at: _bossRoomBounds.centre);
  }

  void advance(Seconds dt) {
    for (var i = 0; i < _platforms.length; i++) {
      _platforms[i]._advance(dt);
      _platformBoxes[i] = _platforms[i]._box;
    }
  }

  Contact? sweep(WorldBox box, Vec2 displacement) => _earliest(
    const Sweep().box(box, displacement, _geometry.solids),
    const Sweep().box(box, displacement, _platformBoxes),
  );

  Contact? cast(Vec2 from, Vec2 to) => _earliest(
    const Sweep().ray(from, to, _geometry.solids),
    const Sweep().ray(from, to, _platformBoxes),
  );

  bool isSolidAt(Vec2 point) {
    if (_geometry.isSolidAt(point)) {
      return true;
    }
    for (var i = 0; i < _platformBoxes.length; i++) {
      if (_platformBoxes[i].contains(point)) {
        return true;
      }
    }
    return false;
  }

  bool isAbyssAt(Vec2 point) => _geometry.isAbyssAt(point);

  /// The rings within [radius] of [point]; the same view is refilled by
  /// the next call.
  Iterable<HookSpot> ringsNear(Vec2 point, double radius) {
    _ringBuffer.clear();
    _geometry.ringsNear(point, radius, _ringBuffer);
    return _rings;
  }

  static Contact? _earliest(Contact? a, Contact? b) {
    if (a == null) {
      return b;
    }
    return b == null || a.fraction <= b.fraction ? a : b;
  }

  void _changed() {
    _revision++;
    _altarViews = List.unmodifiable([
      for (final altar in _altars) altar._view(),
    ]);
  }

  Altar? _altar(EntityId id) {
    for (var i = 0; i < _altars.length; i++) {
      if (_altars[i]._id == id) {
        return _altars[i];
      }
    }
    return null;
  }
}
```

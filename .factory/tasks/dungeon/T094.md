# T094 — Find where a moving box first meets a solid

## Description

`Sweep`, the domain service that holds the zone's collision rule: where a box moving by a
displacement first meets any of a list of solid boxes (each solid grown by the box's half sizes,
then the box's centre swept through it), and the same for a ray. Its answer is a `Contact`:
- the point where the box's centre stops;
- the normal of the face met;
- the fraction of the move done.

A solid the box already overlaps is passed through (operator, 2026-10-16), so a body never sticks
inside one.

## Constraints

- Stateless and allocation-free but for the `Contact` it returns; indexed loops
  (architecture §6.1).
- `Contact` is a value object, as T089's `Constraints` say.

```dart
// lib/features/dungeon/domain/contact.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';

/// Where a moving box or a ray first met a solid.
final class Contact {
  const Contact({
    required this.point,
    required this.normal,
    required this.fraction,
  }) : assert(fraction >= 0 && fraction <= 1, 'a contact lies on the move');

  final Vec2 point;
  final Vec2 normal;
  final double fraction;

  @override
  bool operator ==(Object other) =>
      other is Contact &&
      other.point == point &&
      other.normal == normal &&
      other.fraction == fraction;

  @override
  int get hashCode => Object.hash(point, normal, fraction);
}
```

```dart
// lib/features/dungeon/domain/sweep.dart — new
import 'dart:math' as math;

import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/features/dungeon/domain/contact.dart';

/// Where a moving box first meets a solid: its centre swept through each
/// solid grown by the box's half sizes.
final class Sweep {
  const Sweep();

  /// The earliest contact of [box] moved by [displacement] with any of
  /// [solids]: where its centre stops, the face it meets and the fraction
  /// of the move done. A solid [box] already overlaps is passed through.
  Contact? box(WorldBox box, Vec2 displacement, List<WorldBox> solids) {
    Contact? first;
    for (var i = 0; i < solids.length; i++) {
      final solid = solids[i];
      if (solid.overlaps(box)) {
        continue;
      }
      final contact = _enter(box.centre, displacement, solid, box);
      if (contact != null &&
          (first == null || contact.fraction < first.fraction)) {
        first = contact;
      }
    }
    return first;
  }

  /// The earliest contact of the ray from [from] to [to] with [solids].
  Contact? ray(Vec2 from, Vec2 to, List<WorldBox> solids) => box(
    WorldBox(centre: from, halfWidth: 0, halfHeight: 0),
    to - from,
    solids,
  );

  Contact? _enter(Vec2 origin, Vec2 move, WorldBox solid, WorldBox box) {
    final left = solid.left - box.halfWidth;
    final right = solid.right + box.halfWidth;
    final top = solid.top - box.halfHeight;
    final bottom = solid.bottom + box.halfHeight;
    final enterX = _entry(origin.x, move.x, left, right);
    final enterY = _entry(origin.y, move.y, top, bottom);
    final enter = math.max(enterX, enterY);
    final exit = math.min(
      _exit(origin.x, move.x, left, right),
      _exit(origin.y, move.y, top, bottom),
    );
    if (enter > exit || enter < 0 || enter > 1) {
      return null;
    }
    return Contact(
      point: origin + move.scaled(enter),
      normal: enterX > enterY
          ? Vec2(move.x > 0 ? -1 : 1, 0)
          : Vec2(0, move.y > 0 ? -1 : 1),
      fraction: enter,
    );
  }

  static double _entry(double origin, double move, double low, double high) {
    if (move == 0) {
      return origin > low && origin < high
          ? double.negativeInfinity
          : double.infinity;
    }
    return math.min((low - origin) / move, (high - origin) / move);
  }

  static double _exit(double origin, double move, double low, double high) {
    if (move == 0) {
      return origin > low && origin < high
          ? double.infinity
          : double.negativeInfinity;
    }
    return math.max((low - origin) / move, (high - origin) / move);
  }
}
```

## Acceptance criteria

The box is `WorldBox(centre: Vec2(100, 0), halfWidth: 10, halfHeight: 20)`; the floor is
`WorldBox(centre: Vec2(100, 60), halfWidth: 200, halfHeight: 10)` (top 50).

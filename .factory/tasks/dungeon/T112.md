# T112 — Test Akeris's presence through a generated zone

## Description

Dungeon's presence and its platforms tested with the loop (testing.md §7), against a generated zone
rather than a hand-built one. The test builds, all real:
- a `GameLoop` over an `EventQueue`, stepping `StepZone`;
- an `InMemoryZoneRepository`, `SeededZoneGenerator(kits: [SuspendedSanctuaryKit()])`,
  `PresenceInZone`, `BossRoomDoors` and `ZoneCollisionWorld`.

Akeris is stood in for by positions fed to `movedTo`, one per frame, and a box laid on a platform.
Nothing is mocked; only what is on `main` and dungeon's own tasks are used (operator, 2026-10-17).

## Preconditions

- On `main`: `EventQueue`, `StepClock`, `GameLoop`.
- On `feat/dungeon`: T110, T142.

## Acceptance criteria

A frame is `movedTo(p)` then `loop.advance(Seconds(1 / 60))`; a `GameEvent` handler records
`published`. The zone is `generate(ZoneNumber.first, Seed(42))`; `b` is its boss room's bounds.

| Test file | Test name | Assertion |
|---|---|---|
| `test/integration/dungeon_presence_test.dart` | walking the main path reports each room once | Frames at the bottom centre of each main-path room, in path order, then the start again: one `RoomEntered` per main-path room, ids in path order, and one more for the return to the start (one per change of room). |
| `test/integration/dungeon_presence_test.dart` | entering the boss room seals it and autosaves | A frame at `Vec2(b.left + 290, b.bottom - 1)` delivers `BossRoomEntered(boss: BossId.golem)` and `SoundEffectCued(sfx.bossDoor.seal)`; the next `StepZone.state.isBossRoomSealed` is true (`boss-room.md` Z12). |
| `test/integration/dungeon_presence_test.dart` | after the boss the way down starts the next zone | After the seal, `BossRoomDoors.unseal()` and a frame at `state.wayDown`: one `WayDownReached(zone: ZoneNumber.first)`; ten more frames there add none (`layout.md` Z9). |
| `test/integration/dungeon_presence_test.dart` | a drifting platform carries what stands on it | In the first zone of seeds 1–10 with a platform, a box standing on a platform's top: after one frame, `carry(box)` is that platform's displacement over the frame (`hazards.md`). |

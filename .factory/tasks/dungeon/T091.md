# T091 — Model a zone's layout as values

## Description

What one attempt of the builder produces, before the `Zone` is assembled from it:
- each placed room (its template as placed, mirrored or not; its cell; its depth from the start;
  the room it grew from; whether it is on the main path; a dead end's role; the passages that
  lead somewhere);
- the links between rooms (`layout.md` §B.2: side passages only);
- the layout itself, with the grid it was laid on.

A dead end's role is the lore spirit, an altar or a lookout (§B.2 step 5).

## Preconditions

- T089's values are on `feat/dungeon`.

## Constraints

- Value objects, as T089's `Constraints` say. `DeadEndRole` is a plain enum with no tests of its
  own.

```dart
// lib/features/dungeon/domain/placed_room.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/features/dungeon/domain/dead_end_role.dart';
import 'package:saviors_paradox/features/dungeon/domain/edges_box.dart';
import 'package:saviors_paradox/features/dungeon/domain/passage.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_kind.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_template.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone_grid.dart';

/// A room as one attempt placed it on the grid; its template is already
/// mirrored when it was placed mirrored.
final class PlacedRoom {
  PlacedRoom({
    required this.index,
    required this.template,
    required this.column,
    required this.row,
    required this.depth,
    required this.from,
    required this.isOnMainPath,
    required this.role,
    required List<Passage> linked,
  }) : assert(index >= 0 && depth >= 0, 'a room has a place in the zone'),
       linked = List.unmodifiable(linked);

  final int index;
  final RoomTemplate template;
  final int column;
  final int row;
  final int depth;
  final int? from;
  final bool isOnMainPath;
  final DeadEndRole? role;
  final List<Passage> linked;

  RoomKind get kind => template.kind;

  Vec2 originOn(ZoneGrid grid) =>
      Vec2(column * grid.cellWidth, row * grid.cellHeight);

  WorldBox boundsOn(ZoneGrid grid) {
    final origin = originOn(grid);
    return edgesBox(
      origin.x,
      origin.y,
      origin.x + template.widthOn(grid),
      origin.y + template.heightOn(grid),
    );
  }

  bool isLinkedAt(Passage passage) => linked.contains(passage);

  @override
  bool operator ==(Object other) =>
      other is PlacedRoom &&
      other.index == index &&
      other.template == template &&
      other.column == column &&
      other.row == row &&
      other.depth == depth &&
      other.from == from &&
      other.isOnMainPath == isOnMainPath &&
      other.role == role &&
      _samePassages(other.linked, linked);

  @override
  int get hashCode => Object.hash(
    index,
    template,
    column,
    row,
    depth,
    from,
    isOnMainPath,
    role,
    Object.hashAll(linked),
  );
}

bool _samePassages(List<Passage> a, List<Passage> b) {
  if (a.length != b.length) {
    return false;
  }
  for (var i = 0; i < a.length; i++) {
    if (a[i] != b[i]) {
      return false;
    }
  }
  return true;
}
```

```dart
// lib/features/dungeon/domain/zone_layout.dart — new
import 'package:saviors_paradox/features/dungeon/domain/placed_room.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_link.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone_grid.dart';

/// The rooms of one attempt and the passages between them.
final class ZoneLayout {
  ZoneLayout({
    required this.grid,
    required List<PlacedRoom> rooms,
    required List<RoomLink> links,
  }) : rooms = List.unmodifiable(rooms),
       links = List.unmodifiable(links);

  final ZoneGrid grid;
  final List<PlacedRoom> rooms;
  final List<RoomLink> links;

  /// The rooms a passage joins to room [index], in the order linked.
  List<int> neighboursOf(int index) => [
    for (final link in links)
      if (link.from == index)
        link.to
      else if (link.to == index)
        link.from,
  ];

  @override
  bool operator ==(Object other) =>
      other is ZoneLayout &&
      other.grid == grid &&
      _same(other.rooms, rooms) &&
      _same(other.links, links);

  @override
  int get hashCode =>
      Object.hash(grid, Object.hashAll(rooms), Object.hashAll(links));
}

bool _same<T>(List<T> a, List<T> b) {
  if (a.length != b.length) {
    return false;
  }
  for (var i = 0; i < a.length; i++) {
    if (a[i] != b[i]) {
      return false;
    }
  }
  return true;
}
```

## Acceptance criteria

Rooms use templates built in the test from T089's values: a 2 × 1 template for the bounds test
and a 1 × 1 template elsewhere.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/dungeon/domain/placed_room_test.dart` | a room stands where its cell is | A 2 × 1 room placed at column 3, row 2 on `ZoneGrid.standard` has its origin at (4800, 2048) and its bounds running to (8000, 3072) (`04-zones/zone-1-suspended-sanctuary/layout.md` §B.1). |
| `test/features/dungeon/domain/placed_room_test.dart` | a room knows the passages that lead somewhere | With `linked: [Passage(side: right, row: 0)]`, `isLinkedAt` is true for it and false for `Passage(side: left, row: 0)`. |
| `test/features/dungeon/domain/placed_room_test.dart` | placed rooms are equal by value | Two rooms built from equal values are equal with equal hash codes; a different `depth` makes them unequal; `linked` cannot be changed (`UnsupportedError`). |
| `test/features/dungeon/domain/room_link_test.dart` | links are equal by value | `RoomLink(from: 0, to: 1, side: right, row: 2)` equals another with the same values, and not one with `row: 3`. |
| `test/features/dungeon/domain/zone_layout_test.dart` | a room's neighbours are the rooms its links join | With links 0→1 and 1→2, `neighboursOf(1)` is `[0, 2]`, `neighboursOf(0)` is `[1]` and `neighboursOf(2)` is `[1]`. |
| `test/features/dungeon/domain/zone_layout_test.dart` | layouts are equal by value | Two layouts with equal rooms and links are equal with equal hash codes; dropping a link makes them unequal. |

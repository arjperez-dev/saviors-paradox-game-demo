# T141 — Take the item from an altar within reach

## Description

Step (iii) of three (planner wave-05 `altars-sink-expand-contract`) and architect change-04's
`ports-altars` note. The sink becomes required, and `takeWithin` becomes real:
- it finds the altar within 80 su of the point (`Zone.altarWithinReach`, T097) and takes its gift
  (`Zone.takeFrom`);
- it saves the zone;
- it publishes `ItemTaken(altar, item)`, then `SoundEffectCued(sfx.item.take)` at the altar;
- it returns the item.

An empty altar, or none in reach, gives null and publishes nothing. inventory and arsenal learn the
item from `ItemTaken` (architect change-04).

## Preconditions

- T140 is on `feat/dungeon`: no caller still uses `ZoneAltars(zones)`.

## Constraints

- No rule and no state; one aggregate per call.

## Implementation

```dart
// lib/features/dungeon/application/zone_altars.dart — replaced whole
import 'package:saviors_paradox/core/contracts/events/item_taken.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_cued.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/altars.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/core/contracts/state/altar_item.dart';
import 'package:saviors_paradox/features/dungeon/application/ports/zone_repository.dart';
import 'package:saviors_paradox/features/dungeon/application/zone_reading.dart';

/// Lays an item back on its altar, and gives what an altar in reach
/// holds to whoever takes it.
final class ZoneAltars implements Altars {
  ZoneAltars(this._zones, this._events);

  /// 07-audio/sfx/sfx.md: the item flies into his hand.
  static const SoundEffectId taken = SoundEffectId('sfx.item.take');

  final ZoneRepository _zones;
  final EventSink _events;

  @override
  void returnTo(EntityId altar, AltarItem item) {
    final zone = _zones.load();
    if (zone == null) {
      return;
    }
    zone.returnTo(altar, readGift(item));
    _zones.save(zone);
  }

  @override
  AltarItem? takeWithin(Vec2 point) {
    final zone = _zones.load();
    final altar = zone?.altarWithinReach(point);
    if (zone == null || altar == null) {
      return null;
    }
    final took = zone.takeFrom(altar);
    if (took == null) {
      return null;
    }
    _zones.save(zone);
    final item = writeAltarItem(took.gift);
    _events
      ..publish(ItemTaken(altar: took.altar, item: item))
      ..publish(SoundEffectCued(sound: taken, at: took.at));
    return item;
  }
}
```

# T100 — Read the zone into the contracts

## Description

Dungeon's anti-corruption layer (architecture §2.2), as functions:
- a `Zone` becomes the `ZoneState` snapshot (`spawns` stays empty until the enemy mix arrives in
  a later dungeon wave);
- an `AltarItem` becomes an `AltarGift`, and back;
- a `HookSpot` becomes a ring `HookPoint`;
- a `Contact` becomes a `CollisionHit`.

## Preconditions

- T097's `Zone` and its views, and T098's `ZoneFactory`, are on `feat/dungeon`.

## Constraints

- Functions, not types; the exhaustive `switch`es over the sealed gifts and items have no
  `default`.

## Implementation

```dart
// lib/features/dungeon/application/zone_reading.dart — new
import 'package:saviors_paradox/core/contracts/ports/collision_hit.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point_kind.dart';
import 'package:saviors_paradox/core/contracts/state/altar_item.dart';
import 'package:saviors_paradox/core/contracts/state/altar_snapshot.dart';
import 'package:saviors_paradox/core/contracts/state/room_snapshot.dart';
import 'package:saviors_paradox/core/contracts/state/spirit_snapshot.dart';
import 'package:saviors_paradox/core/contracts/state/zone_state.dart';
import 'package:saviors_paradox/features/dungeon/domain/altar_gift.dart';
import 'package:saviors_paradox/features/dungeon/domain/contact.dart';
import 'package:saviors_paradox/features/dungeon/domain/hook_spot.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone.dart';

// Dungeon's anti-corruption layer (architecture.md §2.2).

ZoneState readZoneState(Zone zone) => ZoneState(
  zone: zone.number,
  biome: zone.biome,
  seed: zone.seed,
  bounds: zone.bounds,
  rooms: [
    for (final room in zone.rooms)
      RoomSnapshot(
        room: room.room,
        bounds: room.bounds,
        neighbours: room.neighbours,
        isOnMainPath: room.isOnMainPath,
        isBossRoom: room.isBossRoom,
      ),
  ],
  spawns: const [], // the enemy mix comes with a later dungeon wave
  altars: [
    for (final altar in zone.altars)
      AltarSnapshot(
        altar: altar.altar,
        room: altar.room,
        position: altar.position,
        item: _itemOf(altar.gift),
      ),
  ],
  spirits: [
    for (final spirit in zone.spirits)
      SpiritSnapshot(
        spirit: spirit.spirit,
        role: spirit.role,
        room: spirit.room,
        position: spirit.position,
      ),
  ],
  start: zone.start,
  wayDown: zone.wayDown,
  bossRoom: zone.bossRoom,
  isBossRoomSealed: zone.isBossRoomSealed,
);

AltarGift readGift(AltarItem item) => switch (item) {
  AltarWeapon(:final weapon) => WeaponGift(weapon),
  AltarShield(:final shield) => ShieldGift(shield),
  AltarScroll(:final scroll) => ScrollGift(scroll),
};

AltarItem writeAltarItem(AltarGift gift) => switch (gift) {
  WeaponGift(:final weapon) => AltarWeapon(weapon: weapon),
  ShieldGift(:final shield) => AltarShield(shield: shield),
  ScrollGift(:final scroll) => AltarScroll(scroll: scroll),
};

HookPoint readHookPoint(HookSpot spot) =>
    HookPoint(id: spot.id, kind: HookPointKind.ring, position: spot.position);

CollisionHit readContact(Contact contact) => CollisionHit(
  point: contact.point,
  normal: contact.normal,
  fraction: contact.fraction,
);

AltarItem? _itemOf(AltarGift? gift) =>
    gift == null ? null : writeAltarItem(gift);
```

## Acceptance criteria

"The zone" is the zone of `Seed(1)` from `const ZoneFactory().create(ZoneNumber.first,
SuspendedSanctuaryKit(), Seed(1))`.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/dungeon/application/zone_reading_test.dart` | reads a zone into its state | `readZoneState(zone)` has zone 1, `suspendedSanctuary`, the zone's seed and bounds. Each room snapshot has the room id, bounds, neighbours and flags of the matching `RoomView`. `spawns` is empty; there are 8 altars with `item` null; the spirits are `[lore, warning]` with their rooms and positions; and `start`, `wayDown`, `bossRoom` and `isBossRoomSealed` false are as the zone's. |
| `test/features/dungeon/application/zone_reading_test.dart` | reads a sealed zone as sealed | After `zone.sealBossRoom()`, `readZoneState(zone).isBossRoomSealed` is true. |
| `test/features/dungeon/application/zone_reading_test.dart` | reads an altar's gift into its item | After `zone.returnTo(altar, ScrollGift(cursed))`, that altar's snapshot `item` is an `AltarScroll` with `scroll: cursed`. |
| `test/features/dungeon/application/zone_reading_test.dart` | reads each altar item into a gift and back | `readGift` of `AltarWeapon(weapon: hammer)`, `AltarShield(shield: fire)` and `AltarScroll(scroll: health)` gives `WeaponGift(hammer)`, `ShieldGift(fire)` and `ScrollGift(health)`, and `writeAltarItem` of each gives back an item of the same subtype and value. |
| `test/features/dungeon/application/zone_reading_test.dart` | reads a ring into a hook point | `readHookPoint(HookSpot(id: EntityId(1001000), position: Vec2(2680, 2408)))` has that id and position and kind `ring`. |
| `test/features/dungeon/application/zone_reading_test.dart` | reads a contact into a collision hit | `readContact(Contact(point: Vec2(1, 2), normal: Vec2(0, -1), fraction: 0.5))` has that point, normal and fraction. |

# T110 — Tell the zone where Akeris stands

## Description

`PresenceInZone`, the use case behind the `ZonePresence` contract, replacing its stub. akeris calls
`movedTo` once per step with his feet (architect change-04). It loads the zone and asks the root the
three questions of T109. It saves the zone, then turns each domain event into what other contexts
hear:

- `AkerisEnteredRoom` → `RoomEntered(room)`.
- `BossRoomSealed` → `BossRoomEntered(boss)`, then `SoundEffectCued(sfx.bossDoor.seal, at: his
  feet)`. `boss-room.md`: the doors seal and the game autosaves, which is `save`'s, hearing
  `BossRoomEntered`.
- `AkerisReachedWayDown` → `WayDownReached(zone)`.

The order is room, then seal, then way down, so a step that does more than one reports them in the
order they happened.

## Preconditions

- On `main`, `presence_in_zone.dart` is a stub: `final class PresenceInZone implements
  ZonePresence` with an empty `movedTo` and no constructor arguments.
- T109 is on `feat/dungeon`.

## Constraints

- No rule and no state; one aggregate per call (checklist A15).
- Nothing allocates on a step that changes nothing (architecture §6.1): only an event that happened
  is built.

## Implementation

```dart
// lib/features/dungeon/application/presence_in_zone.dart — replaced whole
import 'package:saviors_paradox/core/contracts/events/boss_room_entered.dart';
import 'package:saviors_paradox/core/contracts/events/room_entered.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_cued.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_id.dart';
import 'package:saviors_paradox/core/contracts/events/way_down_reached.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/core/contracts/ports/zone_presence.dart';
import 'package:saviors_paradox/features/dungeon/application/ports/zone_repository.dart';

/// Hears where Akeris stands each step, and tells the game what that
/// changed in the zone.
final class PresenceInZone implements ZonePresence {
  PresenceInZone(this._zones, this._events);

  /// 07-audio/sfx/sfx.md: the bars slam and the padlock shuts.
  static const SoundEffectId sealed = SoundEffectId('sfx.bossDoor.seal');

  final ZoneRepository _zones;
  final EventSink _events;

  @override
  void movedTo(Vec2 position) {
    final zone = _zones.load();
    if (zone == null) {
      return;
    }
    final entered = zone.enterRoomAt(position);
    final doors = zone.sealAround(position);
    final wayDown = zone.reachWayDownAt(position);
    _zones.save(zone);
    if (entered != null) {
      _events.publish(RoomEntered(room: entered.room));
    }
    if (doors != null) {
      _events
        ..publish(BossRoomEntered(boss: doors.boss))
        ..publish(SoundEffectCued(sound: sealed, at: position));
    }
    if (wayDown != null) {
      _events.publish(WayDownReached(zone: wayDown.zone));
    }
  }
}
```

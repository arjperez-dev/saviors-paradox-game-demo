# T090 — List the Suspended Sanctuary's room catalog

## Description

`BiomeKit`, the abstract factory a zone is built from (design-patterns §10): a biome's grid, its
room templates by kind, the fixed order of its main path, the kinds a branch is drawn from, its
room count and altar count, and its boss. `SuspendedSanctuaryKit` is zone 1's kit:
- the 15 templates of `layout.md` §B.3, copied value for value from the sandbox's `ZT` (the
  sandbox's `I(x0, x1, y, t, u)` is an `IslandSpan(left, right, top, thickness, underside)`);
- the main path of §B.2 step 2;
- branch kinds as the sandbox's `pick(['corr', 'corr', 'combat', 'shaft'])`;
- 36–44 rooms and 8 altars (`ZONE_TARGET`, `ZONE_ALTARS`);
- the Golem as its boss.

The other four biomes' kits come in later dungeon waves.

## Preconditions

- T089's values are on `feat/dungeon`.

## Constraints

- The kit is a flyweight built once: its templates are made in its constructor and shared,
  never copied (design-patterns §4).
- The catalog is a data table, exempt from the line counts (coding-standards §3).
- Every number comes from the sandbox's `ZT`, `MAIN_PLAN` and `ZONE_TARGET`.

// lib/features/dungeon/domain/biome_kit.dart — new
import 'package:saviors_paradox/core/contracts/kernel/biome.dart';
import 'package:saviors_paradox/core/contracts/kernel/boss_id.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_kind.dart';
import 'package:saviors_paradox/features/dungeon/domain/room_template.dart';
import 'package:saviors_paradox/features/dungeon/domain/zone_grid.dart';

/// The family a biome's zones are built from (design-patterns.md §10):
/// one implementation per biome.
abstract interface class BiomeKit {
  /// The biome this kit builds.
  Biome get biome;

  /// The boss that closes the biome's zone.
  BossId get boss;

  /// The grid its zones are laid on.
  ZoneGrid get grid;

  /// The kinds of the main path after the start, in their fixed order.
  List<RoomKind> get mainPath;

  /// The kinds a branch room is drawn from, repeated by their weight.
  List<RoomKind> get branchKinds;

  /// The fewest rooms a zone of this biome holds.
  int get fewestRooms;

  /// The most rooms a zone of this biome holds.
  int get mostRooms;

  /// The altars a zone of this biome holds.
  int get altarCount;

  /// The templates of [kind]; empty for a kind the biome never uses.
  List<RoomTemplate> templatesOf(RoomKind kind);
}

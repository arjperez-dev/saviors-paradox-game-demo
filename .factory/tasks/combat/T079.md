# T079 — Keep the projectiles in flight

## Description

The repository of the `Flights` aggregate (architecture §4, A14): the port in
`application/ports/` and the in-memory implementation in `infrastructure/`. It loads and saves
the whole aggregate.

## Preconditions

- T078's `Flights` is on `feat/combat`.

## Constraints

- Its one mutable field is the aggregate it holds, assigned by `save`.

## Interfaces

| File | Symbol | Role | Building block | Signature |
|---|---|---|---|---|

| `lib/features/combat/infrastructure/in_memory_flights_repository.dart` | `InMemoryFlightsRepository` | exports | repository | `InMemoryFlightsRepository([Flights? flights])` |

## Implementation

```dart
// lib/features/combat/application/ports/flights_repository.dart — new
import 'package:saviors_paradox/features/combat/domain/flights.dart';

/// Where the projectiles in the air are kept.
abstract interface class FlightsRepository {
  /// The projectiles in the air, whole.
  Flights load();

  /// Keeps [flights] as the projectiles in the air.
  void save(Flights flights);
}
```

```dart
// lib/features/combat/infrastructure/in_memory_flights_repository.dart — new
import 'package:saviors_paradox/features/combat/application/ports/flights_repository.dart';
import 'package:saviors_paradox/features/combat/domain/flights.dart';

/// The projectiles in the air, held in memory for the zone.
final class InMemoryFlightsRepository implements FlightsRepository {
  InMemoryFlightsRepository([Flights? flights]) : _flights = flights ?? Flights();

  Flights _flights;

  @override
  Flights load() => _flights;

  @override
  void save(Flights flights) => _flights = flights;
}
```

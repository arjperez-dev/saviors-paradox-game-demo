# T068 — Judge a raised shield against a strike's element

## Description

Two rules decide how a raised shield meets an attack, and this task gives each one home:
- `ShieldStops` (a specification, design-patterns §12) — whether a shield stops an element. Any
  shield stops a plain attack; only the fire shield stops fire, and only the ice shield ice
  (`elements.md` §1).
- `BlockJudge` (a domain service) — gives a `BlockVerdict`. *Unguarded*: no shield, an unblockable
  attack, or a shield that doesn't stop the element. *Perfect*: the shield was raised for at most
  the perfect window, 0.2 s (operator, 2026-10-16; VISION leaves it to the game). *Blocked*:
  raised longer.

## Preconditions

- T067's `Guard` is on `feat/combat`.

## Constraints

- `BlockJudge` holds no state; `BlockVerdict` is a plain enum.

## Implementation

```dart
// lib/features/combat/domain/shield_stops.dart — new
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/shield_id.dart';

/// Whether a shield stops an attack of [element] (elements.md §1): any
/// shield stops a plain one, only the fire shield fire, only the ice
/// shield ice.
final class ShieldStops {
  const ShieldStops(this.element);

  final Element element;

  bool isSatisfiedBy(ShieldId shield) => switch (element) {
    Element.plain => true,
    Element.fire => shield == ShieldId.fire,
    Element.ice => shield == ShieldId.ice,
  };
}
```

```dart
// lib/features/combat/domain/block_verdict.dart — new
/// How a raised shield met an attack.
enum BlockVerdict { unguarded, blocked, perfect }
```

```dart
// lib/features/combat/domain/block_judge.dart — new
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/features/combat/domain/block_verdict.dart';
import 'package:saviors_paradox/features/combat/domain/guard.dart';
import 'package:saviors_paradox/features/combat/domain/shield_stops.dart';

/// Decides whether a shield stopped an attack, and whether perfectly.
final class BlockJudge {
  const BlockJudge();

  /// VISION.md §Assumptions leaves it to the game; operator, 2026-10-16.
  static const Seconds perfectWindow = Seconds(0.2);

  BlockVerdict judge({
    required Element element,
    required bool isBlockable,
    required Guard? guard,
  }) {
    if (guard == null ||
        !isBlockable ||
        !ShieldStops(element).isSatisfiedBy(guard.shield)) {
      return BlockVerdict.unguarded;
    }
    return guard.raisedFor <= perfectWindow
        ? BlockVerdict.perfect
        : BlockVerdict.blocked;
  }
}
```

# T081 — Register the bodies an attack can reach

## Description

`CombatantRoster`, combat's implementation of the `CombatantRegistry` contract. It replaces the
stub at the path the combat `CLAUDE.md` fixes. It is not a DDD repository: the bodies it holds
are other features' aggregates, seen through their `Combatant` face, and it adds no rule of its
own (the reach is T070's `Reach`). It sits in `application/` against checklist A14, and the
architect's change-04 note asks for it to move to `infrastructure/` (registry decision).

## Preconditions

- On `main`, `lib/features/combat/application/combatant_roster.dart` is a stub whose four
  methods do nothing.
- T070's `Reach` and T080's `MockCombatant` are on `feat/combat`.

## Constraints

- `near` allocates nothing per call: it refills one buffer behind one `UnmodifiableListView` made
  at construction, valid until the next call (architecture §6.1). No internal list leaves the
  roster mutable.
- Registering an id twice is a programmer error: a `StateError`.

## Implementation

```dart
// lib/features/combat/application/combatant_roster.dart — replaced whole
import 'dart:collection';

import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant_registry.dart';
import 'package:saviors_paradox/features/combat/domain/reach.dart';

/// Every body an attack can reach, as its own feature registered it.
final class CombatantRoster implements CombatantRegistry {
  CombatantRoster() : this._(<Combatant>[]);

  CombatantRoster._(List<Combatant> near)
    : _near = near,
      _nearView = UnmodifiableListView(near);

  final List<Combatant> _combatants = [];
  final List<Combatant> _near;
  final UnmodifiableListView<Combatant> _nearView;

  @override
  void register(Combatant combatant) {
    if (_indexOf(combatant.id) >= 0) {
      throw StateError('combatant ${combatant.id} is registered already');
    }
    _combatants.add(combatant);
  }

  @override
  void unregister(EntityId combatant) {
    final index = _indexOf(combatant);
    if (index >= 0) {
      _combatants.removeAt(index);
    }
  }

  /// The bodies whose hurtbox [radius] reaches from [point], in the order
  /// they registered. The same view is refilled by the next call.
  @override
  Iterable<Combatant> near(Vec2 point, double radius) {
    _near.clear();
    for (var i = 0; i < _combatants.length; i++) {
      final combatant = _combatants[i];
      if (const Reach().reaches(combatant.hurtbox, point, radius)) {
        _near.add(combatant);
      }
    }
    return _nearView;
  }

  @override
  Vec2? positionOf(EntityId combatant) => byId(combatant)?.hurtbox.centre;

  Combatant? byId(EntityId combatant) {
    final index = _indexOf(combatant);
    return index < 0 ? null : _combatants[index];
  }

  int _indexOf(EntityId combatant) {
    for (var i = 0; i < _combatants.length; i++) {
      if (_combatants[i].id == combatant) {
        return i;
      }
    }
    return -1;
  }
}
```

## Acceptance criteria

Each body is a `MockCombatant` stubbed with an `id` and a `hurtbox`.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/combat/application/combatant_roster_test.dart` | finds a registered body near a point | A body with hurtbox centre `Vec2(30, 0)`, half 10 × 10, is in `near(Vec2(0, 0), 20)`. |
| `test/features/combat/application/combatant_roster_test.dart` | leaves out a body out of reach | The same body is not in `near(Vec2(0, 0), 19.9)`. |
| `test/features/combat/application/combatant_roster_test.dart` | lists the bodies in the order they registered | Bodies `EntityId(3)`, `EntityId(1)` and `EntityId(2)`, registered in that order and all in reach, give ids `[3, 1, 2]`. |
| `test/features/combat/application/combatant_roster_test.dart` | forgets an unregistered body | After `unregister(EntityId(3))`, `near` no longer lists it and `byId(EntityId(3))` is null. |
| `test/features/combat/application/combatant_roster_test.dart` | unregistering an unknown body changes nothing | `unregister(EntityId(99))` leaves the two registered bodies in `near`. |
| `test/features/combat/application/combatant_roster_test.dart` | refuses a body registered twice | Registering a second body with the id `EntityId(3)` throws a `StateError`. |
| `test/features/combat/application/combatant_roster_test.dart` | gives a body's position as its hurtbox centre | `positionOf(EntityId(3))` is its hurtbox's centre; `positionOf(EntityId(99))` is null. |
| `test/features/combat/application/combatant_roster_test.dart` | finds a body by its id | `byId(EntityId(1))` is the same mock that was registered. |

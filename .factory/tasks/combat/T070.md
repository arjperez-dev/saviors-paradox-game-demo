# T070 — Tell whether a point reaches a body's box

## Description

The one home of combat's reach rule: a circle around a point reaches a body when the hurtbox
point nearest it lies within the radius. Both the roster's `near` and a projectile's contact use
it.

## Constraints

- Stateless and allocation-free: it is called for every body in the per-frame path
  (architecture §6.1).

## Implementation

```dart
// lib/features/combat/domain/reach.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';

/// Whether a circle reaches a box: the box's point nearest [point] lies
/// within [radius] of it.
final class Reach {
  const Reach();

  bool reaches(WorldBox box, Vec2 point, double radius) {
    final dx = _outside(point.x, box.left, box.right);
    final dy = _outside(point.y, box.top, box.bottom);
    return dx * dx + dy * dy <= radius * radius;
  }

  static double _outside(double value, double low, double high) {
    if (value < low) {
      return low - value;
    }
    return value > high ? value - high : 0;
  }
}
```

## Acceptance criteria

All three tests use `WorldBox(centre: Vec2(0, 0), halfWidth: 10, halfHeight: 20)`.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/combat/domain/reach_test.dart` | a point inside the box reaches it at no radius | `reaches(box, Vec2(5, -15), 0)` is true. |
| `test/features/combat/domain/reach_test.dart` | a point beside the box reaches it only within the radius | From `Vec2(20, 0)`: radius 10 reaches, radius 9.99 does not. |
| `test/features/combat/domain/reach_test.dart` | a point off a corner is measured to the corner | From `Vec2(13, 24)`: radius 5 reaches, radius 4.99 does not. |

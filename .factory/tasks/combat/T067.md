# T067 — Model the values an exchange is made of

## Description

Combat's first value objects (architecture §4):
- `Damage` — health an exchange takes;
- `Immunities` — the elements a body ignores;
- `Guard` — a raised shield as combat sees it;
- `Affliction` — a status effect an exchange inflicts.

`Affliction.byShield` holds the one rule of what a shield does to a body: the ice shield freezes,
or slows an ice-immune body; the fire shield burns, but not a fire-immune body; the sacred shield
inflicts nothing (operator, 2026-10-16; `controls.md` G16; `reflect.md`).

## Constraints

- Every type is a value object: immutable, `final` fields, a `const` constructor wherever it
  compiles (not where an assert reads a `Seconds`). `==` is the same runtime type with every field
  equal, and `hashCode` is `Object.hash` of the fields in declaration order (one field: its own
  `hashCode`).
- A test asserting a value from a reference names that reference in a comment at its `expect`.

## Implementation

```dart
// lib/features/combat/domain/damage.dart — new
/// The health an exchange takes from a body; what the body absorbs is its
/// own loadout's (design-patterns.md §1).
final class Damage {
  const Damage(this.amount) : assert(amount >= 0, 'damage is never negative');

  static const Damage none = Damage(0);

  final double amount;

  bool get isNone => amount == 0;

  @override
  bool operator ==(Object other) => other is Damage && other.amount == amount;

  @override
  int get hashCode => amount.hashCode;
}
```

```dart
// lib/features/combat/domain/immunities.dart — new
import 'package:saviors_paradox/core/contracts/kernel/element.dart';

/// The elements a body is immune to (VISION.md §Mechanics; operator,
/// 2026-10-16: they change only what a shield inflicts).
final class Immunities {
  const Immunities({this.toFire = false, this.toIce = false});

  static const Immunities none = Immunities();

  final bool toFire;
  final bool toIce;

  bool covers(Element element) => switch (element) {
    Element.plain => false,
    Element.fire => toFire,
    Element.ice => toIce,
  };

  @override
  bool operator ==(Object other) =>
      other is Immunities && other.toFire == toFire && other.toIce == toIce;

  @override
  int get hashCode => Object.hash(toFire, toIce);
}
```

```dart
// lib/features/combat/domain/guard.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/shield_id.dart';

/// A defender's raised shield, and how long it has been up.
final class Guard {
  Guard({required this.shield, required this.raisedFor})
    : assert(raisedFor.value >= 0, 'a shield is raised for no negative time');

  final ShieldId shield;
  final Seconds raisedFor;

  @override
  bool operator ==(Object other) =>
      other is Guard && other.shield == shield && other.raisedFor == raisedFor;

  @override
  int get hashCode => Object.hash(shield, raisedFor);
}
```

```dart
// lib/features/combat/domain/affliction.dart — new
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/shield_id.dart';
import 'package:saviors_paradox/core/contracts/ports/status_effect_kind.dart';
import 'package:saviors_paradox/features/combat/domain/immunities.dart';

/// A status effect an exchange inflicts on one body.
final class Affliction {
  Affliction({required this.target, required this.kind, required this.duration})
    : assert(duration.value > 0, 'an affliction lasts some time');

  /// controls.md G16: a perfect block against a melee hit.
  static const Seconds afterPerfectBlock = Seconds(1.5);

  /// reflect.md: a reflected projectile on its thrower.
  static const Seconds afterReflect = Seconds(0.5);

  final EntityId target;
  final StatusEffectKind kind;
  final Seconds duration;

  /// What [shield] inflicts on [target] for [duration]: the ice shield
  /// freezes (slows an ice-immune body), the fire shield burns (nothing on
  /// a fire-immune body), the sacred shield nothing.
  static Affliction? byShield({
    required ShieldId shield,
    required EntityId target,
    required Immunities immunities,
    required Seconds duration,
  }) => switch (shield) {
    ShieldId.sacred => null,
    ShieldId.ice => Affliction(
      target: target,
      kind: immunities.toIce
          ? StatusEffectKind.slowed
          : StatusEffectKind.frozen,
      duration: duration,
    ),
    ShieldId.fire => immunities.toFire
        ? null
        : Affliction(
            target: target,
            kind: StatusEffectKind.burning,
            duration: duration,
          ),
  };

  @override
  bool operator ==(Object other) =>
      other is Affliction &&
      other.target == target &&
      other.kind == kind &&
      other.duration == duration;

  @override
  int get hashCode => Object.hash(target, kind, duration);
}
```

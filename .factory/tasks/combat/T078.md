# T078 — Fly the projectiles from a fixed pool

## Description

`Flights`, the aggregate root of every projectile in the air. It is a pool of 64 `Flight`
entities, made once and reused (design-patterns §8; operator, 2026-10-16).

**Invariants it guards:**
- a flight is spent after 4 s in the air, or on its first contact;
- a launch into a full pool reuses the oldest flight;
- a flight moves only by its own velocity;
- it never meets a body of its side, an invulnerable body, or one its radius does not reach;
- it turns at most once. A perfect block against a reflectable flight sends it back level toward
  its thrower at 1.6× its speed, its 4 s restarted (`reflect.md` §2; operator);
- once turned, it meets only its thrower. It damages the thrower and inflicts, by the reflecting
  shield, frozen, slowed or burning for 0.5 s (`reflect.md`).

**Hitstops:** 0.06 s on Akeris; 0.05 s on another body; 0.05 s for the reflected hit; 0.07 s for a
reflect; 0.05 s for a block (`hit-feedback.md` §2).

**Domain events it records:** `FlightStruck`, `FlightBlocked`, `FlightTurned` and
`FlightCrashed`, each returned by the call that caused it.

## Preconditions

- T067's `Damage`, `Guard`, `Immunities` and `Affliction`; T068's `BlockJudge`; T069's
  `HitstopRule`; T070's `Reach`; T072's `Defender`; and T077's `Missile` / `FlightId` are on
  `feat/combat`.

## Constraints

- **The aggregate boundary.**
  - `Flight` is a `part of 'flights.dart'`: its constructor `Flight._()` and every mutator
    (`_launch`, `_move`, `_turn`, `_spend`) are library-private. Outside code cannot build or
    change one.
  - No method of `Flights` returns, takes or exposes a `Flight`. It answers with a `FlightId`, a
    `FlightTrack` value or a domain event.
  - Every change goes through `launch`, `advance`, `crash` or `meet`. `_slots` never leaves the
    root.
- `Flight` is equal by its `FlightId` alone (checklist A12).
- `advance` and `flyingAt` allocate nothing but the `Vec2` of each move (registry decision: the
  kernel `Vec2` is immutable).
- `FlightTrack` and the events follow T073's `Constraints` (every field in `==`).
- `flight.dart` is a `part` file with no test file of its own; it is tested through
  `flights_test.dart`.

// lib/features/combat/domain/flight.dart — new
part of 'flights.dart';

/// One projectile in the air: an entity of [Flights], reused from its
/// pool and reached only through the root.
final class Flight {
  Flight._();

  FlightId _id = const FlightId(0);
  bool _isFlying = false;
  EntityId _thrower = const EntityId(0);
  EntityId _striker = const EntityId(0);
  CombatantSide _side = CombatantSide.neutral;
  Element _element = Element.plain;
  Vec2 _from = Vec2.zero;
  Vec2 _at = Vec2.zero;
  Vec2 _velocity = Vec2.zero;
  double _radius = 1;
  Damage _damage = Damage.none;
  bool _isReflectable = false;
  ShieldId? _turnedBy;
  Seconds _age = Seconds.zero;

  void _launch(FlightId id, Missile missile) {
    _id = id;
    _isFlying = true;
    _thrower = missile.thrower;
    _striker = missile.thrower;
    _side = missile.side;
    _element = missile.element;
    _from = missile.position;
    _at = missile.position;
    _velocity = missile.velocity;
    _radius = missile.radius;
    _damage = missile.damage;
    _isReflectable = missile.isReflectable;
    _turnedBy = null;
    _age = Seconds.zero;
  }

  void _move(Seconds dt) {
    _from = _at;
    _at = _at + _velocity.scaled(dt.value);
    _age = _age + dt;
    if (_age >= Flights.lifetime) {
      _isFlying = false;
    }
  }

  // reflect.md §2: straight back toward its thrower, level, faster.
  void _turn(Defender reflector, ShieldId shield, Vec2? throwerAt) {
    final towards = throwerAt == null ? -_velocity.x : throwerAt.x - _at.x;
    final speed = _velocity.length * Flights.reflectSpeedFactor;
    _velocity = Vec2(towards < 0 ? -speed : speed, 0);
    _striker = reflector.id;
    _side = reflector.side;
    _turnedBy = shield;
    _age = Seconds.zero;
  }

  void _spend() => _isFlying = false;

  @override
  bool operator ==(Object other) => other is Flight && other._id == _id;

  @override
  int get hashCode => _id.hashCode;
}

// lib/features/combat/domain/flights.dart — new
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';

import 'package:saviors_paradox/core/contracts/ports/combatant_side.dart';
import 'package:saviors_paradox/features/combat/domain/affliction.dart';
import 'package:saviors_paradox/features/combat/domain/block_judge.dart';
import 'package:saviors_paradox/features/combat/domain/block_verdict.dart';
import 'package:saviors_paradox/features/combat/domain/damage.dart';
import 'package:saviors_paradox/features/combat/domain/defender.dart';
import 'package:saviors_paradox/features/combat/domain/flight_event.dart';
import 'package:saviors_paradox/features/combat/domain/flight_id.dart';
import 'package:saviors_paradox/features/combat/domain/flight_track.dart';
import 'package:saviors_paradox/features/combat/domain/hitstop_rule.dart';
import 'package:saviors_paradox/features/combat/domain/missile.dart';
import 'package:saviors_paradox/features/combat/domain/reach.dart';

part 'flight.dart';

/// The projectiles in the air (design-patterns.md §8): a pool of
/// [capacity] flights made once and reused; nothing outside reaches a
/// flight but through this root.
final class Flights {
  Flights()
    : _slots = List<Flight>.generate(
        capacity,
        (_) => Flight._(),
        growable: false,
      );

  /// Operator, 2026-10-16.
  static const int capacity = 64;

  /// Operator, 2026-10-16.
  static const Seconds lifetime = Seconds(4);

  /// reflect.md: "faster"; operator, 2026-10-16.
  static const double reflectSpeedFactor = 1.6;

  final List<Flight> _slots;
  int _nextId = 1;

  int get flyingCount {
    var count = 0;
    for (var i = 0; i < capacity; i++) {
      if (_slots[i]._isFlying) {
        count++;
      }
    }
    return count;
  }

  /// Puts [missile] in the air; when the pool is full, the oldest flight
  /// is reused.
  FlightId launch(Missile missile) {
    final id = FlightId(_nextId++);
    _slots[_freeOrOldest()]._launch(id, missile);
    return id;
  }

  /// Moves every flight by its velocity; one older than [lifetime] is
  /// spent.
  void advance(Seconds dt) {
    for (var i = 0; i < capacity; i++) {
      if (_slots[i]._isFlying) {
        _slots[i]._move(dt);
      }
    }
  }

  /// The flight in [slot], or null when the slot is free.
  FlightId? flyingAt(int slot) {
    final flight = _slots[slot];
    return flight._isFlying ? flight._id : null;
  }

  FlightTrack trackOf(FlightId id) {
    final flight = _flying(id);
    if (flight == null) {
      throw ArgumentError.value(id, 'id', 'no flight of this id is flying');
    }
    return FlightTrack(
      id: id,
      thrower: flight._thrower,
      from: flight._from,
      to: flight._at,
      radius: flight._radius,
    );
  }

  /// Spends the flight where it met the world; null when it is not flying.
  FlightCrashed? crash(FlightId id) {
    final flight = _flying(id);
    if (flight == null) {
      return null;
    }
    flight._spend();
    return FlightCrashed(element: flight._element, at: flight._at);
  }

  /// The flight meets [defender]: it strikes, is blocked or turns back;
  /// null when it is not flying or cannot meet that body.
  FlightEvent? meet(FlightId id, Defender defender, {Vec2? throwerAt}) {
    final flight = _flying(id);
    if (flight == null || !_canMeet(flight, defender)) {
      return null;
    }
    final guard = defender.guard;
    final verdict = const BlockJudge().judge(
      element: flight._element,
      isBlockable: true,
      guard: guard,
    );
    if (guard == null || verdict == BlockVerdict.unguarded) {
      return _struck(flight, defender);
    }
    final isPerfect = verdict == BlockVerdict.perfect;
    if (isPerfect && flight._isReflectable && flight._turnedBy == null) {
      return _turned(flight, defender, guard.shield, throwerAt);
    }
    return _blocked(flight, defender, guard.shield, isPerfect: isPerfect);
  }

  bool _canMeet(Flight flight, Defender defender) =>
      defender.side != flight._side &&
      !defender.isInvulnerable &&
      (flight._turnedBy == null || defender.id == flight._thrower) &&
      const Reach().reaches(defender.hurtbox, flight._at, flight._radius);

  FlightStruck _struck(Flight flight, Defender defender) {
    flight._spend();
    final turnedBy = flight._turnedBy;
    return FlightStruck(
      striker: flight._striker,
      target: defender.id,
      element: flight._element,
      damage: flight._damage,
      at: flight._at,
      hitstop: turnedBy == null
          ? const HitstopRule().onHit(
              target: defender.side,
              kind: AttackKind.projectile,
            )
          : HitstopRule.onReflectedHit,
      affliction: turnedBy == null
          ? null
          : Affliction.byShield(
              shield: turnedBy,
              target: defender.id,
              immunities: defender.immunities,
              duration: Affliction.afterReflect,
            ),
    );
  }

  FlightTurned _turned(
    Flight flight,
    Defender defender,
    ShieldId shield,
    Vec2? throwerAt,
  ) {
    flight._turn(defender, shield, throwerAt);
    return FlightTurned(
      reflector: defender.id,
      thrower: flight._thrower,
      shield: shield,
      at: flight._at,
      hitstop: HitstopRule.onReflect,
    );
  }

  FlightBlocked _blocked(
    Flight flight,
    Defender defender,
    ShieldId shield, {
    required bool isPerfect,
  }) {
    flight._spend();
    return FlightBlocked(
      thrower: flight._striker,
      defender: defender.id,
      element: flight._element,
      shield: shield,
      isPerfect: isPerfect,
      at: flight._at,
      hitstop: HitstopRule.onBlock,
    );
  }

  Flight? _flying(FlightId id) {
    for (var i = 0; i < capacity; i++) {
      final flight = _slots[i];
      if (flight._isFlying && flight._id == id) {
        return flight;
      }
    }
    return null;
  }

  int _freeOrOldest() {
    var oldest = 0;
    for (var i = 0; i < capacity; i++) {
      if (!_slots[i]._isFlying) {
        return i;
      }
      if (_slots[i]._id.value < _slots[oldest]._id.value) {
        oldest = i;
      }
    }
    return oldest;
  }
}

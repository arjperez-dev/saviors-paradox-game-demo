# T114 — Fly projectiles against the combatant registry contract

## Description

The second half of change-04's step 1. `StepFlights` takes `CombatantRegistry` instead of
`CombatantRoster`; it calls only `near` and `positionOf`, both on the contract. The named parameter
keeps its name, `roster`, so `test/integration/combat_exchange_test.dart` compiles unchanged.

## Preconditions

- On `main`, `StepFlights({required FlightsRepository flights, required CombatantRoster roster,
  required CollisionWorld world, required ReportExchange report})` (T087).
- T113's `MockCombatantRegistry` is on `feat/combat`.

## Constraints

- Behaviour unchanged.
- `step_flights.dart` and its test no longer import `combatant_roster.dart`; the test stubs `near`
  and `positionOf` on a `MockCombatantRegistry`, each existing test keeping its name and assertion.

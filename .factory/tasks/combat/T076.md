# T076 — Keep the status effects

## Description

The repository of the `StatusEffects` aggregate (architecture §4, A14): the port in
`application/ports/` and the in-memory implementation in `infrastructure/`. It loads and saves
the whole aggregate.

## Preconditions

- T075's `StatusEffects` is on `feat/combat`.

## Constraints

- Its one mutable field is the aggregate it holds, assigned by `save`; nothing else.

## Interfaces

| File | Symbol | Role | Building block | Signature |
|---|---|---|---|---|
| `lib/features/combat/application/ports/status_effects_repository.dart` | `StatusEffectsRepository` | exports | repository | `StatusEffects load()`, `void save(StatusEffects effects)` |
| `lib/features/combat/infrastructure/in_memory_status_effects_repository.dart` | `InMemoryStatusEffectsRepository` | exports | repository | `InMemoryStatusEffectsRepository([StatusEffects? effects])` |

## Implementation

```dart
// lib/features/combat/application/ports/status_effects_repository.dart — new
import 'package:saviors_paradox/features/combat/domain/status_effects.dart';

/// Where the status effects of every body are kept.
abstract interface class StatusEffectsRepository {
  /// The status effects, whole.
  StatusEffects load();

  /// Keeps [effects] as the status effects of every body.
  void save(StatusEffects effects);
}
```

```dart
// lib/features/combat/infrastructure/in_memory_status_effects_repository.dart — new
import 'package:saviors_paradox/features/combat/application/ports/status_effects_repository.dart';
import 'package:saviors_paradox/features/combat/domain/status_effects.dart';

/// The status effects, held in memory for the zone.
final class InMemoryStatusEffectsRepository implements StatusEffectsRepository {
  InMemoryStatusEffectsRepository([StatusEffects? effects])
    : _effects = effects ?? StatusEffects();

  StatusEffects _effects;

  @override
  StatusEffects load() => _effects;

  @override
  void save(StatusEffects effects) => _effects = effects;
}
```

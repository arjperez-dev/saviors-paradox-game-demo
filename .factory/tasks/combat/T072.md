# T072 — Model a strike reaching its defender

## Description

Combat's own model of the two sides of an exchange (architecture §2.2: the contracts' `Attack`
and `Combatant` are translated in `application/` and never used as the domain):
- `Strike` — one attack: who struck, its side, kind, element, area, damage, knockback, and
  whether it is blockable and lethal;
- `Defender` — a body at the moment it is struck: id, side, hurtbox, its `Guard` if any, whether
  it is invulnerable, and its `Immunities`.

## Preconditions

- T067's `Damage`, `Guard` and `Immunities` are on `feat/combat`.

## Constraints

- Value objects, as T067's `Constraints` say. A named-field constructor is the value object that
  coding-standards §3's four-parameter rule asks for.
- The plain enums `AttackKind` and `CombatantSide` are used as values (operator, 2026-10-16).

## Implementation

```dart
// lib/features/combat/domain/strike.dart — new
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/core/contracts/ports/attack_kind.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant_side.dart';
import 'package:saviors_paradox/features/combat/domain/damage.dart';

/// One attack, as combat resolves it.
final class Strike {
  const Strike({
    required this.attacker,
    required this.side,
    required this.kind,
    required this.element,
    required this.area,
    required this.damage,
    required this.knockback,
    required this.isBlockable,
    required this.isLethal,
  });

  final EntityId attacker;
  final CombatantSide side;
  final AttackKind kind;
  final Element element;
  final WorldBox area;
  final Damage damage;
  final Vec2 knockback;
  final bool isBlockable;
  final bool isLethal;

  @override
  bool operator ==(Object other) =>
      other is Strike &&
      other.attacker == attacker &&
      other.side == side &&
      other.kind == kind &&
      other.element == element &&
      other.area == area &&
      other.damage == damage &&
      other.knockback == knockback &&
      other.isBlockable == isBlockable &&
      other.isLethal == isLethal;

  @override
  int get hashCode => Object.hash(
    attacker,
    side,
    kind,
    element,
    area,
    damage,
    knockback,
    isBlockable,
    isLethal,
  );
}
```

// lib/features/combat/domain/defender.dart — new
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';

import 'package:saviors_paradox/features/combat/domain/guard.dart';
import 'package:saviors_paradox/features/combat/domain/immunities.dart';

/// A body as an exchange meets it.
final class Defender {
  const Defender({
    required this.id,
    required this.side,
    required this.hurtbox,
    required this.guard,
    required this.isInvulnerable,
    this.immunities = Immunities.none,
  });

  final EntityId id;
  final CombatantSide side;
  final WorldBox hurtbox;
  final Guard? guard;
  final bool isInvulnerable;
  final Immunities immunities;

  @override
  bool operator ==(Object other) =>
      other is Defender &&
      other.id == id &&
      other.side == side &&
      other.hurtbox == hurtbox &&
      other.guard == guard &&
      other.isInvulnerable == isInvulnerable &&
      other.immunities == immunities;

  @override
  int get hashCode =>
      Object.hash(id, side, hurtbox, guard, isInvulnerable, immunities);
}

# T086 — Resolve the pending engagements each step

## Description

`StepEngagements`, the system that resolves every pending engagement each world step, oldest
first, and hands what each resolved to `ReportExchange`. It replaces the stub.

## Preconditions

- On `main`, `lib/features/combat/application/step_engagements.dart` is a stub whose `step` does
  nothing.
- T074's repository, T080's mocks and T084's `ReportExchange` are on `feat/combat`.

## Constraints

- No state, and no allocation of its own.
- Tests use a `MockEngagementRepository` whose `next()` answers from a list of real `Engagement`s
  and then null, and a real `ReportExchange` over a `MockEventSink` and a
  `MockStatusEffectControl`.

## Implementation

```dart
// lib/features/combat/application/step_engagements.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/features/combat/application/ports/engagement_repository.dart';
import 'package:saviors_paradox/features/combat/application/report_exchange.dart';

/// Resolves the engagements struck since the last step, oldest first.
final class StepEngagements {
  StepEngagements(this._engagements, this._report);

  final EngagementRepository _engagements;
  final ReportExchange _report;

  void step(Seconds dt) {
    for (
      var engagement = _engagements.next();
      engagement != null;
      engagement = _engagements.next()
    ) {
      final resolved = engagement.resolve();
      if (resolved != null) {
        _report.engagement(resolved);
      }
    }
  }
}
```

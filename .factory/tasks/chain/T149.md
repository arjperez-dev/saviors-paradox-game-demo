# T149 — Describe a throw as a situation the handlers read

## Description

The chain's own words (design-patterns §6), which every handler and the root share:
- `Ring`: a ring's id and where it hangs.
- `ChainHold`: what the chain holds now. `HoldsNothing`; `HoldsRing(ring)`; `HoldsWall(bite, way)`,
  where `way` is how it bit: across a gap, a climbing stretch, or over the top edge.
- `ChainSituation`: what a throw starts from — the shoulder, the aim, whether he is in the air, and
  the hold. `toward` is the aim's side: +1 right, −1 left.
- `ChainAction`: what a throw does. `FlyingAction` is what sends a blade out: `HookRing(ring)`,
  `BiteWall(bite, way)`, `StrikeToward(from, to)`. `StayPut()` sends nothing, and is not a
  `FlyingAction`, so the root's arrival never has to handle it (planner wave-05
  `unreachable-by-type`).
- `ChainActionHandler`: the chain of responsibility's link.
- `ChainWorld`: the domain's port onto the stone and the rings, implemented over `CollisionWorld` in
  `application/`.
- `ChainEvent`: the root's domain events.

The type-only files (`chain_hold.dart`, `chain_action_handler.dart`, `chain_world.dart`,
`chain_event.dart`) get no test of their own (wave-04 `type-only-files-untested`). Their value
types' `==` is exercised where they are used.

## Constraints

- Every value object immutable, `const`, equal by value (checklist A11).

// lib/features/chain/domain/ring.dart — new
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';

/// A ring of the zone the chain can hook.
final class Ring {
  const Ring({required this.id, required this.position});

  final EntityId id;
  final Vec2 position;

  @override
  bool operator ==(Object other) =>
      other is Ring && other.id == id && other.position == position;

  @override
  int get hashCode => Object.hash(id, position);
}

```dart
// lib/features/chain/domain/chain_hold.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/ring.dart';

/// How a blade bit a wall: across a gap (G20), a climbing stretch, or
/// over the top edge (hook-blades.md §3).
enum WallWay { across, stretch, edge }

/// What the chain holds now.
sealed class ChainHold {
  const ChainHold();
}

final class HoldsNothing extends ChainHold {
  const HoldsNothing();

  @override
  bool operator ==(Object other) => other is HoldsNothing;

  @override
  int get hashCode => (HoldsNothing).hashCode;
}

final class HoldsRing extends ChainHold {
  const HoldsRing(this.ring);

  final Ring ring;

  @override
  bool operator ==(Object other) => other is HoldsRing && other.ring == ring;

  @override
  int get hashCode => ring.hashCode;
}

final class HoldsWall extends ChainHold {
  const HoldsWall({required this.bite, required this.way});

  final Vec2 bite;
  final WallWay way;

  @override
  bool operator ==(Object other) =>
      other is HoldsWall && other.bite == bite && other.way == way;

  @override
  int get hashCode => Object.hash(bite, way);
}
```

```dart
// lib/features/chain/domain/chain_situation.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';

/// What a throw starts from: the throwing shoulder, the aim, whether he
/// is in the air, and what the chain holds.
final class ChainSituation {
  const ChainSituation({
    required this.from,
    required this.aim,
    required this.isAirborne,
    required this.hold,
  });

  final Vec2 from;
  final Vec2 aim;
  final bool isAirborne;
  final ChainHold hold;

  /// The aim's side: +1 right, −1 left (akeris always sends a real aim).
  double get toward => aim.x < from.x ? -1 : 1;

  bool get isSwinging => hold is HoldsRing;

  @override
  bool operator ==(Object other) =>
      other is ChainSituation &&
      other.from == from &&
      other.aim == aim &&
      other.isAirborne == isAirborne &&
      other.hold == hold;

  @override
  int get hashCode => Object.hash(from, aim, isAirborne, hold);
}
```

# T151 — Bite a wall across a gap in the air

## Description

Wall to wall (`controls.md` G20; design-patterns §6 step 5). In the air, and not swinging, a wall
across a gap toward the aim bites. The wall must be within 470 su of the shoulder and at least 40 su
from it, at the aim's height clamped from 180 su above the shoulder to 90 below (the sandbox's
`wallAcross`). The bite is where that level line meets the wall's face, and its way is `across`.

`WallAcross` is the domain service that finds that bite. `SwingFromRing` (T152) also asks it, which
is design-patterns §6 step 3. `CrossToWall` is the handler for a wall across with no ring.

## Constraints

- Stateless; constructor-injected `ChainWorld` and `ChainTuning`.

## Implementation

```dart
// lib/features/chain/domain/wall_across.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';

/// Finds a wall across a gap, in the air (controls.md G20; the sandbox's
/// `wallAcross`).
final class WallAcross {
  const WallAcross(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  /// Where the blade would bite a wall across; null on the ground, while
  /// swinging, or with no wall in reach.
  Vec2? biteFor(ChainSituation situation) {
    if (!situation.isAirborne || situation.isSwinging) {
      return null;
    }
    final from = situation.from;
    final height = situation.aim.y.clamp(
      from.y - _tuning.acrossAimAbove,
      from.y + _tuning.acrossAimBelow,
    );
    final start = Vec2(from.x, height);
    final bite = _world.stoneAlong(
      start,
      start + Vec2(situation.toward * _tuning.reach, 0),
    );
    if (bite == null || (bite.x - from.x).abs() < _tuning.acrossGap) {
      return null;
    }
    return bite;
  }
}
```

```dart
// lib/features/chain/domain/cross_to_wall.dart — new
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/wall_across.dart';

/// In the air, a wall across a gap: the blade bites it and pulls him
/// across (controls.md G20; design-patterns.md §6, step 5).
final class CrossToWall implements ChainActionHandler {
  const CrossToWall(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  @override
  ChainAction? tryHandle(ChainSituation situation) {
    final bite = WallAcross(_world, _tuning).biteFor(situation);
    return bite == null ? null : BiteWall(bite: bite, way: WallWay.across);
  }
}
```

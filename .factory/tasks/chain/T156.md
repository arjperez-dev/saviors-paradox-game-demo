# T156 — Keep the chain pair in a repository

## Description

`ChainPair`'s repository (checklist A14): a port in `application/ports/`, held in memory in
`infrastructure/`. There is always one pair in a run. `mocks.dart` gains the mocks of the ports
chain's application calls.

## Implementation

```dart
// lib/features/chain/application/ports/chain_pair_repository.dart — new
import 'package:saviors_paradox/features/chain/domain/chain_pair.dart';

/// Where the run's chain blades are kept.
abstract interface class ChainPairRepository {
  /// The pair, whole.
  ChainPair load();

  /// Keeps [pair] as the run's.
  void save(ChainPair pair);
}
```

```dart
// lib/features/chain/infrastructure/in_memory_chain_pair_repository.dart — new
import 'package:saviors_paradox/features/chain/application/ports/chain_pair_repository.dart';
import 'package:saviors_paradox/features/chain/domain/chain_pair.dart';

/// The run's chain blades, held in memory.
final class InMemoryChainPairRepository implements ChainPairRepository {
  InMemoryChainPairRepository(this._pair);

  ChainPair _pair;

  @override
  ChainPair load() => _pair;

  @override
  void save(ChainPair pair) => _pair = pair;
}
```

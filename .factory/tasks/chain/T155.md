# T155 — Model the pair of hook blades as an aggregate

## Description

`ChainPair`, chain's aggregate root (architecture §2.1). A throw from his shoulder sends one blade
out:
- to a ring in 0.16 s;
- to a wall or as a strike in 0.15 s (`hook-blades.md` §3).

When it arrives:
- a ring or a wall becomes what the pair holds. Hand over hand, the new hold replaces the old, whose
  blade lets go.
- a strike arrives; the application lands it, and the blade comes back.

Throws alternate hands. `StayPut` sends nothing.

**The strike waits for the release** (`mechanics.md` P2). A click at a ring or a wall acts at once; a
strike flies only on the release, toward the release's aim. So the root keeps the readied strike's
shoulder. The spin held past 0.18 s comes with the fighting.

**`letGo`** brings both blades back and holds nothing. Its event is where the blades reel from
(operator, 2026-10-17):
- the bite held: the ring's hook point, or the wall's bite;
- or the target of a blade in flight;
- or the shoulder of a readied strike.

Only a `FlyingAction` can fly, and what arrives is always one, so the arrival is exhaustive with no
impossible case (operator, 2026-10-17).

**Invariants the root guards:**
- At most one blade flies at a time.
- Throws alternate hands.
- The hold changes only when a blade arrives or on `letGo`.
- `revision` rises with every change of hold, so `pull` is rebuilt only then.

**Domain events it records:** `BladeThrown(from, to)`, `RingHooked(ring)`, `WallBitten(bite)`,
`StrikeArrived(from, to)`, `BladesReeled(at)`.

## Constraints

- Mutable fields private; the hold is an immutable value (checklist A7, A11).
- Methods return their event, or null when refused; `advance` adds to a list the caller owns
  (wave-04 `roots-return-their-events`).
- No exception in the domain for an unreachable case: the types exclude it.

## Implementation

```dart
// lib/features/chain/domain/chain_pair.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_event.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';

/// The pair of hook blades, each on its own chain: what flies, what is
/// held, and whose hand throws next. Every change goes through this root.
final class ChainPair {
  ChainPair({ChainTuning tuning = const ChainTuning()}) : _tuning = tuning;

  final ChainTuning _tuning;
  ChainHold _hold = const HoldsNothing();
  FlyingAction? _flying;
  Vec2 _flyingTo = Vec2.zero;
  Seconds _flightLeft = Seconds.zero;
  Vec2? _readiedFrom;
  int _nextHand = 0;
  int _revision = 0;

  ChainHold get hold => _hold;
  int get revision => _revision;
  int get nextHand => _nextHand;
  bool get isFlying => _flying != null;

  /// Sends a blade out from [from] for [action]; a strike waits for the
  /// release (mechanics.md P2). Null when nothing flies.
  BladeThrown? launch(ChainAction action, {required Vec2 from}) {
    if (_flying != null) return null;
    return switch (action) {
      StayPut() => null,
      StrikeToward() => _ready(from),
      HookRing(:final ring) => _fly(
        action,
        from,
        ring.position,
        _tuning.ringFlight,
      ),
      BiteWall(:final bite) => _fly(action, from, bite, _tuning.wallFlight),
    };
  }

  /// The click let go: a readied strike flies toward [aim].
  BladeThrown? release(Vec2 aim) {
    final from = _readiedFrom;
    _readiedFrom = null;
    if (from == null || _flying != null) return null;
    final way = aim - from;
    final length = way.length;
    final to = length == 0
        ? from
        : from + way.scaled(_tuning.strikeRange / length);
    return _fly(
      StrikeToward(from: from, to: to),
      from,
      to,
      _tuning.strikeFlight,
    );
  }

  /// Both blades come back, reeled from where they were; nothing is held.
  BladesReeled? letGo() {
    final at = _reeledFrom();
    if (at == null) return null;
    _hold = const HoldsNothing();
    _flying = null;
    _readiedFrom = null;
    _revision++;
    return BladesReeled(at: at);
  }

  void advance(Seconds dt, List<ChainEvent> into) {
    final flying = _flying;
    if (flying == null) return;
    _flightLeft = _flightLeft - dt;
    if (_flightLeft > Seconds.zero) return;
    _flying = null;
    into.add(_arrive(flying));
  }

  // Where the blades reel from: the bite held, a blade in flight's target,
  // or a readied strike's shoulder; null when neither blade is out.
  Vec2? _reeledFrom() => switch (_hold) {
    HoldsRing(:final ring) => ring.position,
    HoldsWall(:final bite) => bite,
    HoldsNothing() => _flying != null ? _flyingTo : _readiedFrom,
  };

  ChainEvent _arrive(FlyingAction action) => switch (action) {
    HookRing(:final ring) => _holdNow(HoldsRing(ring), RingHooked(ring: ring)),
    BiteWall(:final bite, :final way) => _holdNow(
      HoldsWall(bite: bite, way: way),
      WallBitten(bite: bite),
    ),
    StrikeToward(:final from, :final to) => StrikeArrived(from: from, to: to),
  };

  ChainEvent _holdNow(ChainHold hold, ChainEvent event) {
    _hold = hold;
    _revision++;
    return event;
  }

  BladeThrown? _ready(Vec2 from) {
    _readiedFrom = from;
    return null;
  }

  BladeThrown _fly(FlyingAction action, Vec2 from, Vec2 to, Seconds time) {
    _flying = action;
    _flyingTo = to;
    _flightLeft = time;
    _nextHand = 1 - _nextHand;
    return BladeThrown(from: from, to: to);
  }
}
```

# T154 — Resolve a throw by the first handler that accepts

## Description

`ChainResolver` (design-patterns §6): the first handler that accepts a situation acts; the last
resort always accepts. `ChainResolver.traversal` builds the traversal order §6 fixes from the
approved sandbox's `chainAction` (operator, 2026-10-17): `ClimbWall`, `SwingFromRing`,
`StaySwinging`, `CrossToWall`, `StrikeTowardAim`. The fighting handlers take their place when the
fighting is planned.

## Constraints

- Immutable; the handler list is unmodifiable.

## Implementation

```dart
// lib/features/chain/domain/chain_resolver.dart — new
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/climb_wall.dart';
import 'package:saviors_paradox/features/chain/domain/cross_to_wall.dart';
import 'package:saviors_paradox/features/chain/domain/stay_swinging.dart';
import 'package:saviors_paradox/features/chain/domain/strike_toward_aim.dart';
import 'package:saviors_paradox/features/chain/domain/swing_from_ring.dart';

/// Decides what a throw of the chain blades does: the first handler that
/// accepts (design-patterns.md §6).
final class ChainResolver {
  ChainResolver(List<ChainActionHandler> handlers, this._lastResort)
    : _handlers = List.unmodifiable(handlers);

  /// The traversal order of design-patterns.md §6.
  factory ChainResolver.traversal(ChainWorld world, ChainTuning tuning) =>
      ChainResolver([
        ClimbWall(world, tuning),
        SwingFromRing(world, tuning),
        const StaySwinging(),
        CrossToWall(world, tuning),
      ], StrikeTowardAim(tuning));

  final List<ChainActionHandler> _handlers;
  final ChainActionHandler _lastResort;

  ChainAction resolve(ChainSituation situation) {
    for (final handler in _handlers) {
      final action = handler.tryHandle(situation);
      if (action != null) {
        return action;
      }
    }
    return _lastResort.tryHandle(situation) ?? const StayPut();
  }
}
```

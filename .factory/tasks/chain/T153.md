# T153 — Strike toward the aim when nothing else answers

## Description

`StrikeTowardAim`, the last resort: it always accepts (design-patterns §6, step 6). The blade flies
340 su from the shoulder toward the aim (`hook-blades.md` §3).

## Implementation

```dart
// lib/features/chain/domain/strike_toward_aim.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';

/// The last resort: a ranged strike toward the aim (design-patterns.md
/// §6, step 6; hook-blades.md §3).
final class StrikeTowardAim implements ChainActionHandler {
  const StrikeTowardAim(this._tuning);

  final ChainTuning _tuning;

  @override
  ChainAction tryHandle(ChainSituation situation) {
    final aim = situation.aim - situation.from;
    final length = aim.length;
    final way = length == 0 ? Vec2(situation.toward, 0) : aim.scaled(1 / length);
    return StrikeToward(
      from: situation.from,
      to: situation.from + way.scaled(_tuning.strikeRange),
    );
  }
}
```

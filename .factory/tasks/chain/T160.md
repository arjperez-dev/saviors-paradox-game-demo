# T160 — Answer Akeris's throws as his chain blades

## Description

`ChainPairBlades` replaces its stub. It is the `ChainBlades` port akeris declares and chain
implements (architecture §2.3).
- **`startThrow`:** reads the situation, asks the resolver, and launches what it decides from the
  throw's shoulder. A ring or a wall acts at once; a strike is readied for the release
  (`mechanics.md` P2).
- **`endThrow(aim)`:** flies a readied strike toward the release's aim.
- **`letGo`:** brings both blades back, reeled from the bite held (operator, 2026-10-17).
- **`pull`:** the hold as a `ChainPull`, rebuilt only when the pair's `revision` changes, so akeris
  sees the same instance while nothing changes (planner wave-05, T131's memo).

What the pair raises is reported at once.

## Preconditions

- On `main`, `chain_pair_blades.dart` is a stub with no constructor arguments, `pull` `NoPull()`.

## Constraints

- One aggregate per call; the pull is a memo, not game state.

## Implementation

```dart
// lib/features/chain/application/chain_pair_blades.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_blades.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_pull.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_throw.dart';
import 'package:saviors_paradox/features/chain/application/chain_reading.dart';
import 'package:saviors_paradox/features/chain/application/ports/chain_pair_repository.dart';
import 'package:saviors_paradox/features/chain/application/report_chain.dart';
import 'package:saviors_paradox/features/chain/domain/chain_resolver.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';

/// Akeris's chain blades: his throws, and what they do to his body.
final class ChainPairBlades implements ChainBlades {
  ChainPairBlades({
    required ChainPairRepository pair,
    required ChainResolver resolver,
    required ReportChain report,
    this._tuning = const ChainTuning(),
  }) : _pair = pair, // ignore: prefer_initializing_formals — private
       _resolver = resolver, // ignore: prefer_initializing_formals — ditto
       _report = report; // ignore: prefer_initializing_formals — ditto

  final ChainPairRepository _pair;
  final ChainResolver _resolver;
  final ReportChain _report;
  final ChainTuning _tuning;

  // The pull built for the revision seen last: a memo, not game state.
  int _seen = -1;
  ChainPull _pull = const NoPull();

  @override
  void startThrow(ChainThrow request) {
    final pair = _pair.load();
    final thrown = pair.launch(
      _resolver.resolve(readSituation(request, pair.hold)),
      from: request.from,
    );
    _pair.save(pair);
    if (thrown != null) _report.report(thrown);
  }

  @override
  void endThrow(Vec2 aim) {
    final pair = _pair.load();
    final thrown = pair.release(aim);
    _pair.save(pair);
    if (thrown != null) _report.report(thrown);
  }

  @override
  void letGo() {
    final pair = _pair.load();
    final reeled = pair.letGo();
    _pair.save(pair);
    if (reeled != null) _report.report(reeled);
  }

  @override
  ChainPull get pull {
    final pair = _pair.load();
    if (pair.revision != _seen) {
      _seen = pair.revision;
      _pull = readPull(pair.hold, _tuning);
    }
    return _pull;
  }
}
```

# T152 — Hook the ring a throw reaches

## Description

Design-patterns §6 steps 3 and 4.

**`RingChoice`** picks the ring a throw hooks (the sandbox's `pickRing`, `controls.md` G19). A ring
qualifies when:
- it is within 470 su of the shoulder;
- on the ground it hangs at least 40 su above the shoulder; in the air it may also hang level, or up
  to 90 su below;
- swinging, it is another ring, at least 40 su beyond the one held toward the aim, and the nearest
  wins;
- otherwise it lies within cos 0.8 of the aim, and the lowest `distance × (2.2 − 1.2 cos)` wins.

**`SwingFromRing`** hooks the ring `RingChoice` gives. Not swinging, in the air, with a wall across as
well (`WallAcross`), the aim prefers one: the wall wins when its bite lies closer to the aim's line
than the ring does (the sandbox's `aimPrefersWall`), and the handler then passes. With no ring it
passes.

**`StaySwinging`** handles swinging with no next ring: `StayPut`, nothing happens (step 4).

## Constraints

- Stateless; constructor-injected `ChainWorld` and `ChainTuning`.

## Implementation

```dart
// lib/features/chain/domain/ring_choice.dart — new
import 'dart:math' as math;

import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/ring.dart';

/// Which ring a throw hooks (controls.md G19; the sandbox's `pickRing`).
final class RingChoice {
  const RingChoice(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  Ring? ringFor(ChainSituation situation) {
    Ring? best;
    var bestScore = double.infinity;
    for (final ring in _world.ringsNear(situation.from, _tuning.reach)) {
      final score = _score(ring, situation);
      if (score != null && score < bestScore) {
        best = ring;
        bestScore = score;
      }
    }
    return best;
  }

  // The ring's score; null when it cannot be hooked from here.
  double? _score(Ring ring, ChainSituation situation) {
    final offset = ring.position - situation.from;
    final distance = offset.length;
    final lowest = situation.isAirborne
        ? _tuning.airRingBelow
        : -_tuning.groundRingAbove;
    if (distance > _tuning.reach || offset.y > lowest) {
      return null;
    }
    final hold = situation.hold;
    if (hold is HoldsRing) {
      final beyond = (ring.position.x - hold.ring.position.x) * situation.toward;
      return ring == hold.ring || beyond < _tuning.nextRingBeyond
          ? null
          : distance;
    }
    final aim = situation.aim - situation.from;
    final cos = offset.dot(aim) / math.max(1e-9, distance * aim.length);
    return cos < _tuning.aimCone
        ? null
        : distance * (_tuning.aimScoreBase - _tuning.aimScoreWeight * cos);
  }
}
```

```dart
// lib/features/chain/domain/swing_from_ring.dart — new
import 'dart:math' as math;

import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/ring_choice.dart';
import 'package:saviors_paradox/features/chain/domain/wall_across.dart';

/// Hooks the ring the throw reaches, unless the aim prefers a wall across
/// (design-patterns.md §6, step 3; the sandbox's `aimPrefersWall`).
final class SwingFromRing implements ChainActionHandler {
  const SwingFromRing(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  @override
  ChainAction? tryHandle(ChainSituation situation) {
    final ring = RingChoice(_world, _tuning).ringFor(situation);
    if (ring == null) {
      return null;
    }
    final wall = WallAcross(_world, _tuning).biteFor(situation);
    if (wall != null &&
        _alongAim(situation, wall) > _alongAim(situation, ring.position)) {
      return null;
    }
    return HookRing(ring);
  }

  static double _alongAim(ChainSituation situation, Vec2 point) {
    final aim = situation.aim - situation.from;
    final to = point - situation.from;
    return aim.dot(to) / math.max(1e-9, aim.length * to.length);
  }
}
```

```dart
// lib/features/chain/domain/stay_swinging.dart — new
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';

/// Swinging with no next ring, a click does nothing (design-patterns.md
/// §6, step 4).
final class StaySwinging implements ChainActionHandler {
  const StaySwinging();

  @override
  ChainAction? tryHandle(ChainSituation situation) =>
      situation.isSwinging ? const StayPut() : null;
}
```

# T159 — Report what the chain blades did

## Description

`ReportChain`, the one place chain's domain events become what other contexts hear (architecture
§4).

| Domain event | What it becomes |
|---|---|
| `BladeThrown` | `ChainThrown(from, aim: to)` and `sfx.chain.throw` |
| `RingHooked` | `ChainHooked(kind: ring, at)` and `sfx.chain.hook` |
| `WallBitten` | `ChainHooked(kind: wall, at)` and `sfx.chain.bite` |
| `StrikeArrived` | an `Attack` to `AttackResolver.strike`, then `sfx.chain.back` as the blade returns |
| `BladesReeled` | `sfx.chain.back` |

**The strike's `Attack`:**
- `attacker` `EntityId(100000000)`: chain's strikes carry Akeris's id (`entity_id.dart`).
- side akeris, kind `chain`, element plain.
- `area`: a box over the blade's line, widened 35 su each way (the sandbox's 70 su).
- damage 0.5 (operator, 2026-10-17).
- knockback zero: the chain never pushes back (C1, `hook-blades.md` §6).
- `isBlockable` true: a shield stops it from the front (HB3). `isLethal` false.

## Constraints

- No rule and no state; every sound id `sfx.md`'s.

## Implementation

```dart
// lib/features/chain/application/report_chain.dart — new
import 'package:saviors_paradox/core/contracts/events/chain_hooked.dart';
import 'package:saviors_paradox/core/contracts/events/chain_thrown.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_cued.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/core/contracts/ports/attack.dart';
import 'package:saviors_paradox/core/contracts/ports/attack_kind.dart';
import 'package:saviors_paradox/core/contracts/ports/attack_resolver.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant_side.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point_kind.dart';
import 'package:saviors_paradox/features/chain/domain/chain_event.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';

/// Tells the game what the chain blades did (architecture.md §4).
final class ReportChain {
  ReportChain({
    required EventSink events,
    required AttackResolver attacks,
    this._tuning = const ChainTuning(),
  }) : _events = events, // ignore: prefer_initializing_formals — private
       _attacks = attacks; // ignore: prefer_initializing_formals — ditto

  /// entity_id.dart: chain's strikes carry Akeris's id.
  static const EntityId akeris = EntityId(100000000);

  // 07-audio/sfx/sfx.md, Akeris's chain blades.
  static const SoundEffectId thrown = SoundEffectId('sfx.chain.throw');
  static const SoundEffectId hooked = SoundEffectId('sfx.chain.hook');
  static const SoundEffectId bitten = SoundEffectId('sfx.chain.bite');
  static const SoundEffectId back = SoundEffectId('sfx.chain.back');

  final EventSink _events;
  final AttackResolver _attacks;
  final ChainTuning _tuning;

  void all(List<ChainEvent> events) {
    for (var i = 0; i < events.length; i++) {
      report(events[i]);
    }
  }

  void report(ChainEvent event) {
    switch (event) {
      case BladeThrown(:final from, :final to):
        _events.publish(ChainThrown(from: from, aim: to));
        _cue(thrown, from);
      case RingHooked(:final ring):
        _hooked(HookPointKind.ring, ring.position, hooked);
      case WallBitten(:final bite):
        _hooked(HookPointKind.wall, bite, bitten);
      case StrikeArrived(:final from, :final to):
        _strike(from, to);
      case BladesReeled(:final at):
        _cue(back, at);
    }
  }

  void _hooked(HookPointKind kind, Vec2 at, SoundEffectId sound) {
    _events.publish(ChainHooked(kind: kind, at: at));
    _cue(sound, at);
  }

  // hook-blades.md §6 C1: very low damage, never a push.
  void _strike(Vec2 from, Vec2 to) {
    final half = _tuning.strikeWidth / 2;
    _attacks.strike(
      Attack(
        attacker: akeris,
        side: CombatantSide.akeris,
        kind: AttackKind.chain,
        element: Element.plain,
        area: WorldBox(
          centre: (from + to).scaled(0.5),
          halfWidth: (to.x - from.x).abs() / 2 + half,
          halfHeight: (to.y - from.y).abs() / 2 + half,
        ),
        damage: _tuning.strikeDamage,
        knockback: Vec2.zero,
        isBlockable: true,
        isLethal: false,
      ),
    );
    _cue(back, to);
  }

  void _cue(SoundEffectId sound, Vec2 at) =>
      _events.publish(SoundEffectCued(sound: sound, at: at));
}
```

# T162 — Test a throw hooking a ring of a generated zone

## Description

Chain with the loop and dungeon (testing.md §7), using only what is on `main` and chain's own tasks
(operator, 2026-10-17). Built real:
- `EventQueue`, `GameLoop`;
- dungeon as on `main` (`InMemoryZoneRepository`, `SeededZoneGenerator`, `ZoneCollisionWorld`);
- chain: `InMemoryChainPairRepository`, `WorldForChain`, `ChainResolver.traversal`, `ReportChain`,
  `ChainPairBlades`, `StepChainPair`.

The systems step in the order `StepChainPair`. `AttackResolver` is a `MockAttackResolver`, because
combat's tasks of this wave are on another branch. Akeris is stood in for by the `ChainThrow`s the
test sends.

## Preconditions

- On `main`: `EventQueue`, `GameLoop`, dungeon as wave 4 integrated it.

## Acceptance criteria

The zone is `generate(ZoneNumber.first, Seed(42))`; `ring` is a hook point from
`world.hookPointsNear(state.start, 5000)` with no stone on the line from 200 su below it to it. A
frame is `loop.advance(Seconds(1 / 60))`.

# T161 — Step the blades in flight

## Description

`StepChainPair` replaces its stub: the system that advances the blade in flight by `dt`, saves the
pair and reports what arrived. A hook's arrival changes the hold, and with it `pull`, before akeris
steps: wave 6's order steps chain before akeris (planner wave-05 `wave-6-step-order`). Its event list
is a scratch buffer refilled each step.

## Preconditions

- On `main`, `step_chain_pair.dart` is a stub with an empty `step(Seconds dt)`.

## Implementation

```dart
// lib/features/chain/application/step_chain_pair.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/features/chain/application/ports/chain_pair_repository.dart';
import 'package:saviors_paradox/features/chain/application/report_chain.dart';
import 'package:saviors_paradox/features/chain/domain/chain_event.dart';

/// Advances the chain blades in flight by the world step.
final class StepChainPair {
  StepChainPair(this._pair, this._report);

  final ChainPairRepository _pair;
  final ReportChain _report;

  // A scratch buffer refilled each step: not game state.
  final List<ChainEvent> _arrived = [];

  void step(Seconds dt) {
    final pair = _pair.load()..advance(dt, _arrived);
    _pair.save(pair);
    _report.all(_arrived);
    _arrived.clear();
  }
}
```

# T158 — Translate the chain to and from the contracts

## Description

Chain's anti-corruption layer.

**`readPull`** turns the hold into the `ChainPull` akeris reads:

| Hold | ChainPull |
|---|---|
| nothing | `const NoPull()` |
| a ring | `HangFrom(hookPoint: the ring as a ring HookPoint, length: 210)` |
| a wall bitten across | `PullToward(point: bite)` |
| a stretch, or the edge | `ClimbTo(point: bite)` |

Points are where the blade bit (planner wave-05 `chain-points-are-bites`). akeris re-reads the pull
only when its instance changes, so callers build it once per change of the hold (T160).

**`readSituation`** turns a `ChainThrow` and the hold into a `ChainSituation`.

## Implementation

```dart
// lib/features/chain/application/chain_reading.dart — new
import 'package:saviors_paradox/core/contracts/ports/chain_pull.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_throw.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point_kind.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';

// Chain's anti-corruption layer (architecture.md §2.2).

ChainPull readPull(ChainHold hold, ChainTuning tuning) => switch (hold) {
  HoldsNothing() => const NoPull(),
  HoldsRing(:final ring) => HangFrom(
    hookPoint: HookPoint(
      id: ring.id,
      kind: HookPointKind.ring,
      position: ring.position,
    ),
    length: tuning.swingLength,
  ),
  HoldsWall(:final bite, way: WallWay.across) => PullToward(point: bite),
  HoldsWall(:final bite, way: WallWay.stretch || WallWay.edge) => ClimbTo(
    point: bite,
  ),
};

ChainSituation readSituation(ChainThrow request, ChainHold hold) =>
    ChainSituation(
      from: request.from,
      aim: request.aim,
      isAirborne: request.isAirborne,
      hold: hold,
    );
```

# T157 — Read the chain's world from the collision world

## Description

The domain's `ChainWorld`, over dungeon's `CollisionWorld`: chain's anti-corruption layer
(architecture §2.2).
- Rings are the hook points of kind `ring` or `vine` (a vine swings as a ring, VISION.md).
- A line's first stone is the `cast`'s hit point.
- Stone is `isStaticSolidAt` (architect change-05), so a platform is never climbed as a wall.

The ring list is built per throw, never per step.

## Implementation

```dart
// lib/features/chain/application/world_for_chain.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/collision_world.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point_kind.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/ring.dart';

/// The chain's world, read from the zone's collision world.
final class WorldForChain implements ChainWorld {
  const WorldForChain(this._world);

  final CollisionWorld _world;

  @override
  List<Ring> ringsNear(Vec2 point, double radius) => [
    for (final hook in _world.hookPointsNear(point, radius))
      if (hook.kind == HookPointKind.ring || hook.kind == HookPointKind.vine)
        Ring(id: hook.id, position: hook.position),
  ];

  @override
  Vec2? stoneAlong(Vec2 from, Vec2 to) => _world.cast(from, to)?.point;

  @override
  bool isStoneAt(Vec2 point) => _world.isStaticSolidAt(point);
}
```

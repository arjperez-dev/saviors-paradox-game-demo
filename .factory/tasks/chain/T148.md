# T148 — Hold the chain blades' numbers in one tuning value

## Description

Every number of the chain blades, in one immutable value, each with its source. They are the
sandbox's stand-ins, accepted as starting values (operator, 2026-10-17). The strike's damage is 0.5:
VISION.md's "very low", half the sandbox's universal 1 (operator, 2026-10-17). The first climbing
bite is 100 su above the throwing shoulder: the sandbox's 250 above his feet, with his shoulder 150
above them (operator, 2026-10-17). It is chain's own number, so chain needs no body measure of
akeris's.

## Constraints

- `const ChainTuning()` only; equality by type, as `AkerisTuning`.

## Implementation

```dart
// lib/features/chain/domain/chain_tuning.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';

/// The chain blades' numbers: the sandbox's stand-ins, accepted as
/// starting values to tune (operator, 2026-10-17).
final class ChainTuning {
  const ChainTuning();

  // The sandbox's `REACH`: a ring or a wall across within 470 su.
  final double reach = 470;

  // hook-blades.md §3: the ranged strike flies 340 su.
  final double strikeRange = 340;

  // hook-blades.md §3: out tip-first in 0.15–0.16 s (a ring 0.16, the
  // sandbox's `startRingThrow`; a wall or a strike 0.15).
  final Seconds ringFlight = const Seconds(0.16);
  final Seconds wallFlight = const Seconds(0.15);
  final Seconds strikeFlight = const Seconds(0.15);

  // hook-blades.md §3: the swing's chain, reeled in to 210 su.
  final double swingLength = 210;

  // The sandbox's `pickRing` (controls.md G19): on the ground a ring at
  // least 40 su above the shoulder; in the air at most 90 su below it;
  // an aimed ring within cos 0.8 of the aim, scored distance × (2.2 −
  // 1.2 cos); swinging, the next ring 40 su beyond the one held.
  final double groundRingAbove = 40;
  final double airRingBelow = 90;
  final double aimCone = 0.8;
  final double aimScoreBase = 2.2;
  final double aimScoreWeight = 1.2;
  final double nextRingBeyond = 40;

  // The sandbox's `wallAhead`: a wall beside him within 41 su of his
  // shoulder (half his 34 su and 24 more), stone down to 90 su below it.
  final double wallBeside = 41;
  final double wallBesideDown = 90;

  // The first climbing bite 100 su above the shoulder: the sandbox's
  // `startWallStab` bites 250 above his feet, his shoulder 150 above them
  // (contract.md §2); each later bite 50 above the one held; a bite within
  // 50 su of the top catches over the edge (operator, 2026-10-17).
  final double firstBiteAbove = 100;
  final double nextBiteAbove = 50;
  final double edgeWithin = 50;

  // The sandbox's `wallAcross` (G20): a wall across at least 40 su away,
  // at the aim's height clamped 180 su above to 90 below the shoulder.
  final double acrossGap = 40;
  final double acrossAimAbove = 180;
  final double acrossAimBelow = 90;

  // VISION.md: very low damage, half the sandbox's 1 (operator,
  // 2026-10-17); the sandbox's `startStrike` reaches 70 su from the line.
  final double strikeDamage = 0.5;
  final double strikeWidth = 70;

  @override
  bool operator ==(Object other) => other is ChainTuning;

  @override
  int get hashCode => (ChainTuning).hashCode;
}
```

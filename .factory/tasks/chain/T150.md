# T150 — Bite the wall beside Akeris to climb it

## Description

`ClimbWall`, the first handler of design-patterns §6's traversal order (steps 1 and 2).

- **Hanging from a wall** (`HoldsWall`): the click climbs on. The new bite is 50 su above the one
  held, on its face.
- **Beside a wall, not swinging:** stone within 41 su of his shoulder toward the aim, and at 90 su
  below it (the sandbox's `wallAhead`). The first bite is 100 su above the shoulder on the wall's
  face, whatever the aim's height (the sandbox's `startWallStab` ignores the mouse; operator,
  2026-10-17).

A bite within 50 su of the wall's top catches over the edge. The bite is then on the top, where a
line cast down just inside the face meets stone, and its way is `edge`. Otherwise its way is
`stretch`.

`WallBeside` is the domain service that finds the wall's face from the shoulder; both its uses are
here.

## Constraints

- Stateless; each takes `ChainWorld` and `ChainTuning` through its constructor.

## Implementation

```dart
// lib/features/chain/domain/wall_beside.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';

/// Finds the wall beside Akeris (the sandbox's `wallAhead`).
final class WallBeside {
  const WallBeside(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  /// The x of the wall's face beside [shoulder] on the side [toward];
  /// null when stone does not stand there from his shoulder down.
  double? faceFrom(Vec2 shoulder, double toward) {
    final reach = Vec2(toward * _tuning.wallBeside, 0);
    final high = _world.stoneAlong(shoulder, shoulder + reach);
    final low = shoulder + Vec2(0, _tuning.wallBesideDown);
    if (high == null || _world.stoneAlong(low, low + reach) == null) {
      return null;
    }
    return high.x;
  }
}
```

```dart
// lib/features/chain/domain/climb_wall.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action.dart';
import 'package:saviors_paradox/features/chain/domain/chain_action_handler.dart';
import 'package:saviors_paradox/features/chain/domain/chain_hold.dart';
import 'package:saviors_paradox/features/chain/domain/chain_situation.dart';
import 'package:saviors_paradox/features/chain/domain/chain_tuning.dart';
import 'package:saviors_paradox/features/chain/domain/chain_world.dart';
import 'package:saviors_paradox/features/chain/domain/wall_beside.dart';

/// Climbs a wall on the chain: on from a bite held, or the first bite on
/// the wall beside him (design-patterns.md §6, steps 1–2; the sandbox's
/// `startWallStab`).
final class ClimbWall implements ChainActionHandler {
  const ClimbWall(this._world, this._tuning);

  final ChainWorld _world;
  final ChainTuning _tuning;

  @override
  ChainAction? tryHandle(ChainSituation situation) {
    final hold = situation.hold;
    if (hold is HoldsWall) {
      final side = hold.bite.x < situation.from.x ? -1.0 : 1.0;
      return _bite(
        Vec2(hold.bite.x, hold.bite.y - _tuning.nextBiteAbove),
        side,
      );
    }
    if (situation.isSwinging) {
      return null;
    }
    final face = WallBeside(
      _world,
      _tuning,
    ).faceFrom(situation.from, situation.toward);
    return face == null
        ? null
        : _bite(
            Vec2(face, situation.from.y - _tuning.firstBiteAbove),
            situation.toward,
          );
  }

  // A bite near the top catches over the edge, on the top itself.
  BiteWall _bite(Vec2 at, double side) {
    final inside = at.x + side;
    final above = Vec2(inside, at.y - _tuning.edgeWithin);
    if (_world.isStoneAt(above)) {
      return BiteWall(bite: at, way: WallWay.stretch);
    }
    final top = _world.stoneAlong(above, Vec2(inside, at.y + _tuning.edgeWithin));
    return top == null
        ? BiteWall(bite: at, way: WallWay.stretch)
        : BiteWall(bite: Vec2(at.x, top.y), way: WallWay.edge);
  }
}
```

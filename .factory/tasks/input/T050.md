# T050 — Test commands flowing from raw input through the loop

## Description

The first test across `input` → `loop` that T037 promised: the real `EventQueue`, `StepClock` and
`GameLoop` with `drain: input.drainInto`, a real `TranslateInput` over `InputContexts` with the real
`MenuContext` and `PlayingContext`, a world system counting its steps, and a handler on the queue
recording every `PlayerCommand`. Raw inputs are received between frames and the loop is advanced
with a fixed `dt` of 1/60 s. Only the world camera, the edge to `core/rendering`, is a
`mocktail` double, declared in this file.

## Preconditions

- `EventQueue`, `StepClock` and `GameLoop` with `drain` of `core/loop` are on `main` (T005–T008,
  T034–T036).
- T046's `PlayingContext`, T047's `MenuContext` and T048's `TranslateInput` on `feat/input`.

# T045 — Keep the stack of input contexts

## Description

The input contexts of design-patterns.md §5. `InputContext` is what a context implements — `core/input`'s
playing and menu contexts now, `map`'s and `narrative`'s later in their `presentation/` — translating
one raw input into commands; `InputReading` is what it may read while it does: which keys and
buttons are held, the pointer, its world point and how long it has been still. `InputContexts` is
the stack: the menu at the bottom, playing while a run lasts, and on top one context per standing
halt, the one registered for its `HaltCause` or the menu when none is. Halts stand in the order
raised; a resume removes its cause wherever it stands; a repeated halt and an unmatched resume
change nothing, as in `core/loop`'s `WorldHalts`. The two interfaces have no test file of their
own: they hold no behaviour, and this task's test exercises them through mocks.
`test/core/input/mocks.dart` holds every mock the module's tests use.

```dart
// lib/core/input/application/input_contexts.dart — new
import 'package:saviors_paradox/core/contracts/events/halt_cause.dart';
import 'package:saviors_paradox/core/input/application/input_context.dart';

/// The stack of input contexts (design-patterns.md §5): the menu at the
/// bottom, playing while a run lasts, and on top one context per standing
/// halt.
final class InputContexts {
  InputContexts({
    required InputContext menu,
    required InputContext playing,
    Map<HaltCause, InputContext> halts = const {},
  }) : _menu = menu,
       _playing = playing,
       _halts = Map.unmodifiable(halts);

  final InputContext _menu;
  final InputContext _playing;
  final Map<HaltCause, InputContext> _halts;
  final List<HaltCause> _standing = [];
  bool _isRunning = false;

  /// The context that translates input now: the latest standing halt's,
  /// or the menu's when its cause registered none; else playing during a
  /// run; else the menu.
  InputContext get active {
    if (_standing.isNotEmpty) {
      return _halts[_standing.last] ?? _menu;
    }
    return _isRunning ? _playing : _menu;
  }

  void startRun() => _isRunning = true;

  void endRun() => _isRunning = false;

  /// Stacks [cause]; one already standing keeps its place.
  void halt(HaltCause cause) {
    if (!_standing.contains(cause)) {
      _standing.add(cause);
    }
  }

  /// Removes [cause] wherever it stands; nothing when it does not.
  void resume(HaltCause cause) => _standing.remove(cause);
}
```

## Acceptance criteria

| Test file | Test name | Assertion |
|---|---|---|
| `test/core/input/application/input_contexts_test.dart` | starts at the menu context | A new `InputContexts` has the menu context active. |
| `test/core/input/application/input_contexts_test.dart` | a started run makes playing active | After `startRun`, the playing context is active. |
| `test/core/input/application/input_contexts_test.dart` | an ended run returns to the menu | After `startRun` then `endRun`, the menu context is active. |
| `test/core/input/application/input_contexts_test.dart` | a halt makes its registered context active | With a context registered for `HaltCause.map`, during a run, `halt(HaltCause.map)` makes it active. |
| `test/core/input/application/input_contexts_test.dart` | a halt with no context registered makes the menu active | During a run, `halt(HaltCause.pauseMenu)` with nothing registered for it makes the menu context active. |
| `test/core/input/application/input_contexts_test.dart` | the latest standing halt is the active one | With contexts registered for `map` and `dialogue`, halting `map` then `dialogue` makes the dialogue's active. |
| `test/core/input/application/input_contexts_test.dart` | a resume removes its halt wherever it stands | Halting `map` then `dialogue`, resuming `map` leaves the dialogue's active; resuming `dialogue` then returns to playing. |
| `test/core/input/application/input_contexts_test.dart` | a repeated halt changes nothing | Halting `map`, then `dialogue`, then `map` again leaves the dialogue's active; resuming `dialogue` makes the map's active. |
| `test/core/input/application/input_contexts_test.dart` | an unmatched resume changes nothing | During a run with no halt standing, `resume(HaltCause.map)` leaves playing active. |

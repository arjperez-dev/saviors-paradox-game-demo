# T047 — Translate the menu bindings into commands

## Description

The generic menu context (G10, `06-ui/ui.md` §3): W A S D or the arrows move the focus, Enter
chooses, Esc goes back. It serves the title and every screen without a context of its own — the
pause menu, the ability choice (A/D between the two cards, Enter), a cinematic (whose 5 s skip hold
`cinematics` measures from the confirm and escape presses and releases) — and, until `map` and
`narrative` register theirs, the map and the dialogue. Pointing and clicking in a menu (G10) is not
this context's: `core/ui`'s widgets handle the pointer themselves, so here the pointer, its buttons
and the wheel mean nothing. Until `map` registers its context, M does not close the map — the menu
context does not bind M — and only Esc does, as `PressEscape`.

## Preconditions

- T045's `InputContext`, `InputReading` and `test/core/input/mocks.dart` on `feat/input`.

## Constraints

- The key tables are exhaustive `switch` expressions over `InputKey` with no `_` case
  (coding-standards §6.3).

## Implementation

```dart
// lib/core/input/application/menu_context.dart — new
import 'package:saviors_paradox/core/contracts/events/player_command.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/core/input/application/input_context.dart';
import 'package:saviors_paradox/core/input/application/input_reading.dart';
import 'package:saviors_paradox/core/input/domain/input_key.dart';
import 'package:saviors_paradox/core/input/domain/raw_input.dart';

/// What the keys mean in any menu (00-game/controls.md §4, G10): the focus
/// moves, Enter chooses, Esc goes back. The pointer is core/ui's widgets'.
final class MenuContext implements InputContext {
  const MenuContext();

  @override
  void translate(RawInput input, InputReading reading, EventSink commands) {
    final command = switch (input) {
      KeyDown(:final key) => _pressed(key),
      KeyUp(:final key) => _released(key),
      ButtonDown() || ButtonUp() || PointerMoved() || Scrolled() => null,
    };
    if (command != null) {
      commands.publish(command);
    }
  }

  static PlayerCommand? _pressed(InputKey key) => switch (key) {
    InputKey.w || InputKey.arrowUp => const MoveFocus(columns: 0, rows: -1),
    InputKey.s || InputKey.arrowDown => const MoveFocus(columns: 0, rows: 1),
    InputKey.a || InputKey.arrowLeft => const MoveFocus(columns: -1, rows: 0),
    InputKey.d || InputKey.arrowRight => const MoveFocus(columns: 1, rows: 0),
    InputKey.enter => const PressConfirm(),
    InputKey.escape => const PressEscape(),
    InputKey.space ||
    InputKey.shift ||
    InputKey.controlLeft ||
    InputKey.q ||
    InputKey.e ||
    InputKey.r ||
    InputKey.f ||
    InputKey.g ||
    InputKey.h ||
    InputKey.m ||
    InputKey.digit1 ||
    InputKey.digit2 ||
    InputKey.digit3 ||
    InputKey.digit4 ||
    InputKey.digit5 => null,
  };

  static PlayerCommand? _released(InputKey key) => switch (key) {
    InputKey.enter => const ReleaseConfirm(),
    InputKey.escape => const ReleaseEscape(),
    InputKey.a ||
    InputKey.d ||
    InputKey.w ||
    InputKey.s ||
    InputKey.space ||
    InputKey.shift ||
    InputKey.controlLeft ||
    InputKey.q ||
    InputKey.e ||
    InputKey.r ||
    InputKey.f ||
    InputKey.g ||
    InputKey.h ||
    InputKey.m ||
    InputKey.digit1 ||
    InputKey.digit2 ||
    InputKey.digit3 ||
    InputKey.digit4 ||
    InputKey.digit5 ||
    InputKey.arrowUp ||
    InputKey.arrowDown ||
    InputKey.arrowLeft ||
    InputKey.arrowRight => null,
  };
}
```

# T001 — Run the kernel's tests on the declared stack

## Description

Declares the package `saviors_paradox` with the stack of the root `CLAUDE.md`, pinned exactly, and
locks it. Then it gives the test runner its first suite: the shared kernel the architect wrote. Every
kernel type that has behaviour gets a test file. The enumerations and `EntityId` carry no behaviour
and get none. `flutter test` fails on a tree with no test files, and every later task runs it.

## Constraints

- No file under `lib/` changes. A kernel test that fails against the contract as written is a stop
  with `needs: architect`, never an edit of the contract.
- No `assets:` or `fonts:` in the manifest yet: a declared folder that does not exist fails the build.
  Later tasks add them through `shared_file_notes`.
- `pubspec.lock` is generated by `flutter pub get`, never written by hand.

## Implementation

```text
# pubspec.lock — generated: run `flutter pub get` at the repository root, then commit the file it writes.
```

Each kernel test file imports `package:flutter_test/flutter_test.dart` and the kernel file it tests,
and holds one `group` named for the type under test.

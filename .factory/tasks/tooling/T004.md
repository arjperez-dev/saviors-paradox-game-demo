# T004 — Generate the Windows runner

## Description

The native Windows runner that `run_command` and `build_command` need. It is Flutter's own template,
generated rather than written. Two edits put the game's name on the window and the executable;
the binary keeps the package name.

## Constraints

- Generate in a temporary directory outside the repository and copy only `windows/`. `flutter
  create` run inside the repository would also write `lib/main.dart`, `test/`, `README.md` and
  `.metadata`, none of which is this task's.

## Implementation

```text
# 1. Outside the repository:
flutter create --platforms=windows --org dev.arjperez --project-name saviors_paradox <temp-dir>
# 2. Copy <temp-dir>/windows/ to windows/ at the repository root.
# 3. At the repository root, `flutter pub get`, which writes the three windows/flutter/generated_* files
#    for flutter_soloud, path_provider and window_manager.
```

```cpp
// windows/runner/main.cpp — edited
// before:  if (!window.Create(L"saviors_paradox", origin, size)) {
// after:   if (!window.Create(L"Savior's Paradox", origin, size)) {
```

```text
// windows/runner/Runner.rc — edited
// before:  VALUE "FileDescription", "saviors_paradox" "\0"
// after:   VALUE "FileDescription", "Savior's Paradox" "\0"
// before:  VALUE "ProductName", "saviors_paradox" "\0"
// after:   VALUE "ProductName", "Savior's Paradox" "\0"
```

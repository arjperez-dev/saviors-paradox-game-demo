# T003 — Boot the game in a fullscreen Flame window

## Description

The entry point and the composition root's first two files (architecture §1, `core/app/`). The
game opens fullscreen, as `VISION.md` §Target platform asks, on an empty Flame game. That game is
what later waves wire the loop and the features into, through `shared_file_notes`. It holds no
system yet, so the analyzer and the build see every contract and stub reached from a real entry point.

## Constraints

- `lib/core/app/` imports no feature and no shared module yet: nothing of them is on `main`.
- No player-visible string in Dart: the window title belongs to the native runner (T004).

## Implementation

```dart
// lib/main.dart — new
import 'package:saviors_paradox/core/app/bootstrap.dart';

Future<void> main() => bootstrap();
```

```dart
// lib/core/app/bootstrap.dart — new
import 'package:flame/game.dart';
import 'package:flutter/widgets.dart';
import 'package:saviors_paradox/core/app/saviors_paradox_game.dart';
import 'package:window_manager/window_manager.dart';

/// Opens the window fullscreen and runs the game (VISION.md §Target platform).
Future<void> bootstrap() async {
  WidgetsFlutterBinding.ensureInitialized();
  await windowManager.ensureInitialized();
  await windowManager.waitUntilReadyToShow(
    const WindowOptions(fullScreen: true),
  );
  await windowManager.show();
  await windowManager.focus();
  runApp(GameWidget(game: SaviorsParadoxGame()));
}
```

# T062 — Press a key by clicking the button that carries its cap

## Description

A button that carries a key cap does exactly what its key does (06-ui/ui.md §3, operator
2026-10-15; coding-standards §11.9): clicking *Resume* [`Esc`] is pressing Esc. `KeyCapButton` is a
56-tall `MenuButton` (every reference's key-cap button: pause and save-slot footers, settings, the
map's *Close*, map.md §3) whose left-button press hands a `KeyDown` of its key to `onInput` and whose
release — or cancel — hands the `KeyUp`; in the composition root `onInput` is
`TranslateInput.receive`, so the active input context gives the key its meaning and the widget never
sees `TranslateInput` (design-patterns §5). A button that goes away while held lets its key go.
`CapKey` is a value object (architecture §4): the key and the name its cap shows, given by the
screen, not translated (dialogue.md §6).

## Preconditions

- T061's `MenuButton`, `ButtonContent`, `ButtonShape`, `ButtonState` on `feat/ui`. On `main`:
  `InputKey` and `RawInput` (`KeyDown`, `KeyUp`) in `core/input/domain/`, and
  `TranslateInput.receive(RawInput)`.

## Constraints

- Only the primary button presses the key; a right click presses nothing.
- The key is released once per press, whichever of up, cancel or dispose comes first.

## Implementation

```dart
// lib/core/ui/presentation/cap_key.dart — new
import 'package:saviors_paradox/core/input/domain/input_key.dart';

/// A key a button carries: the key it presses, and the name its cap shows
/// (`Esc` for [InputKey.escape]), which is the key, not a text
/// (06-ui/dialogue/dialogue.md §6).
final class CapKey {
  const CapKey(this.key, {required this.label})
    : assert(label.length > 0, 'a cap names its key');

  final InputKey key;
  final String label;

  @override
  bool operator ==(Object other) =>
      other is CapKey && other.key == key && other.label == label;

  @override
  int get hashCode => Object.hash(key, label);
}
```

```dart
// lib/core/ui/presentation/key_cap_button.dart — new
import 'package:flutter/gestures.dart';
import 'package:flutter/widgets.dart';
import 'package:saviors_paradox/core/input/domain/raw_input.dart';
import 'package:saviors_paradox/core/ui/presentation/button_content.dart';
import 'package:saviors_paradox/core/ui/presentation/button_shape.dart';
import 'package:saviors_paradox/core/ui/presentation/button_state.dart';
import 'package:saviors_paradox/core/ui/presentation/cap_key.dart';
import 'package:saviors_paradox/core/ui/presentation/menu_button.dart';

/// A button carrying a key cap, which does exactly what its key does:
/// pressing it with the left button presses the key, letting go releases
/// it, handed to core/input as raw input — clicking *Resume* [`Esc`] is
/// pressing Esc (06-ui/ui.md §3; coding-standards.md §11.9).
final class KeyCapButton extends StatefulWidget {
  const KeyCapButton({
    required this.label,
    required this.capKey,
    required this.state,
    required this.onInput,
    super.key,
  });

  final String label;
  final CapKey capKey;
  final ButtonState state;
  final ValueChanged<RawInput> onInput;

  // pmFooter, ttSlots, ttSettings, map.md §3: the button is 56 tall.
  static const ButtonShape shape = ButtonShape(height: 56);

  @override
  State<KeyCapButton> createState() => _KeyCapButtonState();
}

final class _KeyCapButtonState extends State<KeyCapButton> {
  bool _held = false;

  @override
  void dispose() {
    _release();
    super.dispose();
  }

  void _press(PointerDownEvent event) {
    if (_held || event.buttons & kPrimaryButton == 0) {
      return;
    }
    _held = true;
    widget.onInput(KeyDown(widget.capKey.key));
  }

  // A button that goes away while held lets its key go, so nothing stays
  // pressed.
  void _release() {
    if (!_held) {
      return;
    }
    _held = false;
    widget.onInput(KeyUp(widget.capKey.key));
  }

  @override
  Widget build(BuildContext context) => Listener(
    onPointerDown: _press,
    onPointerUp: (_) => _release(),
    onPointerCancel: (_) => _release(),
    child: MenuButton(
      content: ButtonContent(
        label: widget.label,
        keyLabel: widget.capKey.label,
      ),
      shape: KeyCapButton.shape,
      state: widget.state,
    ),
  );
}
```

## Acceptance criteria

`KeyCapButton(label: 'Resume', capKey: CapKey(InputKey.escape, label: 'Esc'), state:
ButtonState(seed: Seed(5)), onInput: inputs.add)` under `Directionality`, `InkTheme` and an
`Align(alignment: Alignment.topLeft)`; mouse gestures start at the button's centre.

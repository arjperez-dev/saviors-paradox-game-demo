# T051 — Scale the UI frame to the screen's height

## Description

The architect's stub of `UiScale` replaced by the real one: a point in the 1920×1080 UI frame (hu)
becomes a screen point by multiplying by screen height ÷ 1080, and back by dividing, with no offset —
on a wider screen only the background grows, and centring a sheet is layout (06-ui/ui.md §3).
`ScreenUiScale` is a value object (architecture §4): immutable, built from the screen's height,
equal by it, refusing a height that is not positive. Hud and map will call it through the
`UiScale` port; the kit reaches it through `InkTheme` (T052).

## Preconditions

- The contract `ports/ui_scale` and the kernel's `UiVec2` (with `referenceHeight` 1080),
  `ScreenVec2` and `Vec2` are on `main`; the stub `lib/core/ui/presentation/screen_ui_scale.dart`
  returns zero for both conversions and nothing builds it yet.

## Constraints

- No offset and no aspect handling: the conversion is a pure scale (architect's
  `ports-ui_scale` decision).

## Implementation

```dart
// lib/core/ui/presentation/screen_ui_scale.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/screen_vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/ui_vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/ui_scale.dart';

/// The UI frame at the screen's size: a point in hu scaled by screen height
/// ÷ 1080, with no offset; centring a sheet is layout (06-ui/ui.md §3).
final class ScreenUiScale implements UiScale {
  const ScreenUiScale({required this.screenHeight})
    : assert(screenHeight > 0, 'a screen has a height');

  /// The screen's height, in logical pixels.
  final double screenHeight;

  /// Logical pixels per hu.
  double get pixelsPerHu => screenHeight / UiVec2.referenceHeight;

  @override
  UiVec2 toUi(ScreenVec2 point) =>
      UiVec2(Vec2(point.x / pixelsPerHu, point.y / pixelsPerHu));

  @override
  ScreenVec2 toScreen(UiVec2 point) =>
      ScreenVec2(Vec2(point.x * pixelsPerHu, point.y * pixelsPerHu));

  @override
  bool operator ==(Object other) =>
      other is ScreenUiScale && other.screenHeight == screenHeight;

  @override
  int get hashCode => screenHeight.hashCode;
}
```

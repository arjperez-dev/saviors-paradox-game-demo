# T065 — Test a key cap click reaching a menu through the loop

## Description

The interface kit tested with the modules it meets, through the real loop: a `KeyCapButton` whose
`onInput` is a real `TranslateInput.receive`, drained by a real `GameLoop` into a real `EventQueue`
through the menu context, publishes exactly what its key does; real keys move a `ConfirmQuestion`'s
focus through a `FocusGroup` held by the test as a screen would hold it; and the kit lays out by the
screen's height through `InkTheme`. `WorldCamera` is the only double, a `mocktail` mock declared in
the test file, as in `test/integration/input_commands_test.dart`.

## Preconditions

- T056's `FocusGroup`, T062's `KeyCapButton` / `CapKey`, T064's `ConfirmQuestion` and T052's
  `InkTheme` on `feat/ui`. On `main`: `EventQueue`, `StepClock`, `GameLoop({queue, clock, systems,
  drain})` with `advance(Seconds)`, `TranslateInput({events, camera, contexts})` with `receive` and
  `drainInto`, `InputContexts`, `MenuContext`, `PlayingContext`.

## Acceptance criteria

Each test builds a real `EventQueue`, a `TranslateInput` over `InputContexts(menu: const
MenuContext(), playing: const PlayingContext())` with a `MockWorldCamera`, a `GameLoop(queue:,
clock: StepClock(), systems: const [], drain: translate.drainInto)`, and a list of the
`PlayerCommand`s the queue publishes; it pumps under `Directionality`, `InkTheme` and an
`Align(alignment: Alignment.topLeft)` with the view at the size named and a device pixel ratio of 1;
a frame is `loop.advance(Seconds(1 / 60))`.

| Test file | Test name | Assertion |
|---|---|---|
| `test/integration/ui_kit_test.dart` | clicking a key cap button publishes what its key does | At 1920×1080 with `KeyCapButton(label: 'Resume', capKey: CapKey(InputKey.escape, label: 'Esc'), state: ButtonState(seed: Seed(31200)), onInput: translate.receive)`: a left-button press and one frame publish exactly `[PressEscape()]`; letting go and one more frame publish `[PressEscape(), ReleaseEscape()]` (`06-ui/ui.md` §3; `00-game/controls.md` §4). |
| `test/integration/ui_kit_test.dart` | the keys move a question's focus through its focus group | With a `FocusGroup([[ConfirmAnswer.yes, ConfirmAnswer.no]])`, the focus at `no` and a `MoveFocus` handler on the queue moving it through the group, receiving `KeyDown(InputKey.a)` and advancing one frame moves it to `yes`; pumped again, the yes button's `state.focused` is true (`00-game/controls.md` §4: A moves left; `06-ui/ui.md` §3). |
| `test/integration/ui_kit_test.dart` | the kit lays out by the screen's height | At 2560×1440 the `ConfirmQuestion` lays out 1066.667 × 386.667 within 1e-3, and the `KeyCapButton` is 74.667 tall within 1e-3 (`06-ui/ui.md` §3: scaled by screen height ÷ 1080). |

# T060 — Fill a pencil ring with the fraction of a hold

## Description

The ring that fills while the player holds to skip (intro.md S4; the cinematics sandbox's
`skipOverlay`): a seeded pencil circle of radius 24, 1.4 wide at .3, and over it a round-capped arc
4.2 wide from the top, clockwise, as long as the fraction its owner gives it — how long the hold
lasts is the owner's (`core/ui/CLAUDE.md`). Dark on paper, light on a dark picture (`RingTone`).
The circle is generated once per seed.

## Preconditions

- T052's `InkTheme` and `InkThemeData` ring constants on `feat/ui`. On `main`:
  `CircleStroke.generate`, `StrokeRandom`, `Pencil.outlineCurve`.

/// The hold ring's ink: dark on paper, light on a dark picture (the

enum RingTone {
  onPaper(InkThemeData.ringOnPaper, InkThemeData.ringBaseOnPaper),
  onDark(InkThemeData.ringOnDark, InkThemeData.ringBaseOnDark);

  const RingTone(this.arc, this.base);

  final Color base;
}

```dart
// lib/core/ui/presentation/hold_ring.dart — new
import 'dart:math' as math;

import 'package:flutter/widgets.dart';
import 'package:saviors_paradox/core/contracts/kernel/seed.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/circle_stroke.dart';
import 'package:saviors_paradox/core/rendering/domain/stroke_random.dart';
import 'package:saviors_paradox/core/rendering/presentation/pencil.dart';
import 'package:saviors_paradox/core/ui/presentation/ink_theme.dart';
import 'package:saviors_paradox/core/ui/presentation/ink_theme_data.dart';
import 'package:saviors_paradox/core/ui/presentation/ring_tone.dart';

/// A pencil ring that fills clockwise from the top with the [fraction] its
/// owner gives it: how long a hold has lasted (01-story/cinematics/intro.md
/// S4; the cinematics sandbox's `skipOverlay`). How long the hold lasts is
/// the owner's.
final class HoldRing extends StatefulWidget {
  const HoldRing({
    required this.fraction,
    required this.seed,
    this.tone = RingTone.onPaper,
    super.key,
  }) : assert(fraction >= 0 && fraction <= 1, 'a fraction of the hold');

  final double fraction;
  final Seed seed;
  final RingTone tone;

  // skipOverlay: r = 24.
  static const double radius = 24;

  @override
  State<HoldRing> createState() => _HoldRingState();
}

final class _HoldRingState extends State<HoldRing> {
  late CircleStroke _base;

  @override
  void initState() {
    super.initState();
    _base = _generate(widget.seed);
  }

  @override
  void didUpdateWidget(HoldRing oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (widget.seed != oldWidget.seed) {
      _base = _generate(widget.seed);
    }
  }

  static CircleStroke _generate(Seed seed) => CircleStroke.generate(
    const Vec2(HoldRing.radius, HoldRing.radius),
    HoldRing.radius,
    random: StrokeRandom(seed),
  );

  @override
  Widget build(BuildContext context) {
    final theme = InkTheme.of(context);
    return SizedBox.square(
      dimension: theme.pixels(2 * HoldRing.radius),
      child: CustomPaint(
        painter: _HoldRingPainter(
          base: _base,
          fraction: widget.fraction,
          tone: widget.tone,
          pixelsPerHu: theme.pixels(1),
        ),
      ),
    );
  }
}

final class _HoldRingPainter extends CustomPainter {
  _HoldRingPainter({
    required this.base,
    required this.fraction,
    required this.tone,
    required this.pixelsPerHu,
  });

  final CircleStroke base;
  final double fraction;
  final RingTone tone;
  final double pixelsPerHu;
  final Pencil _pencil = Pencil();
  final Paint _arc = Paint()
    ..style = PaintingStyle.stroke
    ..strokeCap = StrokeCap.round
    ..strokeWidth = InkThemeData.ringArcWidth;

  @override
  void paint(Canvas canvas, Size size) {
    canvas
      ..save()
      ..scale(pixelsPerHu);
    _pencil.outlineCurve(
      canvas,
      base.points,
      InkThemeData.ringBaseWidth,
      tone.base,
    );
    if (fraction > 0) {
      _paintArc(canvas);
    }
    canvas.restore();
  }

  /// skipOverlay: from the top, clockwise, round-capped.
  void _paintArc(Canvas canvas) {
    canvas.drawArc(
      Rect.fromCircle(
        center: const Offset(HoldRing.radius, HoldRing.radius),
        radius: HoldRing.radius,
      ),
      -math.pi / 2,
      fraction * 2 * math.pi,
      false,
      _arc..color = tone.arc,
    );
  }

  @override
  bool shouldRepaint(_HoldRingPainter oldDelegate) =>
      !identical(oldDelegate.base, base) ||
      oldDelegate.fraction != fraction ||
      oldDelegate.tone != tone ||
      oldDelegate.pixelsPerHu != pixelsPerHu;
}
```

## Acceptance criteria

Widget tests set the test view to 1920×1080 with a device pixel ratio of 1 and pump the widget under
`Directionality`, `InkTheme` and an `Align(alignment: Alignment.topLeft)`. Paint widths are compared
in single precision; paints are matched with `flutter_test`'s `paints`.

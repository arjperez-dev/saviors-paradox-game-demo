# T014 — Test the callouts in both languages through the translator

## Description

`localization` as the composition root will build it: a `Translator` over the callouts' catalog and a
catalog standing in for a feature's, with the language read from a `SettingsState` snapshot as
`settings` will publish it. Nothing is mocked.

## Interfaces

| File | Symbol | Role | Signature |
|---|---|---|---|
| `lib/core/localization/application/translator.dart` | `Translator` | uses | `Translator({required List<TextCatalog> catalogs, required SettingsState Function() settings})` |
| `lib/core/localization/domain/callout_texts.dart` | `calloutTexts` | uses | `final TextCatalog calloutTexts` |
| `lib/core/localization/domain/callout_texts.dart` | `CalloutKeys` | uses | `abstract final class CalloutKeys` |
| `lib/core/localization/domain/text_catalog.dart` | `TextCatalog` | uses | `TextCatalog(Map<TextKey, LocalizedText> texts)` |

## Acceptance criteria

| Test file | Test name | Assertion |
|---|---|---|
| `test/integration/localization_language_test.dart` | a callout reads in the language the settings hold | `text(CalloutKeys.counter)` gives COUNTER! while the settings snapshot holds `Language.english`, and ¡CONTRA! once it holds `Language.spanish` (`02-art-direction/fx/callouts/callouts.md` §1). |
| `test/integration/localization_language_test.dart` | a feature's texts and the callouts translate side by side | With `calloutTexts` and a catalog holding `ui.hud.rage` → Rage {time} / Furia {time} (06-ui/hud/hud.md §6), in Spanish `format(TextKey('ui.hud.rage'), {'time': '0:12'}) == 'Furia 0:12'` and `text(CalloutKeys.reflect) == '¡FIUU!'`. |

# T010 — Hold one text in each of the game's languages

## Description

Every player-visible string is a key with an English and a Spanish text (06-ui/ui.md §3). This is
that pair, as an immutable value, giving the text of the language asked for.

## Interfaces

| File | Symbol | Role | Signature |
|---|---|---|---|
| `lib/core/localization/domain/localized_text.dart` | `LocalizedText` | exports | `const LocalizedText({required String english, required String spanish})` |
| `lib/core/localization/domain/localized_text.dart` | `LocalizedText.inLanguage` | exports | `String inLanguage(Language language)` |

## Implementation

```dart
// lib/core/localization/domain/localized_text.dart — new
import 'package:saviors_paradox/core/contracts/kernel/language.dart';

/// One text in both languages; neither is a translation of the other
/// (02-art-direction/fx/callouts/callouts.md).
final class LocalizedText {
  const LocalizedText({required this.english, required this.spanish});

  final String english;
  final String spanish;

  String inLanguage(Language language) => switch (language) {
    Language.english => english,
    Language.spanish => spanish,
  };

  @override
  bool operator ==(Object other) =>
      other is LocalizedText &&
      other.english == english &&
      other.spanish == spanish;

  @override
  int get hashCode => Object.hash(english, spanish);
}
```

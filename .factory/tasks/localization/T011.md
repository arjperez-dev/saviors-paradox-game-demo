# T011 — Gather one part of the game's texts by key

## Description

The key is the string each reference writes (`callout.counter`, `ui.hud.health`), as a zero-cost
type. A catalog is the texts one part of the game owns, by key. Each feature that shows text builds
its own catalog from its references' text tables; the translator gathers them all (T012).
`TextKey` has no behaviour and gets no test file.

## Preconditions

- T010's `LocalizedText`, as its `Interfaces` declare.

## Implementation

```dart
// lib/core/localization/domain/text_key.dart — new
/// A player-visible text's key, as its reference writes it:
/// `callout.counter`, `ui.hud.health` (06-ui/ui.md §3).
extension type const TextKey(String value) {}
```

```dart
// lib/core/localization/domain/text_catalog.dart — new
import 'package:saviors_paradox/core/localization/domain/localized_text.dart';
import 'package:saviors_paradox/core/localization/domain/text_key.dart';

/// The texts one part of the game owns, by key.
final class TextCatalog {
  TextCatalog(Map<TextKey, LocalizedText> texts)
    : _texts = Map.unmodifiable(texts);

  final Map<TextKey, LocalizedText> _texts;

  Iterable<MapEntry<TextKey, LocalizedText>> get entries => _texts.entries;

  /// The text of [key], or null when this catalog does not hold it.
  LocalizedText? operator [](TextKey key) => _texts[key];
}
```

# T041 — Name the hand lettering of the game

## Description

The game letters by hand in *Patrick Hand*, bundled under SIL Open Font License (strokes.md §3);
the font and its license have been in `assets/fonts/Patrick_Hand/` since 40b9e2d, but nothing
declares or names them. `Lettering` is the one home of the family's name and of a lettering style,
for `combat`'s callouts, `cinematics`' cards and wave 3's `InkTheme` in `core/ui`. The manifest's
declaration is a shared-file note; it is applied at integration, after `verify-task`, so this task's
test asserts only the names and T043 proves the bundle.

## Implementation

```dart
// lib/core/rendering/presentation/lettering.dart — new
import 'package:flutter/painting.dart';

/// The game's hand lettering (02-art-direction/strokes/strokes.md §3):
/// Patrick Hand, bundled under assets/fonts/ with its SIL Open Font
/// License.
abstract final class Lettering {
  /// The family the manifest declares for the bundled font.
  static const String family = 'Patrick Hand';

  /// The lettering at [size] logical pixels, in [color].
  static TextStyle style({required double size, required Color color}) =>
      TextStyle(fontFamily: family, fontSize: size, color: color);
}
```

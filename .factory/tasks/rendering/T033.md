# T033 — Test the pencil kit from seed to picture

## Description

The kit as a zone and a defeated enemy will use it: geometry generated from a seed, painted into pictures, a dissolve stepped frame by frame with puffs from one pool. Nothing is mocked. The first test with another module comes when a feature draws with the kit (operator, 2026-10-14: option A).

## Acceptance criteria

| Test file | Test name | Assertion |
|---|---|---|
| `test/integration/rendering_kit_test.dart` | the same seed lays and paints the same wall | Two walls (0, 0)–(960, 400) from `Seed(1)` have equal stone outlines, and their recorded pictures report the same `approximateBytesUsed` (`02-art-direction/ART_DIRECTION.md` §2.1). |
| `test/integration/rendering_kit_test.dart` | nothing trembles from one frame to the next | Painting one wall's geometry on 60 successive recordings leaves every stone's outline points equal to those before the first frame (`02-art-direction/ART_DIRECTION.md` §2.1). |
| `test/integration/rendering_kit_test.dart` | two bodies dissolve from one pool and leave nothing behind | Two dissolves from `Seed(1)` and `Seed(2)` share a pool of 60; stepped and painted every 1/60 s for 3.3 s, both are finished and the pool's `activeCount` is 0 (`02-art-direction/fx/ink-smoke/ink-smoke.md` §3). |
| `test/integration/rendering_kit_test.dart` | the paper is painted once for the screen it covers | A 1066.6667 × 600 overlay from `Seed(99)` records into a picture whose `approximateBytesUsed` is greater than 0. |

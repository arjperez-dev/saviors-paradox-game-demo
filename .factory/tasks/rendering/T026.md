# T026 — Dissolve a defeated body into ink smoke

## Description

The dissolve of `ink-smoke.md` §1, for a body of Akeris's size (≈ 200 su): it fills with ink to 0.88 over 0.2 s, 30 seeded holes open from 0.12 to 0.82 s, upper ones first, each growing to a radius of 20–42 over 0.45 s and letting out a puff from the pool, and the body fades from 1 s to 1.3 s. The puffs fade later. The holes are seeded once; only their size and the puffs move. How a larger body or a boss scales the dissolve is settled with the enemies and the bosses (operator, 2026-10-14).

## Preconditions

- T025's `PuffShape` and `InkPuff`, T024's `Pool` and T015's `StrokeRandom`, as their `Interfaces` declare.
- The kit works in sandbox units (su), the unit of every number in `02-art-direction/`; the caller draws its geometry under a scale of k = Akeris's standing height in world units ÷ 192 (`02-art-direction/ART_DIRECTION.md` §3). A `Vec2` here is a point in su, in the drawing's own frame.

## Constraints

- `step` acquires a puff only when a hole opens, and allocates nothing else.

```dart
// lib/core/rendering/domain/smoothstep.dart — new
/// The smooth ease the sandboxes use (`smooth`): 0 up to [u] = 0, 1 from
/// [u] = 1, and 3u² − 2u³ between.
double smoothstep(double u) {
  final t = u.clamp(0.0, 1.0);
  return t * t * (3 - 2 * t);
}
```

```dart
// lib/core/rendering/domain/ink_hole.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/puff_shape.dart';
import 'package:saviors_paradox/core/rendering/domain/smoothstep.dart';
import 'package:saviors_paradox/core/rendering/domain/stroke_random.dart';

/// One hole that opens in a dissolving body, and the puff it lets out
/// (02-art-direction/fx/ink-smoke/ink-smoke.md §1). Its centre is relative
/// to the body's feet, for a body about 200 su tall.
final class InkHole {
  InkHole._({
    required this.centre,
    required this.radius,
    required this.opensAt,
    required this.puff,
  });

  /// Placed over the body: up to 60 su to either side, 10 to 200 su above
  /// the feet. Upper holes open first, with a seeded spread, between 0.12
  /// and 0.82 s (the sandbox's `HOLES_D`).
  factory InkHole.generate(StrokeRandom random) {
    final centre = Vec2(random.signed() * 60, -10 - random.unit() * 190);
    final radius = random.between(20, 42);
    final spread = random.unit();
    return InkHole._(
      centre: centre,
      radius: radius,
      opensAt: Seconds(
        _inkFill * 0.6 +
            (1 + centre.y / 200) * _spread * 0.55 +
            spread * _spread * 0.45,
      ),
      puff: PuffShape.generate(random),
    );
  }

  /// How long a hole takes to reach its full radius.
  static const Seconds growth = Seconds(0.45);

  static const double _inkFill = 0.2;
  static const double _spread = 0.7;

  final Vec2 centre;
  final double radius;
  final Seconds opensAt;
  final PuffShape puff;

  /// Its radius [elapsed] seconds into the dissolve: 0 until it opens.
  double radiusAt(Seconds elapsed) =>
      radius * smoothstep((elapsed - opensAt).value / growth.value);
}
```

```dart
// lib/core/rendering/domain/ink_dissolve.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/seed.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/ink_hole.dart';
import 'package:saviors_paradox/core/rendering/domain/ink_puff.dart';
import 'package:saviors_paradox/core/rendering/domain/pool.dart';
import 'package:saviors_paradox/core/rendering/domain/smoothstep.dart';
import 'package:saviors_paradox/core/rendering/domain/stroke_random.dart';

/// How a defeated body of about 200 su leaves: it fills with ink, holes open
/// in it from the head down, each letting out a puff, and it is gone by
/// 1.3 s (02-art-direction/fx/ink-smoke/ink-smoke.md §1). Its holes are
/// seeded once; only their size and the puffs move.
final class InkDissolve {
  InkDissolve._(List<InkHole> holes, this._pool)
    : holes = List.unmodifiable(holes),
      _puffs = List.filled(holes.length, null),
      _isLaunched = List.filled(holes.length, false);

  factory InkDissolve.prepare({
    required Seed seed,
    required Pool<InkPuff> puffs,
  }) {
    final random = StrokeRandom(seed);
    return InkDissolve._([
      for (var i = 0; i < holeCount; i++) InkHole.generate(random),
    ], puffs);
  }

  static const int holeCount = 30;
  static const Seconds inkFill = Seconds(0.2);
  static const double fullInk = 0.88;
  static const Seconds fadeStart = Seconds(1);
  static const Seconds fadeLength = Seconds(0.3);

  final List<InkHole> holes;
  final Pool<InkPuff> _pool;
  final List<InkPuff?> _puffs;
  final List<bool> _isLaunched;
  Vec2 _feet = Vec2.zero;
  Seconds _elapsed = Seconds.zero;

  Seconds get elapsed => _elapsed;

  /// Where the body stood when it was defeated.
  Vec2 get feet => _feet;

  /// The ink over the body's drawing: 0 to 0.88 over the first 0.2 s.
  double get inkAlpha => fullInk * smoothstep(_elapsed.value / inkFill.value);

  /// What is left of the body fades out from 1 s to 1.3 s.
  double get bodyAlpha =>
      1 - smoothstep((_elapsed - fadeStart).value / fadeLength.value);

  /// Gone, and every puff faded.
  bool get isFinished => bodyAlpha == 0 && !_puffs.any(_isFlying);

  /// The puff of hole [index], while it flies.
  InkPuff? puffAt(int index) => _puffs[index];

  /// Starts the dissolve of a body standing at [feet].
  void start(Vec2 feet) {
    _feet = feet;
    _elapsed = Seconds.zero;
    for (var i = 0; i < holes.length; i++) {
      _land(i);
      _isLaunched[i] = false;
    }
  }

  void step(Seconds dt) {
    _elapsed = _elapsed + dt;
    for (var i = 0; i < holes.length; i++) {
      _launchIfOpen(i);
      _fly(i, dt);
    }
  }

  void _launchIfOpen(int i) {
    if (_isLaunched[i] || _elapsed < holes[i].opensAt) {
      return;
    }
    _isLaunched[i] = true;
    _puffs[i] = _pool.acquire()..launch(_feet + holes[i].centre, holes[i].puff);
  }

  void _fly(int i, Seconds dt) {
    final puff = _puffs[i];
    if (puff == null) {
      return;
    }
    puff.step(dt);
    if (puff.isSpent) {
      _land(i);
    }
  }

  void _land(int i) {
    final puff = _puffs[i];
    if (puff != null) {
      _pool.release(puff);
      _puffs[i] = null;
    }
  }

  static bool _isFlying(InkPuff? puff) => puff != null;
}
```

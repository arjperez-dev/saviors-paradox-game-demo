# T043 — Test the lettering with its bundled font

## Description

T041's manifest notes, proven on `feat/rendering` once applied: the asset bundle holds Patrick Hand
and its license, and text laid out with `Lettering.style` uses it. The font is loaded the way a
widget test must load a real font, with a `FontLoader` over `rootBundle`.

## Preconditions

- T041 integrated on `feat/rendering`: `Lettering` exists and `pubspec.yaml` declares the family
  `Patrick Hand` and the asset `assets/fonts/Patrick_Hand/OFL.txt`.

## Acceptance criteria

| Test file | Test name | Assertion |
|---|---|---|
| `test/integration/rendering_lettering_test.dart` | the bundled Patrick Hand font loads from the asset bundle | `rootBundle.load('assets/fonts/Patrick_Hand/PatrickHand-Regular.ttf')` returns 212112 bytes. |
| `test/integration/rendering_lettering_test.dart` | text in the lettering lays out in Patrick Hand | After a `FontLoader(Lettering.family)` loads that asset, a `TextPainter` laying out `'Akeris'` in `Lettering.style(size: 40, color: Palette.ink)` is not 240 logical pixels wide, the width the test font gives six glyphs at 40 (`02-art-direction/strokes/strokes.md` §3). |
| `test/integration/rendering_lettering_test.dart` | the font's license ships with it | `rootBundle.loadString('assets/fonts/Patrick_Hand/OFL.txt')` contains `SIL OPEN FONT LICENSE`. |

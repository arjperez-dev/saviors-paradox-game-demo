# T025 — Shape a puff of ink smoke once from its seed

## Description

A puff of `ink-smoke.md` §2: an irregular blob of 9 points, radius 7–14 varying 70–115 % (85 % as tall as it is wide, as the sandbox draws it), hatching toward its upper left, one wisp 1.3 wide curling up, a rise of 55–125 su/s and a drift of up to 25 su/s that slow at 3/s and 4/s, and a life of 0.9–1.5 s over which it grows to 2.3× and fades. Its shape is generated once; in flight only its position and size change. A flying puff is a pooled object (T024).

## Preconditions

- T016's `LineStroke`, T019's `Hatching`, T024's `Poolable` and T015's `StrokeRandom`, as their `Interfaces` declare.
- The kit works in sandbox units (su), the unit of every number in `02-art-direction/`; the caller draws its geometry under a scale of k = Akeris's standing height in world units ÷ 192 (`02-art-direction/ART_DIRECTION.md` §3). A `Vec2` here is a point in su, in the drawing's own frame.

## Implementation

```dart
// lib/core/rendering/domain/puff_shape.dart — new
import 'dart:math' as math;

import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/hatching.dart';
import 'package:saviors_paradox/core/rendering/domain/line_stroke.dart';
import 'package:saviors_paradox/core/rendering/domain/stroke_random.dart';

/// What one puff of ink smoke is, generated once from its seed: an irregular
/// blob of 9 points, its hatching toward the upper left, its wisp, and how it
/// moves and lives (02-art-direction/fx/ink-smoke/ink-smoke.md §2). Points
/// are relative to the puff's centre, at its starting radius.
final class PuffShape {
  PuffShape._({
    required this.radius,
    required List<Vec2> outline,
    required this.hatching,
    required this.wisp,
    required this.velocity,
    required this.life,
  }) : outline = List.unmodifiable(outline);

  factory PuffShape.generate(StrokeRandom random) {
    final radius = random.between(7, 14);
    final outline = [
      for (var k = 0; k < pointCount; k++)
        _point(
          k / pointCount * 2 * math.pi,
          radius * random.between(0.7, 1.15),
        ),
    ];
    final side = random.chance(0.5) ? 1.0 : -1.0;
    return PuffShape._(
      radius: radius,
      outline: outline,
      hatching: _hatching(radius, random),
      wisp: LineStroke.generate(
        Vec2(side * radius * 0.4, -radius * 0.6),
        Vec2(side * radius * 1.1, -radius * 1.5),
        width: wispWidth,
        random: random,
      ),
      velocity: Vec2(random.signed() * 25, -random.between(55, 125)),
      life: Seconds(random.between(0.9, 1.5)),
    );
  }

  static const int pointCount = 9;
  static const double wispWidth = 1.3;
  static const double hatchGap = 3;

  final double radius;
  final List<Vec2> outline;

  /// Over the blob shifted toward its upper left; clipped to it when drawn.
  final Hatching hatching;
  final LineStroke wisp;
  final Vec2 velocity;
  final Seconds life;

  /// The blob is 85 % as tall as it is wide.
  static Vec2 _point(double angle, double reach) =>
      Vec2(math.cos(angle) * reach, math.sin(angle) * reach * 0.85);

  static Hatching _hatching(double radius, StrokeRandom random) {
    final shift = Vec2(-radius * 0.15, -radius * 0.2);
    final reach = Vec2(radius * 1.15, radius * 1.15 * 0.85);
    return Hatching.generate(
      topLeft: shift - reach,
      bottomRight: shift + reach,
      gap: hatchGap,
      random: random,
    );
  }
}
```

```dart
// lib/core/rendering/domain/ink_puff.dart — new
import 'dart:math' as math;

import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/pool.dart';
import 'package:saviors_paradox/core/rendering/domain/puff_shape.dart';

/// A puff of ink smoke in flight: it rises, drifts, grows to 2.3× and fades;
/// its shape never changes (02-art-direction/fx/ink-smoke/ink-smoke.md §2).
/// Puffs come from a [Pool].
final class InkPuff implements Poolable {
  Vec2 _position = Vec2.zero;
  Vec2 _velocity = Vec2.zero;
  Seconds _age = Seconds.zero;
  PuffShape? _shape;

  Vec2 get position => _position;

  /// The shape it was launched with; null before its first launch.
  PuffShape? get shape => _shape;

  /// From 0 when it leaves to 1 when it is gone.
  double get progress => switch (_shape) {
    null => 1,
    final shape => math.min(1, _age.value / shape.life.value),
  };

  bool get isSpent => progress >= 1;

  /// How much its radius has grown: from 1 to 2.3.
  double get growth => 1 + 1.3 * progress;

  @override
  void reset() {
    _position = Vec2.zero;
    _velocity = Vec2.zero;
    _age = Seconds.zero;
    _shape = null;
  }

  /// Sends the puff off from [from] with [shape].
  void launch(Vec2 from, PuffShape shape) {
    _position = from;
    _velocity = shape.velocity;
    _age = Seconds.zero;
    _shape = shape;
  }

  /// Moves it, then slows its drift at 4/s and its rise at 3/s.
  void step(Seconds dt) {
    _age = _age + dt;
    _position = _position + _velocity.scaled(dt.value);
    _velocity = Vec2(
      _velocity.x * math.exp(-dt.value * 4),
      _velocity.y * math.exp(-dt.value * 3),
    );
  }
}
```

# T018 — Generate a jittered polygon once from its seed

## Description

The polygon primitive of `strokes.md` §1: each corner moved by at most a jitter between 0.3 and 0.7, generated once, then filled and outlined in ink by the painter. Stones, rubble and props are polygons.

## Preconditions

- T015's `StrokeRandom`, as its `Interfaces` declare.
- The kit works in sandbox units (su), the unit of every number in `02-art-direction/`; the caller draws its geometry under a scale of k = Akeris's standing height in world units ÷ 192 (`02-art-direction/ART_DIRECTION.md` §3). A `Vec2` here is a point in su, in the drawing's own frame.

## Implementation

```dart
// lib/core/rendering/domain/polygon_stroke.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/rendering/domain/stroke_random.dart';

/// A pencil polygon: each corner moved by at most [jitter] on each axis
/// (02-art-direction/strokes/strokes.md §1; the sandbox's `poly`).
final class PolygonStroke {
  PolygonStroke._(List<Vec2> points) : points = List.unmodifiable(points);

  factory PolygonStroke.generate(
    List<Vec2> corners, {
    required StrokeRandom random,
    double jitter = defaultJitter,
  }) => PolygonStroke._([
    for (final corner in corners)
      corner + Vec2(random.signed() * jitter, random.signed() * jitter),
  ]);

  /// The sandbox's `poly` default; strokes.md §1 allows 0.3 to 0.7.
  static const double defaultJitter = 0.3;

  final List<Vec2> points;
}
```

# T118 — Move Akeris on foot and through the air

## Description

The `Akeris` aggregate root (architecture §4, design-patterns §3), with its first two postures.
- **On foot:** standing, walking and running. A/D held speeds the walk into a run.
- **Airborne:** a tap of Space is the normal jump, Space held the high jump, cut at the normal
  height when released early (VISION.md §Movement). Air control, gravity, a short coyote time after
  walking off an edge, a buffered jump press.

Commands record intents and raise no event. `step` advances the posture and adds what happened to a
list the caller owns.

Parts, all private:
- `_Body`: feet, velocity, facing, height. It moves across, then down, through `Terrain`, stopping
  `0.001` su short of what it meets.
- `_Controls`: what is held and what was just pressed; a press lasts one step, a jump press is
  buffered 0.12 s.
- `_Posture`: the sealed State family.
- `_Postures`: one instance of each posture, reused.

**Invariants the root guards:**
- His body is never placed inside a solid: `placeAt` refuses such a point.
- Only the current posture moves the body, through `Terrain`, so the body never passes into a solid
  by moving.
- He is grounded only when a solid lies within 1 su below his feet and he is not rising.
- Facing follows the direction held.
- His health is a `Health`, never below zero or above its maximum.

**Domain events it records:**
- `Placed(at)`, `Jumped(at, isHigh)` and `Landed(at, fallSpeed)` in this task.
- The rest of the `AkerisEvent` family is declared here and raised by later tasks: `RollStarted`,
  `DiveLanded`, `FellIntoAbyss`, `BackOnFirmGround`, `HitTaken`, `Died`, `HealthChanged`,
  `PickupBegun` and `ChainReleased`.

`Stance` is declared whole here (no test of its own, wave-04 `type-only-files-untested`); its cases
are reached as the postures arrive. `Terrain` is the domain's port onto the solid world: stone,
abyss, which stone never moves, and what a platform's motion did to him. It is implemented in
`application/` over `CollisionWorld` (architect change-05).

## Constraints

- **Privacy.** Every part is `part of 'akeris.dart'` and private; the root's queries return values
  and enums only, never a part (checklist A7, A12; wave-04 `entities-behind-their-root`).
- **No allocation in the step** but the kernel values a moving body needs, its `Vec2`s and
  `WorldBox` (wave-04 `kernel-vec2-allocates`). Postures are reused, and events are built only when
  they happen.
- **Sizes.** No class over 200 lines and no function over 20 (coding-standards §3). `Akeris` gains
  methods in T119–T126; keep its body lean.
- **Tests.** Each part's test file sits at the part's path and exercises it through the root
  (planner wave-05 `parts-tested-through-root`). Tests stub `Terrain` with `stubRoom` from
  `builders.dart`. Every number from a reference names it in a comment.

```dart
/// Akeris, the Savior: his body, his posture and his health. Every change
/// goes through this root (architecture §4).
final class Akeris {
  Akeris({required Vec2 feet, AkerisTuning tuning = const AkerisTuning()})
    : this._(tuning, _Body(feet, tuning), _Postures());

  Akeris._(this._tuning, this._body, this._postures)
    : _posture = _postures.airborne,
      _health = Health.full(_tuning.health);

  /// entity_id.dart: akeris's only id.
  static const EntityId id = EntityId(100000000);

  final AkerisTuning _tuning;
  final _Body _body;
  final _Postures _postures;
  final _Controls _controls = _Controls();
  _Posture _posture;
  Health _health;
  Tether _tether = const Slack();
  WeaponId _held = WeaponId.sacredSword;
  Seconds _rollCooldown = Seconds.zero;
  bool _hasAirRolled = false;

  Vec2 get feet => _body.feet;
  Vec2 get velocity => _body.velocity;
  Facing get facing => _body.facing;
  Health get health => _health;
  Stance get stance => _posture.stanceOf(this);
  bool get isInvulnerable => _posture.isInvulnerable;
  WeaponId get heldWeapon => _held;
  WorldBox get hurtbox => _body.box;
  Vec2 get shoulder =>
      Vec2(_body.feet.x, _body.feet.y - _tuning.shoulderAboveFeet);

  void startMoving(Facing direction) => _controls.heading = direction;
  void stopMoving() => _controls.heading = null;
  void startJump() => _controls.pressJump(_tuning.jumpBuffer);
  void releaseJump() => _controls.isJumpHeld = false;
  void startCrouch() => _controls.isCrouchHeld = true;
  void stopCrouch() => _controls.isCrouchHeld = false;
  void roll() => _controls.isRollPressed = true;
  void descend() => _controls.isDescendPressed = true;
  void hold(WeaponId weapon) => _held = weapon;
  void followTether(Tether tether) => _tether = tether;

  /// Stands Akeris's feet at [feet], still; null when his body would be
  /// inside a solid there.
  Placed? placeAt(Vec2 feet, Terrain terrain) {
    if (_body.wouldOverlapAt(feet, terrain)) {
      return null;
    }
    _body.standAt(feet);
    _posture = _postures.airborne.fall();
    return Placed(at: feet);
  }

  /// Steps Akeris by [dt] on [terrain]; what happened is added to [into].
  void step(Seconds dt, Terrain terrain, List<AkerisEvent> into) {
    _rollCooldown = (_rollCooldown - dt).atLeast(Seconds.zero);
    _controls.age(dt);
    _change(_posture.step(this, dt, terrain, into), into);
    _controls.forgetPresses();
  }

  void _change(_Posture next, List<AkerisEvent> into) {
    if (identical(next, _posture)) {
      return;
    }
    _posture = next;
    final entered = next.enter(this);
    if (entered != null) {
      into.add(entered);
    }
  }
}
```

```dart
// lib/features/akeris/domain/body.dart — new
part of 'akeris.dart';

// Akeris's body in the world: his feet, his speed, his facing and how tall
// he stands (architecture §4: an aggregate's changing state is its own).
final class _Body {
  _Body(this.feet, this._tuning) : height = _tuning.standingHeight;

  // A body that meets a solid stops this far short of it, so the next sweep
  // starts outside it: dungeon's sweep passes through what a box overlaps.
  static const double _skin = 0.001;

  // He is grounded when a solid lies within 1 su below his feet.
  static const Vec2 _groundProbe = Vec2(0, 1);

  final AkerisTuning _tuning;
  Vec2 feet;
  Vec2 velocity = Vec2.zero;
  Facing facing = Facing.right;
  double height;
  bool isGrounded = false;

  WorldBox get box => _boxAt(feet, height);

  WorldBox _boxAt(Vec2 at, double tall) => WorldBox(
    centre: Vec2(at.x, at.y - tall / 2),
    halfWidth: _tuning.halfWidth,
    halfHeight: tall / 2,
  );

  /// Gravity over [dt], never past the fall's cap.
  void fall(Seconds dt) => velocity = Vec2(
    velocity.x,
    math.min(
      _tuning.fallSpeedCap,
      velocity.y + _tuning.gravity * dt.value,
    ),
  );

  /// Moves by the velocity over [dt], across then down (the sandbox's
  /// `moveX`, `moveY`), stopping a skin short of what it meets.
  void move(Seconds dt, Terrain terrain) {
    final dx = velocity.x * dt.value;
    if (dx != 0) {
      final fraction = terrain.travel(box, Vec2(dx, 0));
      feet = Vec2(feet.x + _travelled(dx, fraction), feet.y);
      if (fraction < 1) velocity = Vec2(0, velocity.y);
    }
    final dy = velocity.y * dt.value;
    if (dy != 0) {
      final fraction = terrain.travel(box, Vec2(0, dy));
      feet = Vec2(feet.x, feet.y + _travelled(dy, fraction));
      if (fraction < 1) velocity = Vec2(velocity.x, 0);
    }
    feelGround(terrain);
  }

  void feelGround(Terrain terrain) =>
      isGrounded = velocity.y >= 0 && terrain.travel(box, _groundProbe) < 1;

  static double _travelled(double move, double fraction) =>
      fraction < 1 ? move * fraction - _skin * move.sign : move;

  /// Whether he could stand [tall] where he is, with no ceiling in the way.
  bool hasRoomFor(double tall, Terrain terrain) =>
      tall <= height || terrain.travel(box, Vec2(0, height - tall)) == 1;

  /// A standing body at [at] would be inside a solid: its centre or one of
  /// its corners, 1 su in.
  bool wouldOverlapAt(Vec2 at, Terrain terrain) {
    final b = _boxAt(at, _tuning.standingHeight);
    return terrain.isSolidAt(b.centre) ||
        terrain.isSolidAt(Vec2(b.left + 1, b.top + 1)) ||
        terrain.isSolidAt(Vec2(b.right - 1, b.top + 1)) ||
        terrain.isSolidAt(Vec2(b.left + 1, b.bottom - 1)) ||
        terrain.isSolidAt(Vec2(b.right - 1, b.bottom - 1));
  }

  void standAt(Vec2 at) {
    feet = at;
    velocity = Vec2.zero;
    height = _tuning.standingHeight;
    isGrounded = false;
  }

  void face(Facing? heading) {
    if (heading != null) facing = heading;
  }
}

double _approach(double value, double target, double step) => value < target
    ? math.min(target, value + step)
    : math.max(target, value - step);

double _lerp(double from, double to, double u) => from + (to - from) * u;

// The sandbox's `smooth`, its in-out ease.
double _smooth(double u) {
  final t = u.clamp(0.0, 1.0);
  return t * t * (3 - 2 * t);
}
```

```dart
part of 'akeris.dart';

// What the player holds, and what he has just pressed: a press lasts one
// step (the sandbox's `tap`), a jump press is kept a moment (its buffer).
final class _Controls {
  Facing? heading;
  bool isJumpHeld = false;
  bool isCrouchHeld = false;
  bool isRollPressed = false;
  bool isDescendPressed = false;
  Seconds _jumpBuffered = Seconds.zero;

  int get axis => heading?.sign ?? 0;

  void pressJump(Seconds buffer) {
    isJumpHeld = true;
    _jumpBuffered = buffer;
  }

  /// True once for a jump pressed within its buffer.
  bool takeJump() {
    if (_jumpBuffered <= Seconds.zero) return false;
    _jumpBuffered = Seconds.zero;
    return true;
  }

  bool takeRoll() {
    final pressed = isRollPressed;
    isRollPressed = false;
    return pressed;
  }

  bool takeDescend() {
    final pressed = isDescendPressed;
    isDescendPressed = false;
    return pressed;
  }

  void age(Seconds dt) =>
      _jumpBuffered = (_jumpBuffered - dt).atLeast(Seconds.zero);

  void forgetPresses() {
    isRollPressed = false;
    isDescendPressed = false;
  }
}
```

```dart
// lib/features/akeris/domain/on_foot.dart — new
part of 'akeris.dart';

// Standing, walking and running: A/D held speeds the walk into a run
// (VISION.md §Movement; the sandbox's ground `step`).
final class _OnFoot extends _Posture {
  @override
  Stance stanceOf(Akeris akeris) {
    final speed = akeris._body.velocity.x.abs();
    if (speed < akeris._tuning.walkingFrom) return Stance.standing;
    return speed < akeris._tuning.runningFrom
        ? Stance.walking
        : Stance.running;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    if (akeris._controls.takeJump()) {
      return akeris._postures.airborne.launch(akeris, into);
    }
    _walk(akeris, dt);
    final body = akeris._body
      ..fall(dt)
      ..move(dt, terrain);
    if (!body.isGrounded) {
      return akeris._postures.airborne.walkOff(akeris);
    }
    return this;
  }

  void _walk(Akeris akeris, Seconds dt) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    final heading = akeris._controls.heading;
    final vx = body.velocity.x;
    if (heading == null) {
      body.velocity = Vec2(
        _approach(vx, 0, tuning.stopDeceleration * dt.value),
        body.velocity.y,
      );
      return;
    }
    final rate = vx.sign == -heading.sign
        ? tuning.turnAcceleration
        : (vx.abs() < tuning.walkSpeed
              ? tuning.walkAcceleration
              : tuning.runAcceleration);
    body
      ..velocity = Vec2(
        _approach(vx, heading.sign * tuning.runSpeed, rate * dt.value),
        body.velocity.y,
      )
      ..face(heading);
  }
}
```

```dart
// lib/features/akeris/domain/airborne.dart — new
part of 'akeris.dart';

// In the air: rising, the apex, falling. A tap of Space is the normal jump,
// held the high jump, cut at the normal height when let go early (VISION.md
// §Movement; the sandbox's `jumpLaunch`, `jumpHoldStep` and air `step`).
final class _Airborne extends _Posture {
  Seconds _coyoteLeft = Seconds.zero;
  bool _isHoldingHigh = false;
  double _launchY = 0;
  double _keptSpeed = 0;

  @override
  Stance stanceOf(Akeris akeris) =>
      akeris._body.velocity.y < 0 ? Stance.rising : Stance.falling;

  /// Launches a jump: the high one while Space is still held. [keptSpeed]
  /// is the speed across a roll gives the jump out of it.
  _Airborne launch(
    Akeris akeris,
    List<AkerisEvent> into, {
    double keptSpeed = 0,
  }) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    final isHigh = akeris._controls.isJumpHeld;
    body
      ..velocity = Vec2(
        body.velocity.x,
        -(isHigh ? tuning.highJumpSpeed : tuning.jumpSpeed),
      )
      ..isGrounded = false;
    _isHoldingHigh = isHigh;
    _launchY = body.feet.y;
    _coyoteLeft = Seconds.zero;
    _keptSpeed = keptSpeed;
    into.add(Jumped(at: body.feet, isHigh: isHigh));
    return this;
  }

  /// He walked off an edge: a jump still counts for a moment.
  _Airborne walkOff(Akeris akeris) {
    fall();
    _coyoteLeft = akeris._tuning.coyoteTime;
    return this;
  }

  /// He is in the air with no jump of his own.
  _Airborne fall() {
    _coyoteLeft = Seconds.zero;
    _isHoldingHigh = false;
    _keptSpeed = 0;
    return this;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    _coyoteLeft = (_coyoteLeft - dt).atLeast(Seconds.zero);
    if (_coyoteLeft > Seconds.zero && akeris._controls.takeJump()) {
      return launch(akeris, into);
    }
    _cutHighJump(akeris);
    _steer(akeris, dt);
    final body = akeris._body..fall(dt);
    final fallSpeed = body.velocity.y;
    body.move(dt, terrain);
    return body.isGrounded ? land(akeris, fallSpeed, into) : this;
  }

  /// His feet touched the ground after falling at [fallSpeed].
  _Posture land(Akeris akeris, double fallSpeed, List<AkerisEvent> into) {
    akeris._hasAirRolled = false;
    into.add(Landed(at: akeris._body.feet, fallSpeed: fallSpeed));
    return akeris._postures.onFoot;
  }

  // Space let go while a high jump still rises below the normal height: the
  // rise is cut to end there (VISION.md §Movement).
  void _cutHighJump(Akeris akeris) {
    final body = akeris._body;
    if (!_isHoldingHigh || akeris._controls.isJumpHeld) {
      _isHoldingHigh = _isHoldingHigh && body.velocity.y < 0;
      return;
    }
    _isHoldingHigh = false;
    final tuning = akeris._tuning;
    final normal = tuning.jumpSpeed * tuning.jumpSpeed / (2 * tuning.gravity);
    final left = normal - (_launchY - body.feet.y);
    if (left > 0 && body.velocity.y < 0) {
      body.velocity = Vec2(
        body.velocity.x,
        math.max(body.velocity.y, -math.sqrt(2 * tuning.gravity * left)),
      );
    }
  }

  void _steer(Akeris akeris, Seconds dt) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    final axis = akeris._controls.axis;
    final vx = body.velocity.x;
    final keeps =
        _keptSpeed > tuning.airSpeed && (axis == 0 || axis == vx.sign);
    final next = keeps
        ? vx.sign *
              math.min(_keptSpeed, math.max(vx.abs(), axis.abs() * tuning.airSpeed))
        : _approach(vx, axis * tuning.airSpeed, tuning.airAcceleration * dt.value);
    body
      ..velocity = Vec2(next, body.velocity.y)
      ..face(akeris._controls.heading);
  }
}
```

```dart
import 'package:mocktail/mocktail.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';

import 'mocks.dart';

/// Stubs [terrain] as a room: a floor no box passes downward, a ceiling no
/// box passes upward, the abyss below [abyssBelow]; nothing stops a move
/// across, all the stone is static and no platform carries anything.
/// Callers register fallback values for WorldBox and Vec2.
void stubRoom(
  MockTerrain terrain, {
  double floor = double.infinity,
  double ceiling = double.negativeInfinity,
  double abyssBelow = double.infinity,
}) {
  when(() => terrain.travel(any(), any())).thenAnswer((invocation) {
    final box = invocation.positionalArguments[0] as WorldBox;
    final move = invocation.positionalArguments[1] as Vec2;
    if (move.y > 0 && box.bottom + move.y > floor) {
      return ((floor - box.bottom) / move.y).clamp(0.0, 1.0);
    }
    if (move.y < 0 && box.top + move.y < ceiling) {
      return ((ceiling - box.top) / move.y).clamp(0.0, 1.0);
    }
    return 1.0;
  });
  when(() => terrain.isSolidAt(any())).thenAnswer((invocation) {
    final point = invocation.positionalArguments[0] as Vec2;
    return point.y > floor || point.y < ceiling;
  });
  when(() => terrain.isStaticSolidAt(any())).thenAnswer((invocation) {
    final point = invocation.positionalArguments[0] as Vec2;
    return point.y > floor || point.y < ceiling;
  });
  when(() => terrain.isAbyssAt(any())).thenAnswer(
    (invocation) => (invocation.positionalArguments[0] as Vec2).y > abyssBelow,
  );
  when(() => terrain.carry(any())).thenReturn(Vec2.zero);
}
```

# T138 — Hurt Akeris with the hits combat lands on him

## Description

akeris hears `HitLanded` (architecture §2.3). A hit whose `target` is Akeris goes to the root's
`takeHit(damage, knockback)`. What the root answers, `HitTaken` or `Died`, is reported through
`ReportAkeris`: the hurt sound, or `AkerisDied`. A hit on any other body is not his. A lethal hit
(the grabs of zone 2) waits for the enemies that grab (planner wave-05 `lethal-hits-deferred`).

## Preconditions

- On `main`: `EventQueue` (core/loop).

## Constraints

- No rule: the root decides what a hit does.

## Implementation

```dart
// lib/features/akeris/application/hear_hits.dart — new
import 'package:saviors_paradox/core/contracts/events/hit_landed.dart';
import 'package:saviors_paradox/core/contracts/ports/event_source.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/application/report_akeris.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';

/// What combat lands on Akeris hurts him.
final class HearHits {
  HearHits(this._akeris, this._report, EventSource events) {
    events.subscribe<HitLanded>(hear);
  }

  final AkerisRepository _akeris;
  final ReportAkeris _report;

  void hear(HitLanded hit) {
    if (hit.target != Akeris.id) {
      return;
    }
    final akeris = _akeris.load();
    final happened = akeris.takeHit(hit.damage, hit.knockback);
    _akeris.save(akeris);
    if (happened != null) {
      _report.report(happened);
    }
  }
}
```

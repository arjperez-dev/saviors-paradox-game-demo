# T128 — Read Akeris's terrain from the collision world

## Description

The domain's `Terrain`, implemented over dungeon's `CollisionWorld`: akeris's anti-corruption layer
(architecture §2.2, checklist A6). A sweep's hit becomes the fraction of the move travelled.
`isStaticSolidAt` and `carry` are dungeon's answers (architect change-05). They are valid after the
zone's step, which wave 6's composition root runs before akeris's (planner wave-05
`wave-6-step-order`).

## Constraints

- No rule and no state; nothing but the forward.

## Implementation

```dart
// lib/features/akeris/application/terrain_of_world.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/core/contracts/ports/collision_world.dart';
import 'package:saviors_paradox/features/akeris/domain/terrain.dart';

/// Akeris's terrain, read from the zone's collision world.
final class TerrainOfWorld implements Terrain {
  const TerrainOfWorld(this._world);

  final CollisionWorld _world;

  @override
  double travel(WorldBox box, Vec2 move) =>
      _world.sweep(box, move)?.fraction ?? 1;

  @override
  bool isSolidAt(Vec2 point) => _world.isSolidAt(point);

  @override
  bool isStaticSolidAt(Vec2 point) => _world.isStaticSolidAt(point);

  @override
  bool isAbyssAt(Vec2 point) => _world.isAbyssAt(point);

  @override
  Vec2 carry(WorldBox box) => _world.carry(box);
}
```

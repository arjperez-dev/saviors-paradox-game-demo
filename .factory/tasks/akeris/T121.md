# T121 — Drop Akeris in a fast descent

## Description

The fast descent: S in the air drops him at 1750 su/s, keeping 0.3 of his speed across and braking
the rest. It is refused while he still rises faster than 600 su/s. Where it lands it stuns enemies
(VISION.md §Movement), which enemies do on hearing `FastDescentLanded`.

**Domain event:** `DiveLanded(at)`. A dive landing is not a `Landed`.

## Implementation

```dart
// lib/features/akeris/domain/diving.dart — new
part of 'akeris.dart';

// The fast descent: S in the air (VISION.md §Movement; the sandbox's
// `dive`).
final class _Diving extends _Posture {
  @override
  Stance stanceOf(Akeris akeris) => Stance.diving;

  @override
  AkerisEvent? enter(Akeris akeris) {
    final body = akeris._body;
    body.velocity = Vec2(
      body.velocity.x * akeris._tuning.diveKeeps,
      body.velocity.y,
    );
    return null;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final tuning = akeris._tuning;
    final body = akeris._body
      ..velocity = Vec2(
        _approach(
          akeris._body.velocity.x,
          0,
          tuning.diveBraking * dt.value,
        ),
        tuning.diveSpeed,
      )
      ..move(dt, terrain);
    if (!body.isGrounded) {
      return this;
    }
    akeris._hasAirRolled = false;
    into.add(DiveLanded(at: body.feet));
    return akeris._postures.onFoot;
  }
}
```

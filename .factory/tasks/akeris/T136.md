# T136 — Show Akeris to combat as a combatant

## Description

`AkerisBodyCombatant` replaces its stub. It is the read-only `Combatant` view combat sees: his id,
his side, his hurtbox, whether a hit passes through him. It reads only the root's queries, never a
part, and holds nothing of its own (checklist A12; operator, 2026-10-17). No shield is raised and no
element is shrugged off yet: the shields and their elements come with arsenal and Akeris's fighting.

## Preconditions

- On `main`, `akeris_body_combatant.dart` is a stub with no constructor arguments, returning
  `EntityId(0)` and a zero box.

## Implementation

```dart
// lib/features/akeris/application/akeris_body_combatant.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/element.dart';
import 'package:saviors_paradox/core/contracts/kernel/entity_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/world_box.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant.dart';
import 'package:saviors_paradox/core/contracts/ports/combatant_side.dart';
import 'package:saviors_paradox/core/contracts/ports/raised_shield.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';

/// Akeris as combat sees him: a read-only view of the root.
final class AkerisBodyCombatant implements Combatant {
  AkerisBodyCombatant(this._akeris);

  final AkerisRepository _akeris;

  @override
  EntityId get id => Akeris.id;

  @override
  CombatantSide get side => CombatantSide.akeris;

  @override
  WorldBox get hurtbox => _akeris.load().hurtbox;

  // The shields come with arsenal's StrappedShield and his block.
  @override
  RaisedShield? get raisedShield => null;

  @override
  bool get isInvulnerable => _akeris.load().isInvulnerable;

  @override
  bool isImmuneTo(Element element) => false;
}
```

# T123 — Return Akeris from the abyss to firm ground

## Description

Falling into the abyss (VISION.md §Movement, Falls; `hazards.md` Z10). When his feet fall into the
abyss — any posture in the air, `Terrain.isAbyssAt` — he falls on for 0.45 s and the dark lasts
0.25 s. He is then back at the last firm ground and loses 2 health; if that empties it, he dies
there.

**Firm ground** is the last place he stood on foot or crouched with both feet on stone. "Stone" is
`isStaticSolidAt` true 26 su each side of his centre, felt 3 su below (`hazards.md`, the sandbox's
`zAfterStep`). It is never a platform (architect change-05). With no firm ground recorded since he
was last placed, the fall returns him where he was placed: the zone's start, once `EnterZone`
places him there (architect change-05 `state-zone_state`). A curse that makes the fall kill comes
with inventory.

**Invariant added:** the return point is always where his feet stood on stone, or where he was
placed.
**Domain events:** `FellIntoAbyss(at)`, then `BackOnFirmGround(at, damage)` or `Died(at)`.

## Constraints

- As T118. In the dark nothing reaches him: the posture is invulnerable.

## Implementation

```dart
// lib/features/akeris/domain/falling_into_abyss.dart — new
part of 'akeris.dart';

// Falling into the abyss: 0.45 s falling and 0.25 s of dark, then back at
// the last firm ground, losing health (hazards.md Z10).
final class _FallingIntoAbyss extends _Posture {
  Seconds _elapsed = Seconds.zero;

  @override
  Stance stanceOf(Akeris akeris) => Stance.abyssFalling;

  @override
  bool get isInvulnerable => true;

  @override
  AkerisEvent? enter(Akeris akeris) {
    _elapsed = Seconds.zero;
    return FellIntoAbyss(at: akeris._body.feet);
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final tuning = akeris._tuning;
    final body = akeris._body..fall(dt);
    body.feet = body.feet + body.velocity.scaled(dt.value);
    _elapsed = _elapsed + dt;
    if (_elapsed < tuning.abyssFallTime + tuning.abyssDarkTime) {
      return this;
    }
    return akeris._backOnFirmGround(into);
  }
}
```

```dart
// lib/features/akeris/domain/body.dart — `_Body` gains:

  /// Both feet on stone that never moves (hazards.md: never a platform).
  bool standsFirm(Terrain terrain) =>
      isGrounded &&
      terrain.isStaticSolidAt(
        Vec2(feet.x - _tuning.firmFootSpan, feet.y + _tuning.firmFootDepth),
      ) &&
      terrain.isStaticSolidAt(
        Vec2(feet.x + _tuning.firmFootSpan, feet.y + _tuning.firmFootDepth),
      );

  /// His feet are in the abyss as he falls.
  bool fallsIntoAbyss(Terrain terrain) =>
      !isGrounded && velocity.y > 0 && terrain.isAbyssAt(feet);
```

```dart
// lib/features/akeris/domain/akeris.dart — the part; two fields, the first
// set in Akeris._'s initializer list (`_placedAt = _body.feet`):
  Vec2 _placedAt;
  Vec2? _firmGround;
// `placeAt` also sets `_placedAt = feet;` and `_firmGround = null;`; and:

  void _noteFirmGround(Terrain terrain) {
    if (_body.standsFirm(terrain)) {
      _firmGround = _body.feet;
    }
  }

  _Posture _backOnFirmGround(List<AkerisEvent> into) {
    final back = _firmGround ?? _placedAt;
    _body.standAt(back);
    _health = _health.lose(_tuning.abyssDamage);
    if (_health.isDepleted) {
      into.add(Died(at: back));
      return _postures.dead;
    }
    into.add(BackOnFirmGround(at: back, damage: _tuning.abyssDamage));
    return _postures.airborne.fall();
  }
```

```dart
// lib/features/akeris/domain/posture.dart — `_Postures` gains:
  final _FallingIntoAbyss abyss = _FallingIntoAbyss();

// lib/features/akeris/domain/on_foot.dart and crouching.dart — once the
// body has moved and is grounded, before `return this;`:
    akeris._noteFirmGround(terrain);

// lib/features/akeris/domain/airborne.dart, air_rolling.dart, diving.dart
// and hurt.dart — right after `move`, before the grounded test:
    if (body.fallsIntoAbyss(terrain)) {
      return akeris._postures.abyss;
    }
```

## Acceptance criteria

The fall setup: placed with `placeAt(Vec2(0, 0), terrain)` on `stubRoom(terrain, floor: 0)`, he
walks to `Vec2(100, 0)` and stands 10 steps. The stubs are then replaced by
`stubRoom(terrain, abyssBelow: 50)`, so he falls.

# T132 — Hand Akeris the weapon his loadout holds

## Description

`StepLoadout` reads the `LoadoutModifierSource`s again only when one's `revision` changed
(design-patterns §1 rule 3: rebuilt on change, never every frame). It gives the root the weapon in
hand (`heldWeaponOf`). Only the held weapon is read this wave: the decorator chain over the loadout
comes with Akeris's fighting. arsenal implements `HeldWeapon` in a later wave; until then a test
hands him the chain blades through a mocked source.

## Constraints

- The seen revisions are a memo, not game state; a step whose revisions are unchanged loads nothing.

## Implementation

```dart
// lib/features/akeris/application/step_loadout.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/ports/loadout_modifier_source.dart';
import 'package:saviors_paradox/features/akeris/application/akeris_reading.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';

/// Gives Akeris the weapon his loadout holds, when it changes
/// (design-patterns.md §1, rule 3).
final class StepLoadout {
  StepLoadout({
    required AkerisRepository akeris,
    required List<LoadoutModifierSource> sources,
  }) : _akeris = akeris, // ignore: prefer_initializing_formals — private
       _sources = List.unmodifiable(sources),
       _seen = List.filled(sources.length, -1);

  final AkerisRepository _akeris;
  final List<LoadoutModifierSource> _sources;

  // The revisions read last: a memo, not game state.
  final List<int> _seen;

  void step(Seconds dt) {
    if (!_hasChanged()) {
      return;
    }
    final akeris = _akeris.load()..hold(heldWeaponOf(_sources));
    _akeris.save(akeris);
  }

  bool _hasChanged() {
    var hasChanged = false;
    for (var i = 0; i < _sources.length; i++) {
      final revision = _sources[i].revision;
      if (revision != _seen[i]) {
        _seen[i] = revision;
        hasChanged = true;
      }
    }
    return hasChanged;
  }
}
```

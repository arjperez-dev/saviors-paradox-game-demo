# T119 — Crouch Akeris under low ceilings

## Description

The crouch: Left Ctrl held lowers him to 138 su and slows him to 150 su/s, to pass tunnels and low
gaps (VISION.md §Movement). Under a ceiling too low to stand, he stays crouched even after the key
is let go. He crouches from on foot, and lands crouched when the key is held.

**Invariant added to the root:** he stands up only where there is room for 192 su.

## Constraints

- As T118: a private part, reused, tested through the root.

## Implementation

```dart
// lib/features/akeris/domain/crouching.dart — new
part of 'akeris.dart';

// Crouched, still or walking low, under tunnels and low gaps (VISION.md
// §Movement; animations.md §4 crouch; the sandbox's crouch branch).
final class _Crouching extends _Posture {
  @override
  Stance stanceOf(Akeris akeris) => Stance.crouching;

  @override
  AkerisEvent? enter(Akeris akeris) {
    akeris._body.height = akeris._tuning.crouchingHeight;
    return null;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final body = akeris._body;
    final standing = akeris._tuning.standingHeight;
    final canStand = body.hasRoomFor(standing, terrain);
    if (canStand && akeris._controls.takeJump()) {
      body.height = standing;
      return akeris._postures.airborne.launch(akeris, into);
    }
    if (canStand && !akeris._controls.isCrouchHeld) {
      body.height = standing;
      return akeris._postures.onFoot;
    }
    _creep(akeris, dt);
    body
      ..fall(dt)
      ..move(dt, terrain);
    return body.isGrounded ? this : akeris._postures.airborne.walkOff(akeris);
  }

  void _creep(Akeris akeris, Seconds dt) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    body
      ..velocity = Vec2(
        _approach(
          body.velocity.x,
          akeris._controls.axis * tuning.crouchSpeed,
          tuning.crouchAcceleration * dt.value,
        ),
        body.velocity.y,
      )
      ..face(akeris._controls.heading);
  }
}
```

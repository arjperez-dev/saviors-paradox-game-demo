# T130 — Report what happened to Akeris's body

## Description

`ReportAkeris`, the one place akeris's domain events become what other contexts hear (architecture
§4; as `ReportExchange` is combat's).

| Domain event | What it becomes |
|---|---|
| `Jumped` | `sfx.akeris.jump` |
| `Landed` | `AkerisLanded(at, fallSpeed)` and `sfx.akeris.land` |
| `DiveLanded` | `FastDescentLanded(at)` and `sfx.akeris.dive` |
| `RollStarted` | `sfx.akeris.roll`; the chains come back, since a roll cuts a chain action (VISION.md) |
| `FellIntoAbyss` | `sfx.zone1.fall` |
| `HitTaken` | `sfx.akeris.hurt` |
| `Died` | `AkerisDied(cause: health, at)` and `sfx.akeris.death`; the chains come back |
| `ChainReleased` | `ChainBlades.letGo()` |
| `Placed`, `BackOnFirmGround`, `HealthChanged`, `PickupBegun` | nothing |

`movedTo` tells dungeon where his feet stand, once per step (architect change-04,
`ports-zone_presence`).

## Constraints

- No rule and no state (checklist A15); nothing allocated but the events published.
- Every sound id is `07-audio/sfx/sfx.md`'s and named there in a comment.

## Implementation

```dart
// lib/features/akeris/application/report_akeris.dart — new
import 'package:saviors_paradox/core/contracts/events/akeris_died.dart';
import 'package:saviors_paradox/core/contracts/events/akeris_landed.dart';
import 'package:saviors_paradox/core/contracts/events/death_cause.dart';
import 'package:saviors_paradox/core/contracts/events/fast_descent_landed.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_cued.dart';
import 'package:saviors_paradox/core/contracts/events/sound_effect_id.dart';
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_blades.dart';
import 'package:saviors_paradox/core/contracts/ports/event_sink.dart';
import 'package:saviors_paradox/core/contracts/ports/zone_presence.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris_event.dart';

/// Tells the game what happened to Akeris's body, and the zone where he
/// stands (architecture.md §4).
final class ReportAkeris {
  ReportAkeris({
    required EventSink events,
    required ChainBlades chain,
    required ZonePresence presence,
  }) : _events = events, // ignore: prefer_initializing_formals — private
       _chain = chain, // ignore: prefer_initializing_formals — ditto
       _presence = presence; // ignore: prefer_initializing_formals — ditto

  // 07-audio/sfx/sfx.md, Akeris and Zone 1.
  static const SoundEffectId jump = SoundEffectId('sfx.akeris.jump');
  static const SoundEffectId land = SoundEffectId('sfx.akeris.land');
  static const SoundEffectId dive = SoundEffectId('sfx.akeris.dive');
  static const SoundEffectId roll = SoundEffectId('sfx.akeris.roll');
  static const SoundEffectId hurt = SoundEffectId('sfx.akeris.hurt');
  static const SoundEffectId death = SoundEffectId('sfx.akeris.death');
  static const SoundEffectId fall = SoundEffectId('sfx.zone1.fall');

  final EventSink _events;
  final ChainBlades _chain;
  final ZonePresence _presence;

  void all(List<AkerisEvent> events) {
    for (var i = 0; i < events.length; i++) {
      report(events[i]);
    }
  }

  void report(AkerisEvent event) {
    switch (event) {
      case Jumped(:final at):
        _cue(jump, at);
      case Landed(:final at, :final fallSpeed):
        _events.publish(AkerisLanded(at: at, fallSpeed: fallSpeed));
        _cue(land, at);
      case DiveLanded(:final at):
        _events.publish(FastDescentLanded(at: at));
        _cue(dive, at);
      case RollStarted(:final at):
        _cue(roll, at);
        _chain.letGo();
      case FellIntoAbyss(:final at):
        _cue(fall, at);
      case HitTaken(:final at):
        _cue(hurt, at);
      case Died(:final at):
        _died(at);
      case ChainReleased():
        _chain.letGo();
      case Placed() || BackOnFirmGround() || HealthChanged() || PickupBegun():
        break;
    }
  }

  void movedTo(Vec2 feet) => _presence.movedTo(feet);

  void _died(Vec2 at) {
    _events.publish(AkerisDied(cause: DeathCause.health, at: at));
    _cue(death, at);
    _chain.letGo();
  }

  void _cue(SoundEffectId sound, Vec2 at) =>
      _events.publish(SoundEffectCued(sound: sound, at: at));
}
```

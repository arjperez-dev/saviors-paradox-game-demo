# T135 — Throw the chain blades where Akeris aims

## Description

With the chain blades in hand, a left click throws one toward the aim and its release ends the throw
(VISION.md §Mechanics, The chain blades). What the throw does is chain's `ChainResolver`'s; akeris
asks, and tells chain what only his body knows (architect change-05, `ports-chain_throw`):

- **`canThrowChain`:** the chain blades in hand, and a posture that lets a blade fly. On foot, in the
  air, swinging (the next ring) and hanging from a wall (the next stretch) do. Crouched, rolling,
  diving, hurt, dead, picking up, falling into the abyss, pulled across and mid-climb do not (the
  sandbox's `step`).
- **`isAirborne`:** whether his feet are off the ground; hanging counts as in the air (G19, G20).
- **`chainAim(aim, pointerStillFor)`:** the click's aim, or straight ahead at the strike's 340 su
  from his shoulder once the pointer has been still for 4 s (`hook-blades.md` §3; operator,
  2026-10-15 and 2026-10-17). Chain then always receives a real aim and needs no facing.

`ChainThrow` gets his shoulder as `from`, that aim, the click's stillness and W/S, `isAirborne`, and
`isFromFreeHand: false`. The free hand's throw while hanging comes with Akeris's fighting.

**Invariant added:** a chain is thrown only with the chain blades in hand.

## Preconditions

- On `main`: `EventQueue` (core/loop); `ChainThrow` with `isAirborne` (architect change-05).

## Constraints

- The release goes to the chain whatever his posture: it only ends a throw the chain has started.

## Implementation

```dart
// lib/features/akeris/domain/posture.dart — `_Posture` gains:
  /// Whether a hook blade can leave his hand in this posture.
  bool get letsChainFly => false;
// on_foot.dart, airborne.dart, swinging.dart and wall_hanging.dart override
// it: `@override bool get letsChainFly => true;`

// lib/features/akeris/domain/akeris.dart — added:
  bool get canThrowChain =>
      _held == WeaponId.chainBlades && _posture.letsChainFly;

  bool get isAirborne => !_body.isGrounded;

  /// Where a throw goes: the aim, or straight ahead at the chain's reach
  /// once the pointer has been still too long (hook-blades.md §3).
  Vec2 chainAim(Vec2 aim, Seconds pointerStillFor) =>
      pointerStillFor < _tuning.aimForgottenAfter
      ? aim
      : shoulder + Vec2(_body.facing.sign * _tuning.chainReach, 0);
```

```dart
// lib/features/akeris/application/throw_chain.dart — new
import 'package:saviors_paradox/core/contracts/events/player_command.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_blades.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_throw.dart';
import 'package:saviors_paradox/core/contracts/ports/event_source.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';

/// A click with the chain blades throws one where he aims; its release
/// ends the throw (VISION.md §Mechanics, The chain blades).
final class ThrowChain {
  ThrowChain(this._akeris, this._chain, EventSource commands) {
    commands
      ..subscribe<StartAttack>(start)
      ..subscribe<ReleaseAttack>(release);
  }

  final AkerisRepository _akeris;
  final ChainBlades _chain;

  void start(StartAttack attack) {
    final akeris = _akeris.load();
    if (!akeris.canThrowChain) {
      return;
    }
    _chain.startThrow(
      ChainThrow(
        from: akeris.shoulder,
        aim: akeris.chainAim(attack.aim, attack.pointerStillFor),
        pointerStillFor: attack.pointerStillFor,
        isUpHeld: attack.isUpHeld,
        isDownHeld: attack.isDownHeld,
        isFromFreeHand: false,
        isAirborne: akeris.isAirborne,
      ),
    );
  }

  void release(ReleaseAttack attack) => _chain.endThrow(attack.aim);
}
```

# T146 — Carry Akeris on the drifting platforms

## Description

A drifting platform carries Akeris (`hazards.md`; architect change-05, `ports-collision_world`).
Before each posture's step, the root asks `Terrain.carry` how the zone's last step moved the ground
under his body. It sweeps that displacement with `_Body.sweepBy`, so a wall still stops him. A
platform that rose into him lifts him on top; one coming down pushes him out below; one moving
sideways pushes him aside, all as dungeon answers. He rides in every posture but the tethered ones,
which the chain holds, and the fall into the abyss.

**Invariant added:** his body moves with the ground only by a sweep, never into a wall.

## Constraints

- As T118. Nothing is allocated when `carry` answers `Vec2.zero` but that answer.

## Implementation

```dart
// lib/features/akeris/domain/body.dart — `_Body` gains:

  /// Moves with the ground the zone's last step moved under him, swept so
  /// a wall still stops him (hazards.md; CollisionWorld.carry).
  void ride(Terrain terrain) {
    final carried = terrain.carry(box);
    if (carried != Vec2.zero) {
      sweepBy(carried, terrain);
    }
  }

// lib/features/akeris/domain/posture.dart — `_Posture` gains:
  /// Whether a platform's motion carries him in this posture.
  bool get ridesGround => !isTethered;
// lib/features/akeris/domain/falling_into_abyss.dart — `_FallingIntoAbyss`
// overrides it:
  @override
  bool get ridesGround => false;

// lib/features/akeris/domain/akeris.dart — `step` becomes:
  void step(Seconds dt, Terrain terrain, List<AkerisEvent> into) {
    _rollCooldown = (_rollCooldown - dt).atLeast(Seconds.zero);
    _controls.age(dt);
    if (_posture.ridesGround) {
      _body.ride(terrain);
    }
    _change(_posture.step(this, dt, terrain, into), into);
    _controls.forgetPresses();
  }
```

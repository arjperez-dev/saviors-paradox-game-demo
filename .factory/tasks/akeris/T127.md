# T127 — Keep Akeris in a repository

## Description

`Akeris`'s repository (checklist A14; wave-04 `repository-per-root`): a port in `application/ports/`,
held in memory in `infrastructure/`. There is always one Akeris in a run, so `load` is never null.
`mocks.dart` gains the mocks of every port akeris's application calls.

## Constraints

- Loads and saves the whole root, never a part.

## Implementation

```dart
// lib/features/akeris/application/ports/akeris_repository.dart — new
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';

/// Where the run's Akeris is kept.
abstract interface class AkerisRepository {
  /// Akeris, whole.
  Akeris load();

  /// Keeps [akeris] as the one the run plays.
  void save(Akeris akeris);
}
```

```dart
// lib/features/akeris/infrastructure/in_memory_akeris_repository.dart — new
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';

/// The run's Akeris, held in memory.
final class InMemoryAkerisRepository implements AkerisRepository {
  InMemoryAkerisRepository(this._akeris);

  Akeris _akeris;

  @override
  Akeris load() => _akeris;

  @override
  void save(Akeris akeris) => _akeris = akeris;
}
```

# T129 — Translate Akeris to and from the contracts

## Description

Akeris's anti-corruption layer (architecture §2.2), as `zone_reading.dart` is dungeon's:
- `readAkerisState`: the root as the `AkerisState` snapshot. `position` is his feet (planner wave-05
  `position-is-feet`).
- `postureKindOf`: each `Stance` as the contract's `PostureKind`, mapped below.
- `readTether`: the chain's `ChainPull` as a `Tether`. A vine hangs him as a ring does (VISION.md);
  the points of `PullToward` and `ClimbTo` are where the blade bit (planner wave-05
  `chain-points-are-bites`).
- `heldWeaponOf`: the weapon the first `HeldWeapon` across the sources names, or the sacred sword
  when none does. The sword is always carried (VISION.md §Mechanics, Weapons).

**The `Stance` → `PostureKind` mapping:**

| Stance | PostureKind |
|---|---|
| standing, taking | standing |
| walking | walking |
| running | running |
| rising | jumping |
| falling, diving, abyssFalling | falling |
| crouching | crouching |
| rolling, airRolling | rolling |
| hurt | hurt |
| dead | dead |
| swinging | swinging |
| wallHanging | hanging |
| climbing, pulled | climbing |

## Constraints

- Exhaustive `switch`es with no `default` (checklist C7).

## Implementation

```dart
// lib/features/akeris/application/akeris_reading.dart — new
import 'package:saviors_paradox/core/contracts/kernel/weapon_id.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_pull.dart';
import 'package:saviors_paradox/core/contracts/ports/hook_point_kind.dart';
import 'package:saviors_paradox/core/contracts/ports/loadout_modifier.dart';
import 'package:saviors_paradox/core/contracts/ports/loadout_modifier_source.dart';
import 'package:saviors_paradox/core/contracts/state/akeris_state.dart';
import 'package:saviors_paradox/core/contracts/state/posture_kind.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';
import 'package:saviors_paradox/features/akeris/domain/stance.dart';
import 'package:saviors_paradox/features/akeris/domain/tether.dart';

// Akeris's anti-corruption layer (architecture.md §2.2).

AkerisState readAkerisState(Akeris akeris) => AkerisState(
  position: akeris.feet,
  velocity: akeris.velocity,
  facing: akeris.facing,
  posture: postureKindOf(akeris.stance),
  health: akeris.health.current,
  maxHealth: akeris.health.maximum,
  isInvulnerable: akeris.isInvulnerable,
  heldWeapon: akeris.heldWeapon,
);

PostureKind postureKindOf(Stance stance) => switch (stance) {
  Stance.standing || Stance.taking => PostureKind.standing,
  Stance.walking => PostureKind.walking,
  Stance.running => PostureKind.running,
  Stance.rising => PostureKind.jumping,
  Stance.falling || Stance.diving || Stance.abyssFalling => PostureKind.falling,
  Stance.crouching => PostureKind.crouching,
  Stance.rolling || Stance.airRolling => PostureKind.rolling,
  Stance.hurt => PostureKind.hurt,
  Stance.dead => PostureKind.dead,
  Stance.swinging => PostureKind.swinging,
  Stance.wallHanging => PostureKind.hanging,
  Stance.climbing || Stance.pulled => PostureKind.climbing,
};

/// The chain's pull, in akeris's words; its points are where the blade
/// bit.
Tether readTether(ChainPull pull) => switch (pull) {
  NoPull() => const Slack(),
  PullToward(:final point) => PulledToward(point),
  HangFrom(:final hookPoint, :final length) => Hung(
    anchor: hookPoint.position,
    hold: _holdOf(hookPoint.kind),
    length: length,
  ),
  ClimbTo(:final point) => ClimbingTo(point),
};

/// The weapon in his hand: the first a source holds; the sacred sword,
/// always carried, when none does (VISION.md §Mechanics, Weapons).
WeaponId heldWeaponOf(Iterable<LoadoutModifierSource> sources) {
  for (final source in sources) {
    for (final modifier in source.modifiers) {
      if (modifier case HeldWeapon(:final weapon)) {
        return weapon;
      }
    }
  }
  return WeaponId.sacredSword;
}

Hold _holdOf(HookPointKind kind) => switch (kind) {
  HookPointKind.ring || HookPointKind.vine => Hold.ring,
  HookPointKind.wall => Hold.wall,
};
```

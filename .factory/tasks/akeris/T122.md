# T122 — Hurt Akeris until his health runs out

## Description

What a hit does to his body.
- **A hit** costs its damage, knocks him back at 300 su/s and holds him hurt 0.40 s (animations.md
  §4).
- **Invulnerable or dead,** a hit passes through.
- **Health at zero** kills him. Dead, he obeys no command and takes no hit (VISION.md §Win / lose:
  health reaches zero). A hanging posture keeps its hold, since a hit never makes him let go
  (VISION.md); that is `isTethered`, overridden by T125 and T126.
- **Healing and a raised maximum** go through the root, for `AkerisHealth`.

**Invariants added:** health changes only through `takeHit`, `heal` and `raiseMaximum`; dead stays
dead.
**Domain events:** `HitTaken(at, damage)`, `Died(at)`, `HealthChanged(health)`.

## Implementation

```dart
// lib/features/akeris/domain/hurt.dart — new
part of 'akeris.dart';

// Hurt: 0.40 s knocked back at 300 su/s (animations.md §4 hurt).
final class _Hurt extends _Posture {
  Seconds _elapsed = Seconds.zero;

  @override
  Stance stanceOf(Akeris akeris) => Stance.hurt;

  /// Knocks him away along [push], or back from his facing when it has no
  /// side.
  void pushAlong(Akeris akeris, Vec2 push) {
    final body = akeris._body;
    final away = push.x != 0 ? push.x.sign : -body.facing.sign.toDouble();
    body.velocity = Vec2(away * akeris._tuning.hurtKnockback, body.velocity.y);
  }

  @override
  AkerisEvent? enter(Akeris akeris) {
    _elapsed = Seconds.zero;
    return null;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    body
      ..velocity = Vec2(
        _approach(body.velocity.x, 0, tuning.hurtBraking * dt.value),
        body.velocity.y,
      )
      ..fall(dt)
      ..move(dt, terrain);
    _elapsed = _elapsed + dt;
    if (_elapsed < tuning.hurtTime) {
      return this;
    }
    return body.isGrounded
        ? akeris._postures.onFoot
        : akeris._postures.airborne.fall();
  }
}
```

// lib/features/akeris/domain/dead.dart — new
part of 'akeris.dart';

// Dead: he falls where he dies and obeys nothing more (animations.md §5.8;
// VISION.md §Win / lose).
final class _Dead extends _Posture {
  @override
  Stance stanceOf(Akeris akeris) => Stance.dead;

  @override
  bool get isInvulnerable => true;

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final body = akeris._body;
    body
      ..velocity = Vec2(
        _approach(
          body.velocity.x,
          0,
          akeris._tuning.hurtBraking * dt.value,
        ),
        body.velocity.y,
      )
      ..fall(dt)
      ..move(dt, terrain);
    return this;
  }
}

```dart
// lib/features/akeris/domain/posture.dart — `_Posture` gains:
  /// Whether a chain holds him, so a hit never makes him let go.
  bool get isTethered => false;
// and `_Postures` gains:
  final _Hurt hurt = _Hurt();
  final _Dead dead = _Dead();

// lib/features/akeris/domain/akeris.dart — the parts, and:

  /// A hit of [damage] pushing him along [push]: `HitTaken`, or `Died`
  /// when it empties his health; null when it passes through him.
  AkerisEvent? takeHit(double damage, Vec2 push) {
    if (_posture.isInvulnerable) {
      return null;
    }
    _health = _health.lose(damage);
    if (_health.isDepleted) {
      _posture = _postures.dead;
      return Died(at: _body.feet);
    }
    if (!_posture.isTethered) {
      _postures.hurt
        ..pushAlong(this, push)
        ..enter(this);
      _posture = _postures.hurt;
    }
    return HitTaken(at: _body.feet, damage: damage);
  }

  /// Heals [amount], never past his maximum; null once he is dead.
  HealthChanged? heal(double amount) {
    if (_health.isDepleted) {
      return null;
    }
    _health = _health.heal(amount);
    return HealthChanged(health: _health);
  }

  /// Raises his maximum by [amount]; null once he is dead.
  HealthChanged? raiseMaximum(double amount) {
    if (_health.isDepleted) {
      return null;
    }
    _health = _health.raiseMaximum(amount);
    return HealthChanged(health: _health);
  }
```

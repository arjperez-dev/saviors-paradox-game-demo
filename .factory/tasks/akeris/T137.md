# T137 — Heal Akeris when another feature asks

## Description

`AkerisBodyHealth` replaces its stub: the `AkerisHealth` port akeris offers (architecture §2.3). It
is called by inventory's potions and health scroll in a later wave. Each call loads the root, asks it
to heal or raise its maximum, and saves it.

## Preconditions

- On `main`, `akeris_body_health.dart` is a stub with no constructor arguments and empty methods.

## Interfaces

| File | Symbol | Role | Building block | Signature |
|---|---|---|---|---|
| `lib/features/akeris/application/akeris_body_health.dart` | `AkerisBodyHealth` | exports | use case (implements the contract `AkerisHealth`) | `AkerisBodyHealth(AkerisRepository akeris)`, `void heal(double amount)`, `void raiseMaximum(double amount)` |

## Implementation

```dart
// lib/features/akeris/application/akeris_body_health.dart — replaced whole
import 'package:saviors_paradox/core/contracts/ports/akeris_health.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';

/// Heals Akeris, or raises his maximum, when another feature asks.
final class AkerisBodyHealth implements AkerisHealth {
  AkerisBodyHealth(this._akeris);

  final AkerisRepository _akeris;

  @override
  void heal(double amount) {
    final akeris = _akeris.load()..heal(amount);
    _akeris.save(akeris);
  }

  @override
  void raiseMaximum(double amount) {
    final akeris = _akeris.load()..raiseMaximum(amount);
    _akeris.save(akeris);
  }
}
```

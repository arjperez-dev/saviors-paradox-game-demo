# T133 — Turn movement commands into Akeris's intents

## Description

`ControlAkeris` hears the movement commands `core/input` publishes (design-patterns §5) and hands
each to the root as its intent:

| Command | Intent |
|---|---|
| `StartMoving` | `startMoving(direction)` |
| `StopMoving` | `stopMoving()` |
| `StartJump` | `startJump()` |
| `ReleaseJump` | `releaseJump()` |
| `Descend` | `descend()` |
| `Roll` | `roll()` |
| `StartCrouch` | `startCrouch()` |
| `StopCrouch` | `stopCrouch()` |

It subscribes in its constructor, as `TranslateInput` does. Take, the throws and the rest of the
family are other use cases'.

## Preconditions

- On `main`: `EventQueue` (core/loop), used by the tests as the `EventSource`.

## Constraints

- No rule: each handler loads, tells, saves.

## Implementation

```dart
// lib/features/akeris/application/control_akeris.dart — new
import 'package:saviors_paradox/core/contracts/events/player_command.dart';
import 'package:saviors_paradox/core/contracts/ports/event_source.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris.dart';

/// Hands Akeris the player's movement commands (design-patterns.md §5).
final class ControlAkeris {
  ControlAkeris(this._akeris, EventSource commands) {
    commands
      ..subscribe<StartMoving>((c) => _tell((a) => a.startMoving(c.direction)))
      ..subscribe<StopMoving>((_) => _tell((a) => a.stopMoving()))
      ..subscribe<StartJump>((_) => _tell((a) => a.startJump()))
      ..subscribe<ReleaseJump>((_) => _tell((a) => a.releaseJump()))
      ..subscribe<Descend>((_) => _tell((a) => a.descend()))
      ..subscribe<Roll>((_) => _tell((a) => a.roll()))
      ..subscribe<StartCrouch>((_) => _tell((a) => a.startCrouch()))
      ..subscribe<StopCrouch>((_) => _tell((a) => a.stopCrouch()));
  }

  final AkerisRepository _akeris;

  void _tell(void Function(Akeris akeris) intent) {
    final akeris = _akeris.load();
    intent(akeris);
    _akeris.save(akeris);
  }
}
```

## Acceptance criteria

The tests use a real `EventQueue` from `core/loop` as the `EventSource`, publish a command and
`deliver()`, then step the real Akeris the repository holds on `stubRoom(terrain, floor: 0)`.

| Test file | Test name | Assertion |
|---|---|---|
| `test/features/akeris/application/control_akeris_test.dart` | holding a direction moves him that way | `StartMoving(direction: Facing.left)`, then 30 steps: `velocity.x` is negative and `facing` left. |
| `test/features/akeris/application/control_akeris_test.dart` | a stop lets him slow down | After moving, `StopMoving()` and 60 steps: `velocity.x` is 0. |
| `test/features/akeris/application/control_akeris_test.dart` | a jump command jumps him | `StartJump()` then `ReleaseJump()`, one step: `Jumped(isHigh: false)` is added. |
| `test/features/akeris/application/control_akeris_test.dart` | a roll command rolls him | `Roll()`, two steps: `stance` is rolling. |
| `test/features/akeris/application/control_akeris_test.dart` | a crouch command crouches him | `StartCrouch()`, two steps: crouching; `StopCrouch()`, two steps: standing. |
| `test/features/akeris/application/control_akeris_test.dart` | descend in the air dives him | After a jump, `Descend()`, one step: `stance` is diving. |

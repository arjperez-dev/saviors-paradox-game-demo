# T131 — Step Akeris each frame

## Description

`StepAkeris`, the system behind `AkerisState`, replacing its stub. Each step it:
- loads the root;
- hands it the chain's pull as a `Tether`, read again only when the pull changed (a memo, wave-04
  `step-zone-memo`; chain hands the same `ChainPull` while nothing changes);
- steps the root on the terrain and saves it;
- reports what happened, then where his feet stand;
- builds the snapshot once.

Its event list is a scratch buffer refilled each step (wave-04 `repository-per-root`). Neither the
buffer, the memo nor the snapshot is game state.

## Preconditions

- On `main`, `step_akeris.dart` is a stub: `final class StepAkeris` with no constructor arguments,
  `AkerisState get state`, `void step(Seconds dt)`.
- T126, T128, T129, T130 are on `feat/akeris`.

## Constraints

- One aggregate per step (checklist A7). The step allocates nothing but what the root's step
  allocates, the events reported, and the snapshot.

## Implementation

```dart
// lib/features/akeris/application/step_akeris.dart — replaced whole
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_blades.dart';
import 'package:saviors_paradox/core/contracts/ports/chain_pull.dart';
import 'package:saviors_paradox/core/contracts/state/akeris_state.dart';
import 'package:saviors_paradox/features/akeris/application/akeris_reading.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/application/report_akeris.dart';
import 'package:saviors_paradox/features/akeris/domain/akeris_event.dart';
import 'package:saviors_paradox/features/akeris/domain/terrain.dart';

/// Advances Akeris's body by the world step, and shows his snapshot.
final class StepAkeris {
  StepAkeris({
    required AkerisRepository akeris,
    required Terrain terrain,
    required ChainBlades chain,
    required ReportAkeris report,
  }) : _akeris = akeris, // ignore: prefer_initializing_formals — private
       _terrain = terrain, // ignore: prefer_initializing_formals — ditto
       _chain = chain, // ignore: prefer_initializing_formals — ditto
       _report = report; // ignore: prefer_initializing_formals — ditto

  final AkerisRepository _akeris;
  final Terrain _terrain;
  final ChainBlades _chain;
  final ReportAkeris _report;

  // A scratch buffer and two memos, derived each step: not game state.
  final List<AkerisEvent> _happened = [];
  ChainPull? _lastPull;
  AkerisState? _state;

  AkerisState get state => _state ??= readAkerisState(_akeris.load());

  void step(Seconds dt) {
    final akeris = _akeris.load();
    final pull = _chain.pull;
    if (!identical(pull, _lastPull)) {
      _lastPull = pull;
      akeris.followTether(readTether(pull));
    }
    akeris.step(dt, _terrain, _happened);
    _akeris.save(akeris);
    _report
      ..all(_happened)
      ..movedTo(akeris.feet);
    _happened.clear();
    _state = readAkerisState(akeris);
  }
}
```

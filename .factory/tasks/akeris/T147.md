# T147 — Place Akeris at the start of each zone he enters

## Description

On `ZoneEntered`, Akeris stands at the zone's start (architect change-05, `state-zone_state` and
`events-zone_entered`; `layout.md`: "Akeris at the start — the start room's foot of the stair"). The
event is delivered only after dungeon saved the zone, so its `ZoneState.start` is readable. The use
case reads it through `ReadZoneState`, a function wave 6's composition root binds to
`StepZone.state` (planner wave-05 `state-read-as-function`). It hands the start to the root's
`placeAt`, which refuses a point inside a solid. A refused placement changes nothing.

## Preconditions

- On `main`: `EventQueue` (core/loop); akeris `CLAUDE.md` lists `state/zone_state` as consumed
  (architect change-05).

## Constraints

- No rule: the root guards the placement.

## Implementation

```dart
// lib/features/akeris/application/enter_zone.dart — new
import 'package:saviors_paradox/core/contracts/events/zone_entered.dart';
import 'package:saviors_paradox/core/contracts/ports/event_source.dart';
import 'package:saviors_paradox/core/contracts/state/zone_state.dart';
import 'package:saviors_paradox/features/akeris/application/ports/akeris_repository.dart';
import 'package:saviors_paradox/features/akeris/domain/terrain.dart';

/// How akeris reads the zone's snapshot; the composition root binds it.
typedef ReadZoneState = ZoneState Function();

/// Akeris enters each zone at its start (architect change-05).
final class EnterZone {
  EnterZone({
    required AkerisRepository akeris,
    required Terrain terrain,
    required ReadZoneState zone,
    required EventSource events,
  }) : _akeris = akeris, // ignore: prefer_initializing_formals — private
       _terrain = terrain, // ignore: prefer_initializing_formals — ditto
       _zone = zone { // ignore: prefer_initializing_formals — ditto
    events.subscribe<ZoneEntered>((_) => enter());
  }

  final AkerisRepository _akeris;
  final Terrain _terrain;
  final ReadZoneState _zone;

  void enter() {
    final akeris = _akeris.load();
    if (akeris.placeAt(_zone().start, _terrain) != null) {
      _akeris.save(akeris);
    }
  }
}
```

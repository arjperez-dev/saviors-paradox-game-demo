# T115 — Hold Akeris's numbers in one tuning value

## Description

Every gameplay number of Akeris's body, in one immutable value. `VISION.md` leaves them to the game.
The operator accepted the sandbox's stand-ins as starting values, tuning targets rather than fixed
design (operator, 2026-10-17). Tuning is then a change to this file alone, and no rule anywhere
repeats a number (checklist C11). Health is 10, the HP every sandbox uses, and the abyss fall costs
2 (operator, 2026-10-17).

Where his body hangs from a chain's bite is his, not the chain's: chain says only where the blade
bit (planner wave-05 `chain-points-are-bites`).

## Constraints

- Each number names its source in a comment (coding-standards §9).
- `const AkerisTuning()` is the only constructor; equality is by type, since every instance holds
  the same numbers.

## Implementation

```dart
// lib/features/akeris/domain/akeris_tuning.dart — new
import 'package:saviors_paradox/core/contracts/kernel/seconds.dart';

/// The game's numbers for Akeris's body: the sandbox's stand-ins, accepted
/// as starting values to tune (operator, 2026-10-17). A tuning is a change
/// here alone.
final class AkerisTuning {
  const AkerisTuning();

  // Sandbox `GRAV`, and the fall it caps (`air`): su/s², su/s.
  final double gravity = 2900;
  final double fallSpeedCap = 1500;

  // contract.md §2: standing 192 su; sandbox `H_CROUCH`, `H_ROLL`; the
  // body 34 su wide (sandbox `reset`, `w: 34`).
  final double standingHeight = 192;
  final double crouchingHeight = 138;
  final double rollingHeight = 112;
  final double halfWidth = 17;

  // contract.md §2: hip 84, torso 72, the shoulder 6 below the neck.
  final double shoulderAboveFeet = 150;

  // Sandbox `MAX_RUN` and the accelerations of its ground `step`; the
  // walk is 170 (animations.md §1.2).
  final double runSpeed = 440;
  final double walkSpeed = 170;
  final double walkAcceleration = 2600;
  final double runAcceleration = 520;
  final double turnAcceleration = 3000;
  final double stopDeceleration = 2300;

  // Sandbox `gaitOn` (above 25 su/s) and animations.md §1.2's r, past
  // half-way at 170 + 220 / 2.
  final double walkingFrom = 25;
  final double runningFrom = 280;

  // Sandbox air control: toward 400 su/s at 1300 su/s².
  final double airSpeed = 400;
  final double airAcceleration = 1300;

  // Sandbox `JUMP_V`, `JUMP_HIGH_V`; coyote 0.09 s, jump buffer 0.12 s.
  final double jumpSpeed = 1220;
  final double highJumpSpeed = 1520;
  final Seconds coyoteTime = const Seconds(0.09);
  final Seconds jumpBuffer = const Seconds(0.12);

  // Sandbox crouch: toward 150 su/s at 1500 su/s².
  final double crouchSpeed = 150;
  final double crouchAcceleration = 1500;

  // VISION.md §Movement: ≈ 330 su in 0.46 s, invulnerable the first 0.32 s
  // (sandbox `ROLL_T`, `ROLL_V`, `ROLL_IFRAMES`, cooldown 0.12 s); jumping
  // out keeps lerp(620, 280) su/s, never under the air speed.
  final Seconds rollTime = const Seconds(0.46);
  final double rollStartSpeed = 980;
  final double rollEndSpeed = 440;
  final Seconds rollInvulnerability = const Seconds(0.32);
  final Seconds rollCooldown = const Seconds(0.12);
  final double rollJumpStartSpeed = 620;
  final double rollJumpEndSpeed = 280;

  // Sandbox `AIR_ROLL_T`; VISION.md: the roll's invulnerability.
  final Seconds airRollTime = const Seconds(0.42);

  // Sandbox `dive`: 1750 su/s down, braking 900 su/s² across, keeping 0.3
  // of his speed, from anything slower than a 600 su/s rise.
  final double diveSpeed = 1750;
  final double diveBraking = 900;
  final double diveKeeps = 0.3;
  final double diveFromRiseUnder = 600;

  // hazards.md Z10: 0.45 s falling, 0.25 s to dark, 2 damage (operator,
  // 2026-10-17); firm ground: both feet on stone, 26 su each side, felt
  // 3 su below (sandbox `zAfterStep`).
  final Seconds abyssFallTime = const Seconds(0.45);
  final Seconds abyssDarkTime = const Seconds(0.25);
  final double abyssDamage = 2;
  final double firmFootSpan = 26;
  final double firmFootDepth = 3;

  // The sandboxes' HP = 10 (operator, 2026-10-17).
  final double health = 10;

  // animations.md §4 hurt: 0.40 s, knocked back at 300 (sandbox braking
  // 1300 su/s²).
  final Seconds hurtTime = const Seconds(0.4);
  final double hurtKnockback = 300;
  final double hurtBraking = 1300;

  // items.md §2: the pickup, 0.5 s.
  final Seconds pickupTime = const Seconds(0.5);

  // hook-blades.md §3 and the sandbox's `swing`: reeled in to 210 su at
  // 420 su/s; A/D pump 2.6; damped 0.12/s; at most 1.45 rad, bouncing back
  // at 0.2; Space adds 380 su/s up; a chain never shorter than 90 su.
  final double swingLength = 210;
  final double reelSpeed = 420;
  final double swingPump = 2.6;
  final double swingDamping = 0.12;
  final double swingLimit = 1.45;
  final double swingBounce = 0.2;
  final double letGoLift = 380;
  final double shortestChain = 90;

  // Sandbox `POSE.swing` through `skeleton`: the gripping hand 218.6 su
  // above his feet (66 + 32 + 30 above the hip, 46·sin 92° + 46·sin 104°
  // below it).
  final double handAboveFeet = 218.6;

  // The sandbox's `wallGrabStep`: across in 0.3 s; animations.md §4: a
  // climb stretch in 0.5 s; the sandbox's `wallHang`: jumping off at 360
  // back, 820 up.
  final Seconds pullAcrossTime = const Seconds(0.3);
  final Seconds climbStretchTime = const Seconds(0.5);
  final double wallJumpAway = 360;
  final double wallJumpLift = 820;

  // The sandbox's `wallGrabStep`: pulled across, he hangs 250 su below the
  // bite; `wallClimb`: a stretch ends 200 su below the new bite (50 su a
  // click, operator, 2026-10-17); animations.md §4: the mantle, 0.62 s,
  // 40 su past the edge (the sandbox's `WL.x + d * 40`).
  final double hangBelowBite = 250;
  final double stretchBelowBite = 200;
  final Seconds mantleTime = const Seconds(0.62);
  final double mantleOver = 40;

  // How far into the wall, above and below a bite, he feels whether it
  // caught the top edge: a probe, no reference number.
  final double edgeProbe = 8;

  // hook-blades.md §3: the strike's 340 su; a pointer still for 4 s aims
  // straight ahead (operator, 2026-10-15).
  final double chainReach = 340;
  final Seconds aimForgottenAfter = const Seconds(4);

  @override
  bool operator ==(Object other) => other is AkerisTuning;

  @override
  int get hashCode => (AkerisTuning).hashCode;
}
```

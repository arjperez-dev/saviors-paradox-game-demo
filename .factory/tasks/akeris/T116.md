# T116 — Model Akeris's health as a value

## Description

`Health` (architecture §4's own example of a value object): what is left and the most it can be. It
never goes below zero or above its maximum, and every change returns a new value.

## Constraints

- Immutable, equal by value, validated in its constructor (checklist A11).

## Interfaces

| File | Symbol | Role | Building block | Signature |
|---|---|---|---|---|
| `lib/features/akeris/domain/health.dart` | `Health` | exports | value object | `const Health({required double current, required double maximum})`, `const Health.full(double maximum)`, `bool get isDepleted`, `Health lose(double amount)`, `Health heal(double amount)`, `Health raiseMaximum(double amount)` |

## Implementation

```dart
// lib/features/akeris/domain/health.dart — new
import 'dart:math' as math;

/// How much health Akeris has left, and the most he can have.
final class Health {
  const Health({required this.current, required this.maximum})
    : assert(maximum > 0, 'some health is possible'),
      assert(current >= 0 && current <= maximum, 'within its maximum');

  const Health.full(double maximum)
    : this(current: maximum, maximum: maximum);

  final double current;
  final double maximum;

  bool get isDepleted => current == 0;

  Health lose(double amount) {
    assert(amount >= 0, 'a loss is never a gain');
    return Health(current: math.max(0, current - amount), maximum: maximum);
  }

  Health heal(double amount) {
    assert(amount >= 0, 'healing never hurts');
    return Health(
      current: math.min(maximum, current + amount),
      maximum: maximum,
    );
  }

  /// A higher maximum; what is left stays (the health scroll heals apart).
  Health raiseMaximum(double amount) {
    assert(amount > 0, 'a raise raises');
    return Health(current: current, maximum: maximum + amount);
  }

  @override
  bool operator ==(Object other) =>
      other is Health && other.current == current && other.maximum == maximum;

  @override
  int get hashCode => Object.hash(current, maximum);
}
```

| `test/features/akeris/domain/health_test.dart` | a loss never goes below zero | `Health.full(10).lose(3)` is `Health(current: 7, maximum: 10)`; `.lose(30)` is `current: 0` and `isDepleted`. |

| `test/features/akeris/domain/health_test.dart` | raising the maximum keeps what is left | `Health(current: 4, maximum: 10).raiseMaximum(5)` is `Health(current: 4, maximum: 15)`. |
| `test/features/akeris/domain/health_test.dart` | health outside its maximum is refused | `Health(current: 11, maximum: 10)` and `Health(current: -1, maximum: 10)` throw an `AssertionError`. |
| `test/features/akeris/domain/health_test.dart` | equal health is equal | Two `Health(current: 4, maximum: 10)` are `==` with equal `hashCode`s; `Health.full(10)` differs. |

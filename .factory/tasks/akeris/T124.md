# T124 — Hold Akeris still while he picks up an item

## Description

The pickup's body (`items.md` §2): standing on the ground, he picks up what an altar held and stands
still 0.5 s while the item flies into his hand. Whether there was an item is the `Altars` port's
answer, asked by the application; the root only says whether he can take now, and holds him.

**Invariant added:** he picks up only on foot and grounded.
**Domain event:** `PickupBegun(at)`.

## Implementation

```dart
// lib/features/akeris/domain/taking.dart — new
part of 'akeris.dart';

// The pickup: 0.5 s standing still while the item flies into his hand
// (items.md §2).
final class _Taking extends _Posture {
  Seconds _elapsed = Seconds.zero;

  @override
  Stance stanceOf(Akeris akeris) => Stance.taking;

  @override
  AkerisEvent? enter(Akeris akeris) {
    _elapsed = Seconds.zero;
    return null;
  }

  @override
  _Posture step(
    Akeris akeris,
    Seconds dt,
    Terrain terrain,
    List<AkerisEvent> into,
  ) {
    final tuning = akeris._tuning;
    final body = akeris._body;
    body
      ..velocity = Vec2(
        _approach(body.velocity.x, 0, tuning.stopDeceleration * dt.value),
        body.velocity.y,
      )
      ..fall(dt)
      ..move(dt, terrain);
    _elapsed = _elapsed + dt;
    return _elapsed < tuning.pickupTime ? this : akeris._postures.onFoot;
  }
}
```

```dart
// posture.dart — `_Postures` gains `final _Taking taking = _Taking();`
// akeris.dart — the part, and:

  bool get canPickUp =>
      identical(_posture, _postures.onFoot) && _body.isGrounded;

  /// Begins the pickup; null when he cannot take now.
  PickupBegun? pickUp() {
    if (!canPickUp) {
      return null;
    }
    _posture = _postures.taking..enter(this);
    return PickupBegun(at: _body.feet);
  }
```

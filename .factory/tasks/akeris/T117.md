# T117 — Name what the chains do to Akeris's body

## Description

`Tether`, akeris's own words for the contract's `ChainPull`, translated in `application/`
(architecture §2.2, checklist A6). The four cases:
- `Slack`: no chain holds him.
- `PulledToward(bite)`: pulled across to the wall his blade bit at `bite`.
- `Hung(anchor, hold, length)`: hanging from a ring, or a wall, `length` of chain to his hand.
- `ClimbingTo(bite)`: climbing toward the new bite.

Each point is where the blade bit; where his body goes from it is the root's (planner wave-05
`chain-points-are-bites`, operator 2026-10-17). A vine hangs him as a ring does (VISION.md), so
`Hold` has two values.

## Constraints

- Each case is a value object: immutable, `const`, equal by value (checklist A11).

## Implementation

```dart
// lib/features/akeris/domain/tether.dart — new
import 'package:saviors_paradox/core/contracts/kernel/vec2.dart';

/// What holds the chain at its far end.
enum Hold { ring, wall }

/// What his chains do to Akeris's body (the contract's ChainPull, in
/// akeris's own words).
sealed class Tether {
  const Tether();
}

final class Slack extends Tether {
  const Slack();

  @override
  bool operator ==(Object other) => other is Slack;

  @override
  int get hashCode => (Slack).hashCode;
}

final class PulledToward extends Tether {
  const PulledToward(this.bite);

  /// Where the blade bit.
  final Vec2 bite;

  @override
  bool operator ==(Object other) => other is PulledToward && other.bite == bite;

  @override
  int get hashCode => bite.hashCode;
}

final class Hung extends Tether {
  const Hung({required this.anchor, required this.hold, required this.length})
    : assert(length > 0, 'a chain has some length');

  final Vec2 anchor;
  final Hold hold;
  final double length;

  @override
  bool operator ==(Object other) =>
      other is Hung &&
      other.anchor == anchor &&
      other.hold == hold &&
      other.length == length;

  @override
  int get hashCode => Object.hash(anchor, hold, length);
}

final class ClimbingTo extends Tether {
  const ClimbingTo(this.bite);

  /// Where the blade bit.
  final Vec2 bite;

  @override
  bool operator ==(Object other) => other is ClimbingTo && other.bite == bite;

  @override
  int get hashCode => bite.hashCode;
}
```

## Cómo se trabaja cada pieza de referencia

1. Se lee la plantilla de `_templates/` y lo que la visión dice de esa pieza.
2. Si es un personaje o una zona, se hace o se amplía su `sandbox.html`, jugable y basado en el sandbox de Akeris, con el mismo trazo estático.
3. Se revisa con capturas del navegador sin ventana, se publica como artifact para que el operador lo pruebe, y se itera.
4. Con el visto bueno, se escribe el `contract.md` con los números, se exporta `sheet.png` y se marca como aprobado en `reference/README.md`.
5. Se marca la casilla aquí y se anota en la bitácora.

Herramientas del sandbox de Akeris que se reutilizan: el trazo estático con semilla, la hoja de poses (`P`), los escenarios de prueba deterministas (`#nombre` en la URL) y las capturas con Chrome sin ventana.
